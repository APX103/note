# 第 12 章  结语

# 你学到了什么

读完本书，你已经熟悉了若干 C 进阶编程概念。再看较大的代码示例，你知道代码为什么长这样，也知道那些设计决定背后的道理。比如，本书[前言](前言.md)里的以太网驱动示例代码，你现在明白为什么有一个显式的 `driverCreate` 方法、为什么有一个持有状态信息的 `DRIVER_HANDLE`——正是[第一部分](Part_01_C模式.md)的模式指引了这个示例以及全书讨论的许多其他示例中的决定。

[第二部分](Part_02_模式故事.md)的模式故事展示了应用本书模式的好处，以及如何通过模式的应用让代码一点一点成长。下次面对 C 编程问题时，翻翻各模式的问题小节，看有没有哪个正对你的问题——若有，恭喜你：模式的指引这就用上了。

# 延伸阅读

本书帮 C 编程新手进阶为高级 C 程序员。下面这几本书对我提升 C 编程功力尤其有帮助：

- Robert C. Martin 的《Clean Code: A Handbook of Agile Software Craftsmanship》（Prentice Hall，2008，中译《代码整洁之道》）讨论实现历久弥坚的高质量代码的基本原则。任何程序员都值得一读，话题覆盖测试、文档、代码风格等。

- James W. Grenning 的《Test-Driven Development for Embedded C》（Pragmatic Bookshelf，2011，中译《嵌入式 C 语言测试驱动开发》）用一个贯穿始终的示例，讲解在贴近硬件的程序中如何用 C 实现单元测试。

- Peter van der Linden 的《Expert C Programming》（Prentice Hall，1994，中译《C 专家编程》）是一本早期的 C 进阶指导书，细致描述 C 语法的运作方式和常见陷阱的规避，还讨论了 C 内存管理等概念，并讲解链接器的工作原理。

- 与本书关系最近的是 Adam Tornhill 的《Patterns in C》（Leanpub，2014）。它同样讲模式，侧重如何用 C 实现"四人帮"设计模式。

# 结束语

与刚走出校门的 C 程序员相比，你现在握有进阶知识：用什么技术去构建大规模、工业级的 C 代码。你现在可以：

- 做错误处理——哪怕没有异常这样的机制

- 管理内存——哪怕没有垃圾回收器、没有析构函数来清理内存

- 实现灵活的接口——哪怕没有原生的抽象机制

- 组织文件和代码——哪怕没有类和包

C 缺一些现代编程语言的便利，但你现在已经能与它共事无碍。
