## 翻译说明

- 译自本仓库 `Fluent-C-book/` 的英文 Markdown 版本（源头为 `~/Documents/Fluent_C.epub`）。
- 代码块逐字符保留原文（含英文注释）；图表、模式名首次出现采用「中文（English）」双语标注。
- 模式名与术语全书统一，如：Guard Clause → 卫语句、Handle → 句柄、Dedicated Ownership → 专属所有权、Abstraction Layer → 抽象层。
- 插图在 `images/`，与英文版一致；跨章链接已指向本章中文文件。
- "已知应用"小节中的大量真实项目名（OpenSSL、Wireshark、NetHack 等）保留英文。
