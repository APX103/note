# 第四代核反应堆结构材料

> 本书基于 Pascal Yvon 主编的 *Structural Materials for Generation IV Nuclear Reactors*（Elsevier/Woodhead, 2016）一书的章节框架，由 AI 综合 IAEA、OECD/NEA、美国能源部（DOE）、欧盟核材料研究计划、各国核学会及同行评议期刊的公开资料独立整理编写，供学习研究参考之用。
>
> ⚠️ **免责声明**：本书为基于公开资料的学术性整理稿，不构成工程设计、材料选型与商业决策依据。所有材料性能数据、辐照寿期参数与许用规范以各国监管机构、ASME/JSME/RCC-MRx 等规范及厂商公开文件为准。

## 阅读建议

- **核材料方向研究生**：按章节顺序通读，重点关注第 2、6、7、9、10 章，建立"环境—机理—材料—寿期"的完整知识链。
- **核工程设计工程师**：可跳读第 1、3、4、5 章腐蚀环境，重点查阅第 9、10、12、17、18 章的选材逻辑与规范衔接。
- **先进材料研究者**：直接切入第 10、11、12、16 章，关注 ODS、难熔金属、SiC/SiC 与高熵合金等前沿体系。
- **政策与项目评估者**：第 1、6、14 章足以为决策提供技术背景，辅以各章"现状与发展方向"小结。
