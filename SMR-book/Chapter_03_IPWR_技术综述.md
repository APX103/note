# 第 3 章　IPWR 技术综述

> **核心命题**　一体化压水堆（Integral PWR, IPWR）通过把堆芯、蒸汽发生器、稳压器、主泵集成于同一压力容器，从根本上消除了一回路大破口事故，简化了系统结构，是非能动安全与固有安全理念在轻水 SMR 中的典型体现。

---

## 3.1　引言

传统压水堆（PWR）的核蒸汽供应系统（NSSS）由分散的压力容器、热腿/冷腿、蒸汽发生器（SG）、稳压器、主泵组成。这种"分散式"布局带来一系列问题：

- 大口径主管道是潜在的**大破口失水事故（LBLOCA）**源；
- 管道+ SG 大量结构增加了系统复杂性和抗震要求；
- 现场安装工时长，受施工质量波动影响大。

**一体化压水堆**把上述部件全部装入一个压力容器内，**消除了主管道**，从而：

- 物理上消除 LBLOCA，使设计基准事故（DBA）大大简化；
- 提高一回路自然循环能力（堆芯在下、SG 在上，密度差驱动循环）；
- 缩短工期，简化厂内布置；
- 改善人因与维修可达性。

IPWR 是当前轻水 SMR 中的主流路线，代表机型包括 NuScale、SMART、ACP100、mPower、CAREM-25、Holtec SMR-300 等。

## 3.2　必要性

为什么要"一体化"？根本原因可以从三个层面回答。

### 3.2.1　安全层面：消除大破口

主管道双端断裂（DEGB）是传统 PWR 设计基准中最严重的事故之一，需要复杂的安全注入系统（SI）和应急堆芯冷却系统（ECCS）应对。IPWR 通过**取消大口径管道**，使反应堆冷却剂系统（RCS）的破损只剩下小口径仪表管和贯穿件，事故后冷却剂装量损失有限。

### 3.2.2　经济层面：模块化制造

分散式 NSSS 的部件来自不同工厂，需要在现场组装、焊接、检验；一体化设计可将整个压力容器作为一个整体模块在工厂完成，运输到现场吊装即可，大幅压缩现场施工的关键路径（CP）。

### 3.2.3　运维层面：减少维修与照射

减少管道焊缝、阀门、密封件意味着减少泄漏点和维修工作量；分散式 SG 的 U 型管是 PWR 故障高发区，一体化设计采用直管或螺旋管 SG，可改善可靠性并降低检修人员剂量。

## 3.3　一体化压水堆（IPWR）

### 3.3.1　典型结构

下图为典型 IPWR 的概念布局（文字描述）：

```
┌────────────────────────────┐
│       压力容器顶盖          │  ← 稳压器（内置在容器顶部）
│   ┌──────────────────┐     │
│   │     蒸汽发生器     │     │  ← 直管/螺旋管 SG 环绕堆芯
│   │  （围绕堆芯环形）  │     │
│   │  ┌────────────┐  │     │
│   │  │   堆芯     │  │     │  ← 紧凑堆芯，燃料组件数量少
│   │  │  （底部）   │  │     │
│   │  └────────────┘  │     │
│   │   控制棒驱动机构  │     │  ↑ 向上抽出
│   └──────────────────┘     │
│         主泵（外置/内置）   │
└────────────────────────────┘
```

- **堆芯**位于压力容器下部，控制棒从顶部插入；
- **蒸汽发生器**布置在堆芯上方的环形空间；
- **稳压器**集成于容器顶盖内部；
- **主泵**可以是内置式（如 NuScale 的"管内喷射"）或外置式（如 SMART 的全封闭泵）。

### 3.3.3　关键工程问题

- **SG 内置带来的检修可达性下降**：一旦发生 SG 管泄漏，难以像分散 PWR 那样整体更换 SG；多采用**冗余 + 在役检查（ISI）**策略。
- **控制棒驱动机构（CRDM）与 SG 的空间冲突**：CRDM 须穿过 SG 区域，常采用**长驱动轴 + 顶部布置**或**侧向驱动**。
- **压力容器尺寸受限**：一体化容器直径通常 3–6 m，需匹配大型锻造能力（中国一重、日本 JSW、韩国 Doosan 等具备）。
- **主泵选型**：屏蔽泵寿命长但效率低；湿定子泵噪声小；NuScale 用"无泵"自然循环方案，是激进简化。

## 3.4　安全性

IPWR 的安全优势集中体现在：

1. **消除 LBLOCA**：物理上不存在大破口途径，DBA 清单大幅简化。
2. **自然循环冷却**：堆芯在下、SG 在上，全功率自然循环可行（NuScale、BWRX-300）；事故下断电仍可长期冷却。
3. **低压差小破口**：一旦发生小破口，因装量大、压力下降缓慢，ECCS 注入压力低、容量小。
4. **源项减少**：堆芯功率密度低、燃料温度低，事故下裂变产物释放量显著降低，缩小应急计划区（EPZ）至厂址边界（部分设计目标）。
5. **多机厂址纵深防御**：单模块功率小，事故影响半径小，多模块间可互相支持冷却。

## 3.5　经济性

### 3.5.1　资本成本构成

IPWR 电站资本成本（OCC）主要分项：

| 分项 | 占比（参考） |
|---|---|
| 直接成本：反应堆厂房、辅助厂房、汽轮机厂房 | 50–60% |
| 间接成本：工程设计、采购、施工管理 | 20–25% |
| 业主成本：项目开发、调试、首炉燃料 | 10–15% |
| 不可预见费 + 融资利息 | 10–20% |

IPWR 通过以下途径降低 OCC：

- 工厂预制缩短现场工期（48 个月 → 36 个月以下）；
- 简化系统（少阀门、少管道、少泵）；
- 缩小安全壳与应急系统；
- 模块化运输，缩短现场关键路径。

### 3.5.2　规模不经济的对抗

IPWR 单机功率小，单位 kWe 资本成本通常比大型核电站高 20–50%。对抗"规模不经济"的途径：

- **系列化生产**：FOAK → NOAK，每倍产量学习率约 10%（即成本下降 10%）。
- **多机组叠加**：同址安装 4–12 个模块，共享汽轮机厂房、控制室、冷却水系统。
- **缩短建造周期**：缩短融资期，降低 IDC（利息在建期）。
- **简化监管**：系列化设计认证 + 厂址许可一次到位，多台机组滚动审批。

### 3.5.3　平准化电力成本（LCOE）

OECD/NEA 2024 年报告给出的 SMR LCOE 范围约：

- **NOAK 阶段**：60–100 USD/MWh；
- **FOAK 阶段**：可能高达 120–180 USD/MWh；
- **燃气联合循环 + CCS**：80–120 USD/MWh；
- **陆上风电 + 储能**：60–110 USD/MWh。

可见 NOAK 阶段 SMR 在工业基荷电力上具备竞争力。

## 3.6　发展趋势

1. **自然循环 + 非能动安全**是 IPWR 的设计主流（NuScale、BWRX-300、CAREM-25）。
2. **增大单机功率**（从 50 MWe 向 300 MWe）以摊薄单位投资和运维成本，是近期趋势（BWRX-300、SMR-300、AP300）。
3. **首堆快速进入市场**：2025–2030 年将有多台 IPWR 首堆并网，验证商业可行性。
4. **与可再生能源耦合**：通过蒸汽抽汽、储热、制氢等多样化负荷提升容量因子和 LCOE 表现。
5. **海上 / 移动式 IPWR**：俄罗斯 KLT-40S、中国 ACPR50S 把 IPWR 推向海上应用。
6. **数字孪生与智能运维**：基于 IoT 与 AI 的预测性维护将贯穿全寿命周期（见第 6、7 章）。

## 3.7　结论

IPWR 是当前 SMR 商业化的主流技术路线，它通过**结构一体化**实现了"消除大破口 + 自然循环冷却 + 工厂模块化制造"三位一体的优势。第 4–9 章将分别从堆芯燃料、系统部件、仪控、人机界面、安全、防扩散六个角度展开 IPWR 的关键技术；第 10–13 章讨论其商业化路径。
