# 第 6 章　IPWR 仪表和控制（I&C）

> **核心命题**　IPWR 的仪控系统通过**数字化 + 安全级 DCS + 智能诊断**实现了对反应堆全寿期的精细管理；但仪控平台的多样性、隔离与软件共因故障（CCF）仍是核安全监管的重点关切。

---

## 6.1　引言

仪表与控制（Instrumentation & Control, I&C）系统是反应堆的"神经系统"，负责：

1. **测量**：温度、压力、流量、液位、中子通量、辐射、振动等；
2. **控制**：维持运行参数在限值内，响应负荷变化；
3. **保护**：在事故工况下触发停堆、专设安全设施；
4. **监测**：设备健康、辐射、化学、人员剂量；
5. **信息**：为操纵员提供决策支持。

IPWR 的 I&C 系统相较大型 PWR 有以下特点：

- **共享与多机组**：12 个模块共享一个主控室，I&C 须支持"独立 + 联动"双重逻辑；
- **高自动化**：单堆人员少（如 NuScale 6 模块电站仅约 30 名操纵员）；
- **数字孪生**：依托大量传感器数据，可在数字空间中镜像物理堆；
- **退役 + 在役检查友好**：因模块化运输，I&C 须支持"工厂级检修 + 现场热态调试"。

## 6.2　系统 I&C

"系统 I&C"指反应堆以外的厂级控制，包括：

- **汽轮机控制**：转速、负荷、并网、超速保护；
- **凝汽器与给水控制**：液位、温度、流量；
- **BOP 控制**：循环水、压缩空气、化学药剂、电气；
- **辐射监测**：厂内、厂外、流出物；
- **消防、安防、通信**。

通常采用**非安全级 DCS**（如 Emerson Ovation、Siemens SPPA-T3000、HollySys MACS），架构采用分层分布式：

```
┌────────────┐
│ 厂级监视层  │ SCADA / 工程师站 / 操作员站
├────────────┤
│ 监督控制层  │ DCS 主控单元 / 历史数据库
├────────────┤
│ 现场控制层  │ 过程控制器（PLC / DCS CPU）+ 远程 I/O
├────────────┤
│ 现场仪表层  │ 变送器 / 阀门定位器 / 执行机构
└────────────┘
```

## 6.3　核蒸汽供应系统 I&C

NSSS I&C 是核安全的核心，分为**反应堆功率控制**、**反应堆保护**、**专设安全设施驱动**三大子系统。

### 6.3.1　反应堆功率控制系统

- **功率量程探测器**：堆外电离室（4 节或 6 节），覆盖 10⁻³–10⁰ 额定功率；
- **中间量程**：γ 补偿电离室；
- **源量程**：BF₃ / ³He 正比计数管（用于启堆）；
- **堆芯功率分布**：移动式堆芯中子探测器（固定式 + 移动式联合），或自给能探测器（SPND）阵列。

**控制模式**：

- **模式 A（基荷）**：维持反应堆功率恒定；
- **模式 B（负荷跟踪）**：灰棒调节反应性以匹配电网负荷；
- **模式 C（频率调节）**：基于温度反馈的小幅调节；
- **冷却剂平均温度控制**：T_avg 程序 → 控制棒动作。

### 6.3.2　反应堆保护系统（RPS）

RPS 是**安全级**系统，须满足：

- **冗余**：通常 4 通道（2/4 逻辑）；
- **隔离**：通道间电气隔离 + 物理隔离；
- **多样性**：硬件多样性 + 软件多样性，应对共因故障（CCF）；
- **FPGA / 微处理器混合**：现代设计多采用 FPGA 实现核心保护逻辑（如 Westinghouse Common Q、Triconex、Rolls-Royce SPINLINE）；
- **手动停堆**：硬接线按钮，绕过任何数字逻辑。

**典型保护参数**：

- 高/低中子通量；
- 高/低冷却剂温度；
- 高/低稳压器压力；
- 低冷却剂流量；
- SG 液位低；
- 安全壳压力高；
- 地震（触发 OBE/SSE 阈值停堆）。

### 6.3.3　专设安全设施驱动系统（ESFAS）

驱动 ECCS、AFW、安全壳喷淋、安全壳隔离等。逻辑与 RPS 类似，但响应动作更复杂。

### 6.3.4　IPWR 特有 I&C 挑战

- **多模块共享 I&C**：12 个模块的 RPS 共存于同一安全级机柜群，须保证模块间**电气、功能、空间三重隔离**；
- **无主泵自然循环**：失去主泵信号后，I&C 须正确判断自然循环已建立，无须紧急干预；
- **一体化 SG 控制**：OTSG 对给水扰动敏感，须高速响应的给水流量控制；
- **远程支持与运维**：单堆人员少，I&C 须支持远程诊断与专家协同。

## 6.4　BOP 仪表

BOP（Balance of Plant）指汽轮机、凝汽器、给水、电气、冷却水等常规岛与辅助系统。其仪表与火电类似，但有如下特点：

- **质量等级**：部分系统须达核级（如主蒸汽管道至隔离阀的仪表）；
- **冗余**：给水、循环水、电气保护系统须冗余；
- **数字化程度高**：DCS 集中管理；
- **网络安全**：BOP 与外部电网、调度、远程数据中心有数据交换，需严格的网络安全分区（参考 NIST 800-82、NEI 08-09）。

## 6.5　故障诊断和预测

"预测性维护（Predictive Maintenance, PdM）"是 IPWR 智能化的重要方向。

### 6.5.1　数据来源

- **振动监测**：主泵、汽轮机、风机轴承振动谱；
- **温度分布**：热电偶、分布式光纤（DTS）；
- **流量与压力**：电磁流量计、Coriolis 质量流量计；
- **辐射**：γ 谱仪、中子探测器；
- **电气**：电机电流、谐波；
- **化学**：在线电导率、pH、γ 谱；
- **视觉**：摄像头（用于维修期间可达区域）。

### 6.5.2　方法

- **统计分析**：阈值告警、SPC；
- **机器学习**：基于历史数据的异常检测（PCA、自编码器、LSTM、Transformer）；
- **数字孪生**：用机理模型 + 实时数据驱动虚拟反应堆，与实测对比；
- **专家系统 / 知识图谱**：嵌入工程经验和故障树；
- **物理-数据融合**：模型预测 + 数据校正（如 Kalman 滤波）。

### 6.5.3　典型应用

- 主泵轴承磨损预测；
- SG 管泄漏早期检测；
- 控制棒卡涩检测；
- 流量分布异常识别（堆芯热工水力监测）；
- 汽轮机叶片裂纹早期预警；
- 燃料破损检测（**一回路放射性活度跟踪**）。

## 6.6　信号处理电子设备

- **变送器**：智能化变送器（4–20 mA + HART / Foundation Fieldbus / Profibus）；
- **数据采集**：远程 I/O、现场总线；
- **数字滤波**：卡尔曼、自适应；
- **隔离器 / 安全栅**：防爆、防浪涌、信号隔离；
- **抗电磁干扰**：屏蔽、双绞、滤波；
- **环境适应性**：耐辐照、耐温（电缆、电子设备）。

## 6.7　电缆

核级电缆分为：

- **1E 级（安全级）**：用于 RPS、ESFAS、安全级仪表；
- **非 1E 级**：用于普通测控；
- **特殊电缆**：耐火、低烟无卤、抗辐射。

**材料**：

- **绝缘**：XLPE（交联聚乙烯）、EPR（乙丙橡胶）、硅橡胶；
- **护套**：CSPE、低烟无卤；
- **耐辐照**：无机矿物绝缘电缆（MI）用于高辐照区。

IPWR 因一体化、模块化，电缆路径简化，但每个模块仍需独立的信号穿越压力容器边界（**贯穿件**是核级电缆的关键设计点）。

## 6.8　未来发展趋势和挑战

### 6.8.1　趋势

1. **FPGA + 数字混合架构**：FPGA 处理保护逻辑，CPU 处理诊断和操作员交互；
2. **完全数字化 + 远程支持**：操纵员 + 远程专家协同，借助 5G/6G 卫星通信；
3. **网络安全**：合规 NRC RG 5.71、IEC 62645；
4. **AI 辅助决策**：故障诊断、操纵员辅助（注意 AI 不能进入安全级决策链）；
5. **数字孪生驱动运维**：与设计、运行、退役全寿期数据贯通；
6. **小型化、嵌入式传感**：MEMS 传感器、自供能中子探测器。

### 6.8.2　挑战

- **软件共因故障（SWCCF）**：相同数字平台在所有通道内可能因相同软件 bug 同时失效，需要多样性平台；
- **认证**：数字 I&C 平台需通过 IEC 62566、IEC 61513 等认证，周期长；
- **网络安全**：核设施是高价值攻击目标，纵深防御要求高；
- **人员资质**：操纵员、维修工程师、I&C 工程师短缺；
- **IPWR 多机组的控制室人因**：单操纵员监督 12 台堆，认知负荷与人因可靠性分析（HRA）是研究热点（见第 7 章）。

## 6.9　结论

IPWR 的 I&C 系统在大型 PWR 数字化基础上更进一步：从"控制反应堆"演变为"管理全寿期资产"。本章从系统 I&C、NSSS I&C、BOP、故障诊断、电子设备、电缆六个方面作了概述。第 7 章将转入人机界面（HSI）主题。
