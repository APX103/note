# 第 10 章　SMR 经济性和融资方面

> **核心命题**　SMR 的经济性命题是"以工厂系列化制造 + 多机组叠加 + 缩短建造周期"对抗规模经济。本章从投资和风险、资本成本、多机组竞争力、对其他发电技术的竞争力等维度展开。

---

## 10.1　引言

核电站经济性传统上靠"规模经济（Economies of Scale）"驱动：单机功率越大，单位 kWe 资本成本越低。然而 21 世纪后，大型核电站（如 EPR、AP1000、华龙一号）超支和拖期严重：

- 法国 Flamanville 3（EPR）：预算 33 亿欧元 → 实际 190 亿+；工期 5 年 → 17+；
- 美国 Vogtle 3/4（AP1000）：预算 140 亿美元 → 340+ 亿美元；
- 中国三门 1/2（AP1000）：工期 8 年（计划 4 年）。

在这种背景下，**模块化制造 + 多机组叠加 + 缩短建造周期**成为对抗"规模不经济"的替代方案。SMR 经济性分析的核心问题就是：这条替代路线是否可行？

## 10.2　投资和风险因素

### 10.2.1　资本成本构成

核电站资本成本（Overnight Capital Cost, OCC）分项（参考美国 EIA、OECD/NEA）：

| 分项 | 占比 |
|---|---|
| 直接成本（土建、设备、安装） | 50–60% |
| 间接成本（设计、采购管理、施工管理） | 20–25% |
| 业主成本（土地、首炉燃料、调试） | 10–15% |
| 不可预见费 + 融资（IDC） | 10–20% |

LCOE（平准化电力成本）：

```
LCOE = (CRF × OCC + 年固定 O&M + 年燃料 + 年退役基金) / 年发电量
CRF = i(1+i)^n / [(1+i)^n − 1]
```

其中 i 为贴现率（核电站常用 5–10%），n 为寿命（60 年）。

### 10.2.2　风险因素

- **超支风险**：FOAK 经常超支 50%–200%；
- **拖期风险**：建造期延长 1 年 → IDC 增加 5–10%；
- **融资风险**：长周期 + 大额投资，融资成本敏感；
- **监管风险**：新设计审批不确定；
- **市场风险**：电力市场电价、可再生能源竞争；
- **政治风险**：政策变化、公众反对；
- **供应链风险**：大型锻件、核级泵阀集中度高。

SMR 通过以下方式降低风险：

- 模块化制造：工厂可控环境 → 质量稳定；
- 多机组分期投运：缩短资金回收期；
- 标准化设计：一次设计认证 + 多次复制；
- FOAK → NOAK 学习曲线。

## 10.3　资本成本与规模经济

### 10.3.1　经典规模经济公式

```
C1 / C2 = (S1 / S2)^α
```

其中 C 为成本，S 为规模，α 为规模指数（典型 0.6）。

按 α = 0.6，将 1000 MWe 大型核电站"缩小"为 100 MWe SMR，单位 kWe 成本 = (1/10)^(1-0.6) = 2.51 倍。这就是"SMR 规模不经济"的根源。

### 10.3.2　对抗规模不经济的途径

1. **工厂制造学习曲线**：每倍累计产量成本下降 10%–20%（学习率）；
2. **多机组叠加**：4–12 个模块共享一个厂房、控制室、辅助系统，单位 kWe 投资摊薄；
3. **缩短建造周期**：48 个月 → 36 → 24 → 18 个月，IDC 显著降低；
4. **简化系统**：少泵、少阀、少管道 → 减少采购和安装成本；
5. **标准化设计认证**：一次审批 → 多次复制；
6. **干式建造 + 工厂模块运输**：减少现场气候影响；
7. **3D 打印关键部件**：定位格架、管板局部结构已开始试用。

### 10.3.3　估算案例

OECD/NEA 2024 年报告给出的 SMR OCC 估计（NOAK 阶段）：

- 美国：3500–5500 USD/kWe（大型 LWR：4000–6000 USD/kWe）；
- 欧洲：4000–6000 USD/kWe；
- 中国 / 韩国：2500–4000 USD/kWe。

NOAK 阶段 SMR 与大型 LWR 经济性接近；FOAK 阶段 SMR 通常高出 30%–80%。

## 10.4　资本成本和多机组

### 10.4.1　多机组叠加的优势

- **共享厂房、控制室、汽轮机厂房**：土建摊薄；
- **共享辅助系统**：CVCS、冷却水、电气；
- **共享运维团队**：操纵员、维修人员；
- **共享备件库**：库存成本下降；
- **共享许可证**：一次厂址许可 → 多机组运行。

### 10.4.2　多机组的风险

- **共因故障**：所有模块共享某些系统（如冷却水），可能成为单点；
- **共模风险**：相同设计 → 相同潜在缺陷；
- **运维复杂度**：12 个模块 + 1 个汽轮机 + 1 个控制室，协调难度大；
- **人员技能**：操纵员需同时管理多台堆，认知负荷增加（见第 7 章）。

### 10.4.3　最佳机组数

经济性研究表明：

- 4–6 模块的经济性最佳（共享 + 灵活平衡）；
- 12 模块以上，共享收益边际递减；
- 1–2 模块不足以摊薄固定成本，不经济。

## 10.5　资本成本和规模因素

### 10.5.1　学习曲线

```
C(N) = C(1) × N^(-b)
```

b 为学习指数，典型 0.05–0.15。

| 累计产量 N | 成本（相对首堆） |
|---|---|
| 1（FOAK） | 100% |
| 2 | 90% |
| 4 | 80% |
| 8 | 70% |
| 16 | 65% |

从 FOAK 到 NOAK（N≈10），单位成本通常下降 30%。

### 10.5.2　SMR 的特殊性

- **工厂流水线**：与飞机、汽车类似，学习率可能更高（10%–20%）；
- **但市场容量有限**：全球 SMR 年需求可能 50–200 台（2040 年前），难以达到汽车、飞机的规模；
- **首堆风险高**：FOAK 可能超支 50%–200%，需政府或大业主兜底。

## 10.6　多 SMR 机组竞争力

### 10.6.1　对比大型 LWR

| 指标 | 大型 LWR | SMR 多机组 |
|---|---|---|
| FOAK OCC | 5000–7000 USD/kWe | 6000–9000 USD/kWe |
| NOAK OCC | 4000–6000 USD/kWe | 3500–5500 USD/kWe |
| 建造期 | 60–96 月 | 24–36 月 |
| 资金门槛 | 高（120–150 亿美元） | 低（5–30 亿美元） |
| 灵活性 | 低（必须基荷） | 高（多机启停 + 综合能源） |
| 单位容量因子 | 90%+ | 90%（基荷）或灵活 |

SMR 的核心优势是**资金门槛低 + 灵活性**，而非单位 kWe 投资更低。

### 10.6.2　对比可再生能源 + 储能

- **LCOE**：NOAK SMR 约 60–100 USD/MWh；风+储能约 50–110；光伏+储能约 50–100；燃气联合循环 + CCS 约 80–120。
- **容量因子**：SMR 90%；可再生能源 25–40%；
- **稳定性**：SMR 提供惯性、可靠容量；
- **用地**：SMR 单位土地发电量是光伏 50 倍、风电 100 倍。

SMR 在"高比例可再生能源电网 + 工业基荷 + 偏远地区"具有独特价值。

## 10.7　SMR 相对于其他发电技术的竞争力

### 10.7.1　基荷电力（替代煤电）

- 中国、印度、东欧、东南亚有大量煤电待替代；
- SMR 因规模适中、可建在原煤电场址（接入电网、用水、用地现成），是煤电替代的有力竞争者。

### 10.7.2　工业热 + 制氢

- 高温 SMR（HTR-PM、Xe-100、Natrium）可提供 700–900 ℃ 热源，用于：
  - 钢铁（直接还原 DRI-EAF）；
  - 水泥；
  - 化工（合成氨、甲醇、烯烃）；
  - 制氢（高温固体氧化物电解 SOEC、热化学循环）。

### 10.7.3　海水淡化

- SMART、ACPR50S 等设计专门面向海水淡化市场（中东、北非）；
- 经济性：在缺水 + 缺电的中东，SMR 海水淡化可与化石能源方案竞争。

### 10.7.4　偏远地区 / 岛屿 / 海上

- 加拿大北方、阿拉斯加、俄罗斯北极、岛屿（海南、台湾、希腊岛屿）；
- 替代柴油发电（柴油 LCOE 200–400 USD/MWh）；
- 海上浮动核电站（俄罗斯 Akademik Lomonosov、中国 ACPR50S）。

## 10.8　外部因素

### 10.8.1　碳定价

- 碳价（如 EU ETS、中国全国碳市场）的引入使 SMR 相对化石能源竞争力上升；
- 碳价 50 USD/tCO₂ 即可使煤电成本上升约 5 美分/kWh，超过 SMR。

### 10.8.2　政策支持

- 美国 IRA 法案（2022）：先进核能税收抵免（PTC/ITC）+ 40 亿美元贷款担保；
- 欧盟绿色分类（EU Taxonomy）：在某些条件下包含核能；
- 英国 GDA + AR 项目；
- 中国 "十四五"先进核能发展规划；
- 加拿大、波兰、罗马尼亚 SMR 战略。

### 10.8.3　公众接受度

- 公众接受度是 SMR 落地的关键非经济因素；
- 强调安全、就业、低碳，与社区共商共建共享；
- 透明沟通：风险、收益、退役、废物。

### 10.8.4　供应链与人才

- 大型锻件（RPV、SG）全球产能紧张；
- HALEU 燃料供应（美国、欧洲仍依赖俄罗斯）；
- 核级泵、阀、I&C 平台供应商集中；
- 核工程师、操纵员人才短缺。
