# 第 12 章　SMR 施工

> **核心命题**　SMR 施工的核心命题是"以工厂制造替代现场施工"。本章从加工制造、部件制造、先进焊接、供应链影响四个角度展开。

---

## 12.1　引言

传统大型核电站建造周期长（5–8 年），主因是大量**现场施工**：

- 大体积混凝土浇筑（安全壳、厂房基础）；
- 大型管道焊接；
- 现场模块拼装；
- 调试与冷热态试验。

每一步受现场气候、人工质量、协调进度影响。AP1000、EPR 等大型核电站大量超支拖期，根本原因就是"现场施工工时不可控"。

SMR 的核心思路：

1. **压力容器、蒸汽发生器、稳压器**等在工厂完成；
2. **NSSS 模块**作为整体运输到现场；
3. 现场仅做基础 + 厂房 + 模块吊装 + 接管 + 调试；
4. 缩短建造周期到 24–36 个月。

本章按"加工制造 → 部件制造 → 先进焊接 → 供应链"展开。

## 12.2　加工制造

### 12.2.1　工厂制造优势

- **质量稳定**：车间环境（温湿、洁净、计量、工艺）可控；
- **效率高**：流水线、固定工位、专用装备；
- **人员资质稳定**：车间焊工、检验员长期固定；
- **检验手段完善**：现场难以实施的检验（如深射线探伤）在工厂易实施；
- **缩短现场关键路径**：现场不依赖单一大件到货即可推进。

### 12.2.2　主要工厂制造内容

- **压力容器（RPV）**：由大型锻件（筒体、顶盖、底封头、管嘴）焊接而成；
- **蒸汽发生器（SG）**：直管或螺旋管，管束胀接 / 焊接到管板；
- **稳压器**：容器 + 加热器 + 喷雾管；
- **堆芯 + 燃料组件**：燃料由专门工厂制造（如西屋、AREVA、中核北方）；
- **控制棒驱动机构（CRDM）**：精密机械加工；
- **主泵（屏蔽泵 / 湿定子泵）**：电机 + 泵壳；
- **辅助系统模块**：阀门、管道、热交换器预组装为模块。

### 12.2.3　大型锻件

RPV 筒体、SG 管板、稳压器封头等大型锻件是核电站的"工业母机"产品：

- 单件重量 100–500 吨；
- 直径 3–6 m；
- 锻造 + 热处理 + 机加工 + 堆焊层；
- 全世界能稳定供货的工厂不多：中国一重、二重、上重、日本 JSW、韩国 Doosan、法国 Le Creusot（Areva）、俄罗斯 OMZ。

SMR 的 RPV 直径通常 3–5 m，比大型 PWR（4–6 m）小，但仍需要顶级大型锻件。

### 12.2.4　模块化运输

- **运输方式**：海运（重件船）、河运、铁路、公路；
- **尺寸限制**：公路 ≤ 5 m 宽，铁路 ≤ 4 m 宽（标准机车），海运无限制；
- **NuScale**：模块直径约 3 m，高 23 m，重约 700 吨，可海运 + 重型卡车短途；
- **GE Hitachi BWRX-300**：NSSS 模块直径约 5 m，需海运 + 铁路。

## 12.3　部件制造

### 12.3.1　NSSS 模块

把 RPV + 内部构件 + SG + 稳压器 + 主泵 + 控制棒驱动机构 + 部分管路集成到一个"模块"中：

- 在工厂整体装配、焊接、检验；
- 整体运到现场；
- 现场吊装就位 + 二回路 + 安全壳接口。

NuScale、BWRX-300、ACP100 都采用这种模式。

### 12.3.2　安全壳

- **钢制安全壳**（NuScale、BWRX-300）：在工厂整体制造，运到现场吊装；
- **预应力混凝土安全壳**（ACP100、SMART）：现场建造；
- **复合安全壳**（钢内衬 + 混凝土）：混合方案。

### 12.3.3　辅助模块

- **泵房模块**：CVCS、ECCS、AFW 等阀门与管道预组装；
- **电气模块**：电气柜、电缆桥架预组装；
- **管道模块**：长管段在工厂焊接，现场对接。

### 12.3.4　汽轮机厂房与汽轮机

- 汽轮机仍主要在现场安装（因尺寸大）；
- 部分 SMR（NuScale）采用紧凑汽轮机，可整体模块化。

## 12.4　先进焊接技术

### 12.4.1　传统焊接

- **埋弧焊（SAW）**：用于 RPV 主焊缝；
- **窄间隙焊（NG-SAW）**：减少填充金属量，提高效率；
- **钨极氩弧焊（TIG）**：薄壁管、SG 管接头；
- **金属极气体保护焊（MIG/MAG）**：管道、支架；
- **电渣焊（ESW）**：厚板拼接。

### 12.4.2　先进焊接

- **激光焊接**：深熔、热影响区小、变形小；
- **激光-电弧复合焊**：兼顾效率与质量；
- **电子束焊**：真空环境，深度大；
- **摩擦焊**：固相焊接，无熔化，适合异种金属；
- **搅拌摩擦焊（FSW）**：用于铝合金、铜合金；
- **增材制造（3D 打印）**：用于复杂结构（定位格架、管板、SG 局部结构）；
- **冷喷涂**：用于涂层修复。

### 12.4.3　在线监测与无损检验

- **相控阵超声（PAUT）**：替代射线，分辨率高、安全；
- **衍射时差超声（TOFD）**：精确测缺陷尺寸；
- **数字射线**：高分辨率 + 自动判读；
- **声发射**：在役监测焊缝裂纹；
- **涡流**：SG 管检查。

### 12.4.4　焊接自动化

- 焊接机器人：焊接路径 + 视觉识别 + 实时反馈；
- 数字化焊接电源：精确控制熔滴过渡；
- 焊接质量数据库：每道焊缝可追溯。

## 12.5　供应链影响

### 12.5.1　供应链特征

SMR 对供应链的影响是双重的：

**正面**：

- 模块化减少现场施工人力，对当地劳动力依赖降低；
- 工厂系列化生产，给供应商带来稳定订单；
- 一次设计 + 多次复制，给监管、业主、供应商带来协同机会。

**负面**：

- 大型锻件、核级泵阀供应商集中，瓶颈明显；
- HALEU 燃料供应链不成熟（美国、欧洲）；
- 新材料（TRISO、铅铋合金、熔盐）供应链尚未形成；
- 全球运输能力（重件船、专用码头）有限。

### 12.5.2　关键瓶颈

| 瓶颈 | 描述 | 缓解 |
|---|---|---|
| 大型锻件 | RPV、SG 管板锻件供应紧张 | 各国扩产（中国一重、JSW、Doosan） |
| HALEU 燃料 | 5%–20% 富集度燃料供应不足 | 美国 Centrus、TerraPower；中俄已有能力 |
| TRISO 燃料 | 包覆颗粒燃料产能不足 | X-energy、BWXT 扩产 |
| 核级泵阀 | 屏蔽泵、核级阀供应商少 | 多元化供应商 |
| 重件运输 | 公路 / 铁路限制大 | 海运 + 重件码头 |

### 12.5.3　本地化要求

许多国家在 SMR 出口合同中要求**本地化**：

- 部分部件本地生产（如管道、支架、电缆）；
- 本地工程师参与设计、调试；
- 本地运维团队；
- 乏燃料管理本地化（或返回供应商国）。

本地化要求给出口商带来成本压力，但有助于打开市场。

### 12.5.4　供应链韧性与地缘政治

- 中美俄三国在核供应链上的相互依赖与脱钩；
- 俄乌冲突后，欧洲急于摆脱俄罗斯核燃料供应；
- 中国 HALEU、TRISO 自主化加速；
- 美国 DOE 推动 HALEU 国内生产（Centrus、X-energy 等）。

## 12.6　结论

SMR 施工的本质是"工厂化"——把过去散布在工地的焊接、组装、检验工序转移到工厂流水线。这要求：

1. **设计面向制造（DFM）**：从设计阶段就考虑工厂制造与运输；
2. **模块化结构**：减少现场焊接、安装；
3. **数字主线（Digital Thread）**：从设计到运行的数据贯通；
4. **供应链协同**：核心供应商深度参与设计；
5. **运输与物流**：海运、铁路、公路的重件物流规划；
6. **本地化与全球化的平衡**：满足业主国本地化要求。

未来 10 年（2025–2035）是 SMR 首堆密集建造的关键时期，施工能力的成熟将决定 SMR 商业化的成败。
