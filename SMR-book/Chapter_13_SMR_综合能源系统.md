# 第 13 章　SMR 综合能源系统

> **核心命题**　SMR 不只是"小型核电站"，更是多能互补综合能源系统的"核心热源"。通过与可再生能源、储能、制氢、海水淡化、工业供热耦合，SMR 可显著提升电网韧性、能源系统低碳化与经济性。

---

## 13.1　引言

未来能源系统呈现以下趋势：

- **高比例可再生能源**：风电、光伏占比上升，但其间歇性带来电网稳定性挑战；
- **深度脱碳**：电力、工业、交通、建筑全部脱碳，氢能、合成燃料、电气化成为关键；
- **多能互补**：电、热、冷、气、氢、水多种能源载体相互转化；
- **分布式 + 集中式并存**：大型基地 + 分布式微网。

在这一背景下，SMR 凭借：

- **稳定基荷**：90% 容量因子；
- **高温热源**：300–700 ℃（轻水）/ 700–950 ℃（气冷）/ 高于 500 ℃（液态金属）；
- **零碳排**：全寿期碳排放约 11–12 gCO₂/kWh；
- **灵活功率**：多模块可启停；
- **紧凑**：可与工业设施共址；

成为综合能源系统的理想"核心热源"。

## 13.2　综合能源系统原理

综合能源系统（Integrated Energy System, IES）的核心思想是**多能互补 + 梯级利用**：

```
[核反应堆热源]
      │
      ├─ → 一次蒸汽（高温）
      │       │
      │       ├─ → 汽轮机发电
      │       ├─ → 工业高温工艺（钢铁、水泥、化工）
      │       ├─ → 高温制氢（SOEC、热化学循环）
      │       └─ → 高温储热（熔盐、固态储热）
      │
      ├─ → 抽汽（中温）
      │       ├─ → 区域供热
      │       ├─ → 海水淡化（MED、MSF）
      │       ├─ → 中温储热
      │       └─ → 工业中温工艺（造纸、纺织）
      │
      └─ → 余热（低温）
              ├─ → 温室、养殖
              ├─ → 吸收式制冷
              └─ → 干燥
```

## 13.3　综合能源系统结构评估

### 13.3.1　核-可再生-储能混合系统（N-R-H）

```
[SMR] + [风电 / 光伏] + [储能（电化学 / 熔盐）] + [电网]
```

- SMR 提供稳定基荷；
- 可再生能源提供廉价电力（峰时）；
- 储能平抑波动；
- SMR 在可再生过剩时降功率，电力不足时升功率（负荷跟踪）；
- 经济性：综合 LCOE 可比单独 SMR 或单独可再生低 10%–30%。

**案例**：

- 美国 TerraPower Natrium：345 MWe + 1.8 GWh 熔盐储热，可与风电协同；
- 中国核电 + 风光基地：在西北、东北建设大型综合基地。

### 13.3.2　核能 + 工业供热（N-IH）

```
[高温 SMR] + [钢铁 / 水泥 / 化工] + [CO₂ 捕集]
```

- 钢铁：H₂-DRI（氢基直接还原铁）+ 电弧炉；
- 水泥：替代煤燃烧，提供煅烧温度；
- 化工：合成氨、甲醇、烯烃；
- 这些行业占全球 CO₂ 排放约 25%，深度脱碳必须依赖高温热源。

### 13.3.3　核能 + 制氢（N-H₂）

主要技术路线：

| 技术 | 温度 | 效率 | 成熟度 |
|---|---|---|---|
| 低温电解（PEM、AEL） | 60–80 ℃ | 60–70% | 商业化 |
| 高温固体氧化物电解（SOEC） | 700–850 ℃ | 80–90% | 示范 |
| 热化学循环（S-I、Cu-Cl、Hybrid S） | 850–950 ℃ | 40–50%（热） | 研发 |

- 高温 SMR（HTR-PM、Xe-100、Natrium）配合 SOEC 可实现低成本制氢；
- 美国 INL 高温电解（HTSE）示范：与 Bloom Energy 合作运行固体氧化物电解池，并在 Idaho 建立 4–10 MW 规模的氢能验证场（Hydrogen Proving Ground）；
- 中国 HTR-PM 后续：高温制氢 R&D。

氢的应用：

- 燃料电池汽车、钢铁（DRI）、合成氨、甲醇、合成燃料、储能。

### 13.3.4　核能 + 海水淡化（N-D）

- **多级闪蒸（MSF）**：高温蒸汽加热海水多级蒸发；
- **多效蒸馏（MED）**：与 MSF 类似，但效率更高；
- **反渗透（RO）**：常温，电力驱动；
- 混合：MED + RO、MSF + RO。

SMR + 海水淡化的经济性：

- 与化石能源方案相比，在全寿期内更经济；
- 缺水地区（中东、北非、印度、中国北方）潜在市场巨大；
- 案例：俄罗斯 Akademik Lomonosov（70 MWe + 60,000 m³/d）、SMART 海水淡化设计、ACPR50S。

### 13.3.5　核能 + 区域供热（N-DH）

- 中国、俄罗斯、北欧寒冷地区有大量区域供热需求；
- SMR 可作为城市集中供热源（中温 80–150 ℃）；
- 案例：中国"燕龙"低温供热堆（DHR-400）；俄罗斯 BREST-OD-300 计划配套区域供热。

## 13.4　SMR 综合能源系统发展潜力

### 13.4.1　潜力市场

| 应用 | 主要市场 | 容量需求 |
|---|---|---|
| 基荷电力 | 全球 | 大 |
| 工业供热 | 钢铁、水泥、化工 | 中 |
| 制氢 | 全球脱碳 | 大 |
| 海水淡化 | 中东、北非、印度 | 中 |
| 区域供热 | 寒冷地区 | 中 |
| 海上 / 偏远 | 海岛、矿区、北极 | 小但独特 |

### 13.4.2　协同效应

- **经济性**：通过梯级利用 + 多能销售，可提升 SMR 整体收益 20%–50%；
- **可靠性**：与可再生能源互补，提升电网稳定性；
- **脱碳**：覆盖电、热、氢、水多个脱碳难点；
- **能源安全**：核燃料储存方便、供应链本土化、长换料周期。

## 13.5　核能的非电力应用

### 13.5.1　工业工艺

| 工艺 | 温度 | 现状 |
|---|---|---|
| 区域供热 | 80–150 ℃ | 已商业（俄罗斯、中国） |
| 海水淡化 | 80–120 ℃ | 已商业 |
| 造纸、纺织 | 150–200 ℃ | 工业实践 |
| 化工（合成氨、化肥） | 300–500 ℃ | 工业实践 |
| 炼油 | 300–500 ℃ | 工业实践 |
| 钢铁 DRI | 800–1000 ℃ | 示范 |
| 水泥煅烧 | 1400 ℃ | 示范 |
| 制氢（SOEC、热化学） | 700–950 ℃ | 研发示范 |

### 13.5.2　船舶与海上

- **破冰船**：俄罗斯（Arktika 级，RITM-200）、中国（玲龙系列）；
- **海上浮动核电站**：俄罗斯 Akademik Lomonosov、中国 ACPR50S；
- **深空探测**：火星、外行星任务用太空核电源（如 NASA Kilopower）。

### 13.5.3　特殊应用

- **国防**：海军核动力（航母、潜艇）；
- **空间站、月球基地**：永久基地核电源；
- **远程矿区**：替代柴油。

## 13.6　未来发展趋势

1. **核-可再生-储能混合系统**：通过智能调度 + 数字孪生实现最优运行；
2. **SMR + 高温制氢**：将成为 2030 年后重要市场（与电解氢竞争）；
3. **海上 SMR**：解决岛屿、海洋能源需求；
4. **移动 / 可运输 SMR**：军用、灾区救援、临时供电；
5. **多堆联合运行**：4–12 个 SMR 共享厂址，灵活组合发电、供热、制氢；
6. **数字化与 AI**：优化调度、预测性维护、智能控制；
7. **商业模式创新**：能源服务（不仅是电力）、热电联供合同、能源即服务（EaaS）。
