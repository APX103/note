# 第 18 章　中国 SMR 技术

> **核心命题**　中国 SMR 技术呈现"多路线并进 + 多业主协同"格局：中核集团（CNNC）**玲龙一号（ACP100）**是全球首个陆基 IPWR 示范项目；中核 + 清华 + 华能联合的 **HTR-PM** 是全球首座模块式高温气冷堆；中广核 ACPR50S 与中国海上浮动堆面向海洋应用；快堆、铅冷、熔盐堆 R&D 同步推进。

---

## 18.1　引言

中国是全球最大核电建设国，目前运行 55+ 台核电机组，在建 20+ 台，主导堆型为华龙一号（HPR1000，自主三代）、CAP1400（与西屋合作衍生）、国和一号等。在 SMR 领域，中国采取**多路线并进**战略：

- **轻水 SMR**：中核 ACP100（玲龙一号）、中广核 ACPR50S、国电投 CAP200 等；
- **高温气冷堆**：HTR-PM（已商运）；
- **快堆**：中国实验快堆 CEFR（已运行）、示范快堆 CFR-600（在建）；
- **铅冷快堆**：CAS 启动计划；
- **熔盐堆**：上海应物所 TMSR-SF / TMSR-LF；
- **微堆**：泳池式低温供热堆（DHR-400，"燕龙"）、空间堆、海岛堆。

中国 SMR 战略的特点：

- **政府顶层设计**：国家发改委、能源局、国防科工局协调；
- **多家集团并行**：中核、中广核、国电投、华能、清华、中科院分工；
- **军民融合**：海军核动力、空间核电源、海岛堆；
- **"一带一路"出口**：与华龙一号共同推广；
- **依托强大供应链**：一重、二重、东方电气、上海电气、哈汽等。

## 18.2　高温气冷堆（HTR-PM）

### 18.2.1　项目背景

- **HTR-PM**（High-Temperature gas-cooled Reactor Pebble-bed Module）：
  - 由清华大学核研究院（INET）主导设计；
  - 中核集团（CNNC）、华能集团共同建设；
  - **全球首座模块式高温气冷堆示范工程**；
  - 厂址：山东荣成石岛湾（与华能高温气冷堆核电站示范工程共址）。

### 18.2.2　设计参数

| 参数 | 数值 |
|---|---|
| 反应堆模块 | 2 × 250 MWt |
| 总电功率 | 211 MWe |
| 一回路（氦气）温度 | 750 ℃（出口）/ 250 ℃（入口） |
| 一回路压力 | 7 MPa |
| 燃料 | 球床 TRISO（直径 6 cm，含 UO₂ 包覆颗粒） |
| 富集度 | 8.9% |
| 平均燃耗 | 90 GWd/tHM |
| 二回路（蒸汽） | 13.24 MPa / 567 ℃ |
| 设计寿命 | 40 年 |

### 18.2.3　技术特征

- **模块式**：2 个反应堆模块共享 1 个汽轮机；
- **球床燃料**：连续在线换料（球在堆芯循环，类似 AVR、THTR）；
- **TRISO 燃料**：耐 1600 ℃，事故下不破损；
- **氦气循环风机**：磁悬浮高速风机（关键技术突破）；
- **固有安全**：负反应性温度反馈 + 高热容燃料 → 失去冷却下燃料自动稳温 < 1600 ℃。

### 18.2.4　里程碑

- 2012 年开工建造；
- 2021 年 9 月反应堆首次临界；
- 2021 年 12 月并网发电；
- 2023 年 12 月正式商运；
- **意义**：全球首座商用模块式高温气冷堆，验证固有安全 + 商业电力可行性。

### 18.2.5　后续 HTR-PM600 / HTR-PM1000

- 6 × 250 MWt 模块 = 655 MWe 电站；
- 目标市场：北方工业供热、煤电替代、制氢；
- 河北海兴、福建漳州等候选厂址。

## 18.3　ACP100（玲龙一号）

### 18.3.1　项目背景

- **玲龙一号（ACP100 / Linglong One）**：
  - 由中核集团（CNNC）自主设计；
  - **全球首个通过 IAEA 通用安全审查（GSR）的陆基 IPWR**（2016 年）；
  - 厂址：海南昌江核电站（与现有大型核电站共址）；
  - 多用途示范：电力 + 海水淡化 + 工业供热。

### 18.3.2　设计参数

| 参数 | 数值 |
|---|---|
| 热功率 | 385 MWt |
| 电功率 | 125 MWe |
| 一回路压力 | 15 MPa |
| 一回路温度 | 320 ℃ |
| 燃料组件 | 37 个 17×17（CF3 自主） |
| 富集度 | ≤ 4.95% |
| 换料周期 | 24 个月 |
| 设计寿命 | 60 年 |
| SG 形式 | 直流直管 SG（OTSG） |
| 主泵 | 屏蔽泵 × 4 |

### 18.3.3　技术特征

- **一体化压力容器**：堆芯 + SG + 稳压器集成；
- **OTSG**：紧凑、响应快、对水质要求高；
- **屏蔽泵**：4 台，无轴封泄漏；
- **非能动安全**：
  - 被动余热排出（PRHRS）；
  - 被动安全注入；
  - 被动安全壳冷却；
  - 全厂断电（SBO）下 72 小时无须干预；
- 应急计划区（EPZ）目标 300 m（与厂址边界接近）。

### 18.3.4　里程碑

- 2010 年代：设计与 IAEA GSR；
- 2021 年 7 月：海南昌江开工；
- 2022 年起：核岛土建、设备到货；
- 2023 年：压力容器吊装就位；
- 2026 年预计首次临界 + 并网；
- **意义**：中国首个自主 IPWR 示范，为后续商业推广铺路。

### 18.3.5　后续 ACP100 后继

- **ACP100S**（海上浮动版）：与 ACPR50S 类似；
- **ACP100+ / ACP200**：放大版本，目标 200 MWe；
- 出口市场：东南亚、中东、非洲、南美。

## 18.4　中国 SMR 部署情况

### 18.4.1　其他主要 SMR 项目

| 项目 | 类型 | 业主 | 状态 |
|---|---|---|---|
| HTR-PM | 球床 HTGR | 中核 + 华能 + 清华 | 2023 商运 |
| ACP100（玲龙一号） | IPWR | 中核 | 2026 预计 |
| ACPR50S | 海上浮动 PWR | 中广核 | 设计 + 实验堆 |
| CAP200 / Linglong 后继 | IPWR | 国电投 | 概念设计 |
| CFR-600（霞浦示范快堆） | 钠冷快堆 | 中核 | 在建（600 MWe，略大） |
| CIAD（铅冷快堆） | LFR | 中科院 | 概念 |
| TMSR-SF（固态） | 固态熔盐堆 | 上海应物所 | 2023 实验堆临界 |
| TMSR-LF（液态） | 液态熔盐堆 | 上海应物所 | 在建 |
| 燕龙（DHR-400） | 低温供热堆 | 中核 | 设计 |
| 海洋核动力平台 | 海上 IPWR | 中船重工 / 中广核 / 中核 | 设计 |

### 18.4.2　部署特点

- **示范先行**：HTR-PM、ACP100 等示范堆先行验证，再放大推广；
- **多业主分工**：中核主推 IPWR + 快堆；中广核主推海上；国电投主推 CAP200；清华主导 HTR；
- **依托大型核电站共址**：HTR-PM、ACP100 都建在现有核电站厂址，共享基础设施；
- **北方供热**：燕龙、低温堆面向北方城市区域供热；
- **海上 / 岛屿**：南海岛礁、远海油田、海上平台；
- **出口**：与华龙一号共同形成"大型 + 小型"出口组合。

### 18.4.3　出口市场

- **沙特**：与 KAERI 共同评估（双方都涉及 SMART）；
- **印尼**：高温气冷堆评估；
- **巴基斯坦**：与卡拉奇核电群协同；
- **中东、非洲**：海水淡化 + 电力；
- **东欧**：与华龙一号竞争 NuScale、BWRX-300。

## 18.5　发展趋势

1. **首堆密集投运**：HTR-PM（2023 已运行）、ACP100（2026）、CFR-600（2027+）、TMSR-LF；
2. **放大与商业推广**：HTR-PM600、ACP200、海上 SMR；
3. **北方供热市场**：燕龙低温堆、HTR-PM 改供热；
4. **海上浮动堆**：南海岛礁、远海油田；
5. **制氢示范**：HTR-PM 后续高温制氢 R&D；
6. **快堆闭式燃料循环**：CFR-600 + CFR-1200 + 后处理；
7. **熔盐堆前沿**：TMSR-SF 已运行，TMSR-LF 在建；
8. **数字化、智能化**：依托中国 ICT 工业，发展智能核反应堆；
9. **"一带一路"出口**：与华龙一号共同推广；
10. **HALEU 燃料**：TRISO 用 8.9% 富集度，国内富集能力充足。
