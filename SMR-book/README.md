# 小型模块化反应堆（SMR）技术

> 本电子书根据公开教材的目录框架，由 AI 综合 IAEA、NEA、DOE-NE、中国核学会等公开资料整理编写，供学习参考之用。
>
> ⚠️ **免责声明**：本书为基于公开资料的科普性整理稿，不构成工程设计与商业决策依据。所有技术参数以各国监管机构与厂商公开文件为准。

## 编者简介

**李佳伦**　本书编者。本书内容基于公开教材的目录框架，由 AI 综合国际原子能机构（IAEA）、经济合作与发展组织核能署（OECD/NEA）、美国能源部核能办公室（DOE-NE）、中国核学会等机构与厂商的公开资料整理编写而成，仅供学习参考。

## 阅读建议

- **核工程背景读者**：可按章节顺序通读，关注第二部分 IPWR 技术细节。
- **政策/经济背景读者**：建议先读第 1、3、10、11、20 章。
- **快速了解者**：先读第 1、2 章，再按国家章节（第 14–19 章）快速浏览。
