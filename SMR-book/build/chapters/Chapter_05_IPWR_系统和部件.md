# IPWR 系统和部件

> **核心命题**　IPWR 通过"压力容器内一体化"重新组织了反应堆冷却剂系统（RCS），同时革新了蒸汽发生器、主泵、稳压器、安全壳等关键部件的设计。本章梳理这些部件的特征、技术挑战与发展趋势。

---

## 引言

传统 PWR 的反应堆冷却剂系统（RCS）由**压力容器 + 多个 SG + 稳压器 + 主泵 + 大量管道**组成，这是"分散式" NSSS 的标志。IPWR 把这一切装入压力容器内（或紧贴容器），形成**一体化 NSSS**：

```
                ┌─ 顶盖（含稳压器内胆）
                │
压力容器 ──────│── SG（直管或螺旋管，环绕堆芯）
一体化         │  
                │── 堆芯
                │
                └─ 底封头（主泵或管路连接）
```

本章先讲一体化部件（堆芯、SG、稳压器、主泵、压力容器本身），再讲相连系统部件（二回路、安全壳、辅助系统、安全系统）。

## 一体化部件

### 反应堆压力容器（RPV）

**主要特征**：

- 直径 3–6 m，高度 12–25 m，壁厚约 150–250 mm；
- 顶盖 + 筒体 + 下封头三段；
- 材料为低合金钢（SA-508 Gr.3 Cl.1/2）+ 不锈钢堆焊层；
- 顶盖开口：用于换料、控制棒驱动机构、仪表贯穿件；
- 寿期：60 年，受快中子注量（EOL fluence）限制。

**IPWR 特有挑战**：

- **整体锻件**：尽量减少纵向焊缝（"整体锻造筒体"），降低 ISI 工作量；
- **CRDM 穿越顶盖**：因 SG 在堆芯上方，CRDM 必须通过 SG 区域才能驱动堆芯控制棒，导致**CRDM 极长**（如 NuScale、ACP100）或采用**侧向驱动**（SMART）；
- **高温疲劳**：低合金钢 + 316 不锈钢堆焊层在温度瞬变下产生热棘轮和疲劳；
- **快中子注量**：堆芯小但功率密度不低，RPV 内壁快中子注量需要控制（在堆芯筒体区加屏蔽件）。

### 蒸汽发生器（SG）

**IPWR 中 SG 的关键挑战**：

1. 紧凑：要在压力容器与堆芯之间的环形空间内布置；
2. 高效：单台功率 50–300 MWt；
3. 可靠：管束泄漏检测困难，更换困难；
4. 流动稳定性：自然循环或强制循环下，二回路侧两相流必须稳定。

**主要形式**：

- **螺旋管 SG**：NuScale、SMART、CAREM、ACPR50S 等；管束螺旋缠绕，紧凑且热膨胀自补偿；
- **直流直管 SG（OTSG）**：ACP100、mPower 等；二回路水一次通过即过热，结构简单、控制响应快，但对水质要求高；
- **U 形管再循环式 SG**：在 IPWR 中较少见（因占用空间大）。

**设计要点**：

- **管材**：Inconel 690 TT（耐一次水 SCC），Incoloy 800（SMART），钛（海水冷却侧）；
- **管径**：典型 φ12–20 mm；
- **管壁厚**：1.0–1.5 mm；
- **防振设计**：螺旋管束需防流动诱发振动（FIV）；
- **隔离**：每个 SG 配独立隔离阀，便于堵塞泄漏的子模块。

### 稳压器（PZR）

**IPWR 中稳压器特征**：

- 通常**集成于压力容器顶盖内部**，通过"喷雾管 + 加热器"控制一回路压力；
- 部分设计（如 CAREM-25）采用**自加压（Self-pressurization）**：利用一回路顶部汽空间自然形成饱和状态，无须喷雾；
- **加热器**：电加热 50–500 kW；
- **液位控制**：通过化学容积系统（CVCS）补/排冷却剂。

集成式稳压器的优点是消除外部喷雾管线，减少管道接口；缺点是稳压器容积受限，压力波动幅度相对较大。

### 反应堆冷却剂泵（RCP）

**主要类型**：

| 类型 | 优点 | 缺点 | 应用 |
|---|---|---|---|
| **屏蔽泵（Canned Motor Pump）** | 无轴封泄漏、寿期长、维护少 | 效率低（60–70\%）、成本高 | ACP100、SMR-300、AP1000 |
| **湿定子泵** | 类似屏蔽泵，结构更紧凑 | 同上 | SMART |
| **轴封泵** | 效率高（85\%） | 轴封泄漏风险、需轴封注水 | 传统 PWR，IPWR 少用 |
| **无泵（自然循环）** | 极致简化 | 功率上限低（< 300 MWt） | NuScale、BWRX-300、CAREM-25 |

**IPWR 中泵的特点**：

- **内置式**：直接装在压力容器内部或与容器焊成一体（如 NuScale 无泵，但 SMART 有外置屏蔽泵）；
- **冗余**：通常 2–4 台泵，N+1 或 N+2 容错；
- **惰转**：失去电源后惯性飞轮提供短期惯性流量；
- **检修**：内置泵无法在线检修，依赖"长寿命设计 + 整体更换"策略。

### 控制棒驱动机构（CRDM）

- **磁力提升（步进式）**：传统 PWR 标配，在 IPWR 中因顶盖高需加长驱动杆；
- **磁阻马达（齿轮减速）**：通过旋转带动齿条，长度短、可靠性好；
- **内部水力驱动**：如 CAREM-25 的二级冷却剂系统；
- **永磁电机（直接驱动）**：开发中。

CRDM 须穿过 SG 区域才能到达堆芯顶部，因此 IPWR 中 CRDM 经常是"长杆 + 顶部承压壳"结构。安装、检修、抗震分析是设计重点。

## 相连的系统部件

### 二回路系统

- **汽轮机**：饱和蒸汽（直管 SG）或微过热（OTSG）；典型参数 6–8 MPa，280–310 ℃；
- **汽水分离再热器（MSR）**：饱和蒸汽机组必备；
- **凝汽器**：钛管板，海水/淡水/空冷；
- **给水系统**：凝泵 + 给水泵（多级离心）+ 给水加热器；
- **给水流量控制**：随反应堆功率联动，IPWR 中控制响应要求高（OTSG 尤其敏感）。

### 安全壳与厂内布置

- **钢制安全壳**：NuScale 用"σ = 钢制容器 + 水池冷却"的非能动安全壳冷却系统；
- **混凝土 + 钢内衬**：ACP100、SMART 等；
- **地下埋设**：多数 IPWR 把反应堆厂房埋于地下，减少飞机撞击、外部事件威胁；
- **多机组共用大厅**：12 台模块共享一个厂房、一个控制室。

### 辅助系统

- **化学容积系统（CVCS）**：补水、净化、硼酸调配；
- **硼回收系统**：与大型 PWR 类似，但容量小；
- **设备冷却水系统（CCWS）**：安全级冷却；
- **重要厂用水系统（ESW）**：最终热阱；
- **乏燃料水池**：与大型 PWR 共享或独立；
- **废物处理系统**：液体废物、气体废物、固体废物；IPWR 因乏燃料量少，废物系统简化。

### 专设安全系统

IPWR 的专设安全系统显著简化：

- **应急堆芯冷却系统（ECCS）**：因无 LBLOCA，仅需应对 SBLOCA；多采用"被动式安全注入箱 + 蓄压箱"或"被动余热排出（PRHR）"；
- **安全壳冷却**：钢制安全壳 + 顶部水池（被动蒸发/对流冷却，72 h 无需电源）；
- **二次侧冷却**：通过 SG 辅助给水（AFW）实现 PRHR；
- **可居留性系统**：控制室通风、应急电源（柴油 + 蓄电池）。

### 典型安全分级

按 ASME BPVC 或 RCC-M、GB/T 16769：

- **安全 1 级（SC-1）**：RPV、SG 一次侧、稳压器；
- **安全 2 级（SC-2）**：SG 二次侧、主蒸汽管道至隔离阀；
- **安全 3 级（SC-3）**：CVCS、ECCS、AFW；
- **非核级**：常规岛、汽轮机、电气系统。

## 发展趋势

1. **无泵自然循环**是 IPWR 设计的"激进派"，NuScale、BWRX-300、CAREM 已落地，未来可能扩展到更大功率（200–400 MWe）；
2. **OTSG 替代再循环 SG**：紧凑、控制快，但对水质和管理要求高，趋势是采用；
3. **整体锻件 RPV**：减少焊缝、降低 ISI 工作量，已成为新设计标配；
4. **CRDM 简化**：永磁直驱、内置水力驱动有望取代传统磁力提升；
5. **数字孪生与传感**：植入式传感器（如堆芯温度、流量、振动监测）将改变运行与维修模式（见第 6 章）；
6. **3D 打印关键部件**：燃料定位格架、SG 管板局部结构开始试用增材制造；
7. **共享系统 + 多机组冗余**：12 台 NuScale 模块共享一个控制室、辅助厂房，可显著降低单位投资。
