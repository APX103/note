# 韩国 SMR 技术

> **核心命题**　韩国 SMR 技术以 **SMART** 一体化压水堆为旗舰，由韩国原子力研究院（KAERI）主导开发，是**全球首个获设计认证的陆基一体化压水堆**（2012 年），主要面向海水淡化与供热市场。除 PWR 外，韩国也发展了钠冷（PGSFR）与超高温堆设计。

---

## 引言

韩国是核电大国，目前运行 25 台大型 PWR（APR1400、OPR1000、WH-60 等），并出口了阿联酋 Barakah 4 台 APR1400。在 SMR 领域，KAERI 自 1997 年开始研发 **SMART**（System-integrated Modular Advanced ReacTor），目标是：

- 海水淡化 + 电力 + 区域供热；
- 出口中东、东南亚、南美；
- 国际科技合作（与沙特 KA.CARE 等）。

韩国 SMR 战略的特点：

- **政府主导 + 产业出口**：MOTIE（产业通商资源部）/ KHNP（韩国水力核电）/ KAERI 协同；
- **海水电结合**：SMART 专门设计用于海水淡化；
- **依托大型 PWR 工业基础**：Doosan、KEPCO E\&C 等供应链；
- **国际合作 + 出口**：与沙特、马来西亚、印尼等合作。

## 压水堆 SMR 研究历史

### SMART 起步（1997–2006）

- 1997 年 KAERI 启动 SMART 设计；
- 目标：330 MWt / 90 MWe + 海水淡化 40,000 m³/d；
- 一体化 PWR：堆芯、SG、稳压器、主泵集成于同一压力容器；
- 关键技术：
  - 螺旋管 SG（紧凑、热膨胀自补偿）；
  - 4 台屏蔽泵（湿定子）；
  - 自加压稳压器；
  - 自然循环冷却（部分负荷）；
  - 8 个非能动安全系统（PRHRS、ECCS、安全壳冷却）。

### SMART 设计认证（2007–2012）

- 2007 年提交韩国核安全委员会（NSSC / KINS）申请；
- 2012 年获设计认证（**全球首个陆基一体化 PWR 设计认证**）；
- 同期建造 1:1 比例的非能动系统验证装置（FOTES）。

### SMART 海水淡化示范（2010s）

- 韩国本土曾计划 SMART 海水淡化示范项目（Gijang）；
- 因经济性、政治原因推迟；
- 2015 年与沙特 KA.CARE 签署 SMART 预可行性研究（K.A.CARE-SMART）。

### SMART 与国际市场

- 沙特：尚未首堆；
- 阿联酋：Barakah 已选 APR1400，未来 SMR 待考虑；
- 马来西亚、印尼、孟加拉国、泰国：评估中；
- 哈萨克斯坦、乌兹别克斯坦：海水淡化 + 电力；
- 与中国、俄罗斯 SMR 形成竞争。

### SMART-50 / SMART-100 升级

- 2020 年代，KAERI 推出 SMART 升级版：
  - **SMART-50**：50 MWe，专注海外出口；
  - **SMART-100**：100 MWe，扩大单机功率，提升经济性；
- 改进设计：增加自然循环能力、延长换料周期（≥36 个月）、改善 SG 检修可达性。

## 其他堆型 SMR 研究历史

### 钠冷快堆 PGSFR

- **Prototype Gen-IV Sodium-cooled Fast Reactor（PGSFR）**：
  - 150 MWe 金属燃料 SFR；
  - KAERI 主导，DOE（美国）合作；
  - 借鉴 EBR-II、Integral Fast Reactor 经验；
  - 计划 2028 年首堆，但因预算、政治因素推迟。

### 超高温气冷堆

- 韩国原子力研究院（KAERI）+ 韩国电力（KEPCO）评估过 VHTR；
- 主要用于制氢；
- 由于 HTR-PM 在中国已示范，韩国转向观望与合作。

### 微型反应堆

- 韩国在 R\&D 阶段：
  - **U-Battery**（与英国 URENCO 合作评估）；
  - **KAERI Microreactor**：金属燃料 + 热管。

## SMART IPWR 设计特点

### 基本参数

| 参数 | 数值 |
|---|---|
| 热功率 | 330 MWt |
| 电功率 | 90 MWe（约） |
| 海水淡化 | 40,000 m³/d |
| 一回路压力 | 15 MPa |
| 一回路温度 | 310 ℃ |
| 燃料组件 | 57 个 17×17 PWR 组件 |
| 富集度 | ≤ 4.95\% |
| 换料周期 | 36 个月 |
| 设计寿命 | 60 年 |

### 一体化 NSSS

- 堆芯 + SG（8 台螺旋管）+ 稳压器 + 屏蔽泵（4 台）集成于压力容器；
- 消除大破口 LOCA；
- 一回路装量大、自然循环能力强。

### 安全系统

- **被动余热排出系统（PRHRS）**：36 小时无须电源；
- **被动安全注入系统**：依靠重力 + 气压；
- **被动安全壳冷却**：通过自然循环；
- 应急计划区（EPZ）目标 400 m（基于源项分析）。

### 海水淡化接口

- 二回路抽汽供 MED 海水淡化；
- 淡化水与电力可按需求调整；
- 与电网耦合：电力 + 水双重产出。

## SFR 和 VHTR 设计特点

### PGSFR

- 150 MWe，金属燃料（U-10Zr）；
- 钠冷，3 个一回路 + 3 个二回路（池式）；
- 干式后处理（Pyroprocessing）配套；
- 主要目标：闭式燃料循环、长寿命核素嬗变；
- 争议：韩国是否需要快堆（铀资源不丰富）？是否与美国 123 协议冲突？

### VHTR / 制氢

- 高温气冷堆：目标 700–950 ℃；
- 用于制氢（SOEC、热化学 S-I 循环）；
- 主要 R\&D 机构：KAERI、POSTECH、KAIST。

## 发展趋势

1. **SMART 出口突破**：争取沙特、印尼、马来西亚、哈萨克斯坦等市场首堆；
2. **SMART-50 / 100 升级**：提升单机功率 + 自然循环能力；
3. **海上浮动核电站**：基于 SMART 设计海上版本；
4. **PGSFR 复活**：随着韩国核电战略调整，PGSFR 可能重新获资金；
5. **微型反应堆**：远程岛屿、矿区供电；
6. **与中国、俄罗斯竞争**：在东南亚、中东、中亚形成三方竞争；
7. **与俄罗斯、中国合作 + 竞争并存**：朝鲜半岛能源合作、远东合作。
