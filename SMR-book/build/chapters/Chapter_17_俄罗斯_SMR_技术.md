# 俄罗斯 SMR 技术

> **核心命题**　俄罗斯是全球**最先实现 SMR 商业运行**的国家——2019 年投运的浮动核电站 **Akademik Lomonosov**（KLT-40S，2 × 35 MWe），以及正在 Seversk 建造的 **BREST-OD-300** 铅冷快堆。Rosatom 旗下 OKBM、NIKIET、AKME 等设计机构开发了多种 SMR，是 SMR 出口市场的主要玩家。

---

## 引言

俄罗斯（苏联）在核能领域积累了深厚底蕴：

- 全球第二大核电装机（运行 11 台大型核电站，多个堆型）；
- 拥有完整核燃料循环（铀矿、转化、富集、燃料制造、后处理、废物管理）；
- 强大的反应堆设计能力（OKBM Afrikantov、NIKIET、Dollezhal 等）；
- 海军核动力（潜艇、破冰船）支持小型反应堆技术积累；
- 国家主导（Rosatom 集团）+ 出口（Rosatom Overseas）。

俄罗斯 SMR 战略的特点：

- **军民融合**：破冰船、潜艇反应堆技术向民用 SMR 转化；
- **海上优先**：浮动核电站 + 破冰船是首要市场；
- **快堆引领**：BREST-OD-300 铅冷快堆是 PRORYV（突破）项目核心；
- **出口导向**：向亚非拉发展中国家推广。

## OKBM SMR 技术

OKBM Afrikantov（位于 Nizhny Novgorod）是俄罗斯主要反应堆设计机构，开发的 SMR 包括：

### KLT-40S（浮动核电站）

- **类型**：紧凑型压水堆，源自破冰船反应堆；
- **功率**：2 × 35 MWe；
- **载体**："Akademik Lomonosov"号浮动核电站（FNPP）；
- **首堆**：2019 年投运，**全球首座商业浮动核电站**；
- **厂址**：Pevek（楚科奇半岛），为俄罗斯远东地区提供电力 + 区域供热；
- **意义**：证明海上 SMR 商业可行性。

### RITM-200（破冰船 / 浮动核电站）

- **类型**：一体化 PWR，第四代破冰船反应堆；
- **功率**：2 × 50 MWe（破冰船）/ 2 × 50 MWe（陆上版本）；
- **应用**：
  - **Arktika 级破冰船**（已下水 3 艘：Arktika、Sibir、Ural）；
  - **Yakutiya、Chukotka** 等；
  - **陆上 SMR 版本**：1–2 模块陆地部署；
- **优势**：紧凑、效率高、寿期长；
- **目标**：未来俄罗斯新建浮动核电站将基于 RITM-200S（陆上版本），单机 55 MWe。

### ABV-6M / ABV-7A

- **类型**：紧凑型 PWR；
- **功率**：6–12 MWe；
- **应用**：小规模浮动核电站、远东偏远地区；
- **状态**：未首堆，待市场驱动。

### UNITHERM

- **类型**：高温气冷堆概念；
- **功率**：30 MWt / 6 MWe；
- **应用**：区域供热 + 小型电力；
- **状态**：概念设计阶段。

### KLT-40S 改进版

- OKBM 正在开发 KLT-40S 的后继版本，更紧凑、更长寿期（>10 年免换料）。

## AKME SMR 技术

**AKME Engineering**（俄罗斯私人工程公司，与 Rosatom 合作）开发 **SVBR-100**：

### SVBR-100（铅铋共晶冷却）

- **类型**：铅铋共晶（LBE）冷却快堆；
- **功率**：100 MWe；
- **燃料**：铀钚氮化物（或氧化物）；
- **特点**：源自阿尔法级潜艇反应堆技术；
- **优势**：常压运行、热效率高、安全性好；
- **状态**：原计划在 Dimitrovgrad 建造原型堆（RIAR），但因融资、技术问题，进度大幅推迟；
- 2018 年后项目基本停滞，未来不确定。

## NIKIET SMR 技术

**NIKIET**（莫斯科动力工程研究院，Dollezhal）主要开发 **BREST-OD-300**：

### BREST-OD-300（铅冷快堆）

- **类型**：铅冷快堆（LFR）；
- **功率**：300 MWe / 700 MWt；
- **燃料**：铀钚氮化物（UN-PuN）；
- **冷却剂**：液态铅；
- **核心特征**：
  - 铅冷常压运行，消除大破口 + 烧毁风险；
  - 氮化物燃料导热系数高、密度高；
  - 中子学特性：U-Pu 平衡，**反应性空泡系数为负**，固有安全；
  - 配套**干法后处理 + 闭式燃料循环**（PRORYV 项目）；
- **厂址**：俄罗斯 Seversk（西伯利亚，前核武器基地）；
- **建设进度**：
  - 2018 年开始土建；
  - 2021 年反应堆厂房基础完成；
  - 目标 2026–2027 年首次临界；
  - **PRORYV 项目核心**：实现"闭式燃料循环示范"；
- **意义**：俄罗斯在第四代反应堆领域的旗舰项目。

### BREST-GREK / BR-1200

- BREST 系列放大版，1200 MWe；
- 远期规划，需先验证 BREST-OD-300。

### VPBR-300

- NIKIET 设计的气冷快堆概念；
- 处于概念设计阶段。

## 俄罗斯 SMR 部署情况

| 项目 | 类型 | 状态 |
|---|---|---|
| Akademik Lomonosov | KLT-40S 浮动 | 2019 运行 |
| Arktika / Sibir / Ural 破冰船 | RITM-200 | 2019–2022 运行 |
| Yakutiya / Chukotka 破冰船 | RITM-200 | 建造中 |
| BREST-OD-300 | LFR | 建造中（Seversk，目标 2026–2027） |
| SVBR-100 | LBE | 停滞 |
| ABV-6M | PWR | 设计 |
| RITM-200S 陆上 | IPWR | 设计 |
| 出口市场 | 多 | 评估中 |

### 出口项目

- **俄罗斯远东 + 北极**：本国能源基础设施；
- **出口浮动核电站**：曾与印尼、马来西亚、中国（渤海）、智利、苏丹、佛得角等评估；
- **陆上 SMR 出口**：与古巴、越南、埃及、孟加拉国、哈萨克斯坦、乌兹别克斯坦等评估；
- **面临制裁**：俄乌冲突后，西方制裁影响 Rosatom 出口（尽管俄罗斯核能整体未被全面制裁）。

## 未来发展趋势

1. **BREST-OD-300 投运**（2026–2027）：俄罗斯第四代反应堆旗舰；
2. **新一代浮动核电站**：RITM-200S 替代 KLT-40S；
3. **北极 SMR 集群**：俄罗斯北极开发战略需要大量小型核电；
4. **破冰船升级**：更多 RITM-200 破冰船下水；
5. **与中国合作 + 竞争**：浮动核电站、海上 SMR、快堆技术交流；
6. **亚洲、非洲、拉美出口**：受俄乌冲突影响，部分项目推迟或转移；
7. **闭式燃料循环**：BREST + Pyroprocessing 示范；
8. **数字化、自动化**：远东、北极无人值守运行需要远程监控。

## 结论

俄罗斯 SMR 战略的特征是**军民融合 + 国家主导 + 出口导向**。KLT-40S 已商业运行，BREST-OD-300 是全球第四代反应堆前沿项目，RITM-200 是新一代破冰船与浮动核电站的核心。受俄乌冲突与制裁影响，俄罗斯 SMR 出口前景面临不确定性，但其技术能力依然领先。
