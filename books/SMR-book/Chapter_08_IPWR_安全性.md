# 第 8 章　IPWR 安全性

> **核心命题**　IPWR 通过**设计安全（Design Safety）**理念把安全特性"嵌入"硬件本身：消除大破口、自然循环冷却、低功率密度、负反应性反馈，再叠加**纵深防御**与**概率安全分析（PSA/PRA）**，使堆芯损坏频率（CDF）和早期大量释放频率（LERF）显著低于大型压水堆。

---

## 8.1　引言

核安全的演进经历了四个阶段：

1. **能动安全**（1950s–1970s）：依靠泵、阀门、应急电源等能动部件；
2. **非能动安全**（1980s–）：依靠重力、自然循环、压缩气体等非能动原理；
3. **固有安全**（1990s–）：通过物理规律本身消除事故可能（如 IPWR 消除 LBLOCA）；
4. **设计安全**（2000s–）：将上述三者与纵深防御（DiD）系统化融合。

IPWR 是这一演进的典型产物。本章按"安全理念 → 试验验证 → 概率安全分析 → 安保措施 → 趋势"五个方面展开。

## 8.2　安全实现方法：能动、非能动、固有和设计安全

### 8.2.1　能动安全（Active Safety）

依靠外部能源（电、压缩空气）驱动的安全系统：

- 应急堆芯冷却系统（ECCS）；
- 安全壳喷淋系统；
- 应急柴油发电机；
- 辅助给水系统。

优点：响应快、可干预；缺点：依赖电源、泵、阀，存在共因失效风险。

### 8.2.2　非能动安全（Passive Safety）

依靠自然力（重力、自然循环、压缩气体、蒸发、对流）：

- 重力应急冷却（GDCS、IRWST）；
- 自然循环冷却（PRHR HX）；
- 非能动安全壳冷却（PCS）；
- 蓄压箱（CMT、Accumulator）。

AP1000 是大规模应用非能动安全的代表。IPWR 把这一思路进一步发挥：

- **全功率自然循环**（NuScale、BWRX-300）；
- **被动余热导出**：72 小时甚至 30 天内无须操纵员干预或交流电源；
- **被动安全壳冷却**：钢制安全壳 + 顶部水池。

### 8.2.3　固有安全（Inherent Safety）

通过物理规律本身消除事故可能性，而不是依靠附加系统应对：

- **消除 LBLOCA**（IPWR 无大管道）；
- **TRISO 燃料耐 1600 ℃**（HTR-PM、Xe-100）；
- **负反应性温度反馈**保证反应堆不会功率发散；
- **铅冷堆大气压运行**避免压力容器破裂大泄漏。

### 8.2.4　设计安全（Design Safety / Safety-by-Design）

把上述理念与纵深防御（Defense-in-Depth, DiD）系统化集成：

| DiD 层级 | 目标 | IPWR 措施 |
|---|---|---|
| L1 | 防止异常 | 高质量设计与制造、严格运行规程 |
| L2 | 控制异常 | 控制系统、自动降功率、限制保护 |
| L3 | 控制事故 | RPS、ESFAS、非能动 ECCS |
| L4 | 严重事故管理 | SAMG、安全壳过滤排放 |
| L5 | 应急响应 | EPZ、应急计划、外部支援 |

IPWR 的特殊之处在于 L1（设计）已经"内建"了大量 L3/L4 能力（消除 LBLOCA、低功率密度等），从而显著降低 CDF 和 LERF。

## 8.3　SMR 系统和部件试验

新设计的 SMR 必须经过严格的试验验证（V&V）：

### 8.3.1　试验层次

1. **基础试验**：材料、燃料、热工水力基础数据；
2. **部件试验**：泵、阀、SG、CRDM 单件试验；
3. **系统试验**：在缩比整体试验装置（ISTF）上模拟整个 RCS；
4. **堆内辐照试验**：燃料在研究堆中辐照，验证达到目标燃耗；
5. **示范堆**：首堆本身就是最大试验。

### 8.3.2　典型整体试验装置

| 装置 | 国别 | 用于 | 比例 |
|---|---|---|---|
| **OSU-MASLWR** | 美国 Oregon State Univ. | NuScale 自然循环 | 1:3 长度、1:254 体积 |
| **PUMA / APEX** | 美国俄勒冈州立大学 | AP1000 / SMR | 缩比 |
| **FOTES / VISTA** | 韩国 KAERI | SMART | 1:1 部件、缩比整体 |
| **PPTF** | 中核武汉所 | ACP100 | 1:1 部件 |
| **SPES-2** | 意大利 | AP600 | 整体 |

这些装置用于：
- 验证设计瞬态、事故工况下的热工水力行为；
- 为系统分析程序（RELAP5、TRACE、CATHARE）提供验证数据；
- 培训操纵员、运行人员。

### 8.3.3　V&V 与监管对话

监管机构（NRC、CNSC、CNSA、SSC、Rostekhnadzor）要求：

- **设计基准事故（DBA）分析**：证明接受准则满足；
- **超设计基准事故（BDBA）分析**：证明纵深防御充足；
- **严重事故分析**：证明安全壳完整性、源项可控；
- **概率安全分析（PSA）**：第 1 级 + 第 2 级（部分第 3 级）。

## 8.4　PSA/PRA

### 8.4.1　PSA 分级

- **第 1 级 PSA**：评估堆芯损坏频率（CDF）；
- **第 2 级 PSA**：评估安全壳失效、放射性释放（LERF、源项）；
- **第 3 级 PSA**：评估厂外剂量、健康风险、社会经济影响；
- **LPSD PSA**：低功率与停堆模式；
- **内部 / 外部事件**：内部事件（瞬态、LOCA、ATWS）+ 外部事件（地震、洪水、火灾、飞机撞击）。

### 8.4.2　IPWR 的 PSA 结果

IPWR 因消除 LBLOCA、自然循环冷却、低功率密度等特征，CDF 通常显著低于大型 PWR：

| 机型 | CDF（堆-年） | LERF（堆-年） |
|---|---|---|
| 大型 PWR（参考） | 1×10⁻⁵ ~ 1×10⁻⁴ | 1×10⁻⁶ |
| NuScale（设计目标） | < 1×10⁻⁸ | < 1×10⁻⁹ |
| BWRX-300 | < 1×10⁻⁷ | < 1×10⁻⁸ |
| ACP100 | < 1×10⁻⁶ | < 1×10⁻⁷ |

注：实际值以厂商提交监管文件为准。

### 8.4.3　PSA 方法

- **事件树（ETA）/ 故障树（FTA）**：传统方法；
- **IDP（Integrated Deterministic-Probabilistic，确定-概率融合）**：将确定性事故分析与概率安全分析结合；
- **数字化 PSA 平台**：CAFTA、RiskSpectrum、SAPHIRE；
- **人因可靠性分析（HRA）**：SPAR-H、ATHENA、THERP。

### 8.4.4　PSA 的作用

- 设计阶段：识别"薄弱环节"，引导改进；
- 许可证阶段：监管要求的提交文件；
- 运行阶段：风险指引型维修（Risk-Informed Maintenance）；
- 事故管理：SAMG 制定依据。

## 8.5　安保措施

核安全（Safety）与核安保（Security）是两个独立但相关的领域：

- **Safety**：防止事故，关注设备故障、人因、外部自然事件；
- **Security**：防止恶意行为，关注恐怖袭击、内部威胁、网络攻击；
- **Safeguards**：防止核材料扩散，关注材料衡算、保障监督（见第 9 章）。

合称 **3S（Safety, Security, Safeguards）**。

### 8.5.1　安保威胁

- 飞机撞击（"9·11"之后）；
- 车载炸弹；
- 武装袭击（设计基准威胁 DBT）；
- 内部威胁（恶意、误操作）；
- 网络攻击（Stuxnet 之后成为重点）；
- 无人机（小型化、低成本、易获取）。

### 8.5.2　安保设计

- **物理保护（PP）**：分区（控制区、保护区、要害区）、防爆、防入侵；
- **要害屏障（Vital Barrier）**：反应堆厂房、控制室；
- **入侵检测系统（IDS）**：红外、视频、震动；
- **武装响应**：厂内 + 厂外；
- **网络安全**：分区隔离、入侵检测（IDS/IPS）、零信任架构；
- **内部威胁程序（Insider Threat Program）**：人员背景、行为监测；
- **DBT 设计**：按国别监管要求，确定设计基准威胁。

### 8.5.3　IPWR 的安保优势

- **地下埋设**：许多 SMR 反应堆厂房在地下，防飞机撞击、车载炸弹；
- **模块化运输与现场组装周期短**：减少建造期暴露；
- **乏燃料整体返回**：现场不留高放废物；
- **多机厂址纵深**：单模块受袭不影响其他模块。

## 8.6　未来发展趋势

1. **风险指引型监管（Risk-Informed Performance-Based Regulation）**：从规定式（prescriptive）走向基于性能；
2. **应急计划区（EPZ）缩小**：基于源项减少和 CDF 降低，部分 SMR 目标 EPZ = 厂址边界（如 NuScale）；
3. **共因故障对抗**：通过多样性平台、软件多样性，降低 SWCCF；
4. **数字孪生 + PSA**：实时风险监测（Risk Monitor）；
5. **无人值守 + 远程监控**：安保与安全融合；
6. **国际监管协调**：MDEP、CNRA、CSNI 等多边合作平台推动 SMR 监管趋同；
7. **严重事故机理研究**：IPWR 燃料温度低、衰变热小，严重事故机理与大型 PWR 有差异，需独立研究。
