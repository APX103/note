# SMR 人机界面（HSI）

> **核心命题**　SMR 的多机组共享控制室 + 高自动化 + 无人值守运行愿景，使人机界面（HSI）从"提供信息"转向"管理认知负荷"。HSI 设计的核心目标变为：在操纵员数量减少 5–10 倍的情况下，仍能保持甚至超过大型核电站的人因可靠性。

---

## 引言

人机界面（Human-System Interface, HSI）是操纵员与电站之间的中介。传统大型核电站主控室通常有 4–8 名操纵员，盯着数千个报警灯、模拟仪表、记录仪。三里岛事故（1979）后，HSI 设计进入"以人为中心"的时代，强调：

- **清晰的信息层次**（系统 → 子系统 → 部件）；
- **报警分级**（紧急、警告、提示）；
- **任务支持**（程序化操作 SOP）；
- **错误预防**（联锁、防误操作）。

SMR 在此基础上引入新挑战：

- **多机组监督**：1 名操纵员监督 4–12 个反应堆模块；
- **远程 / 无人值守**：部分 SMR 设计追求"无人值守运行"；
- **更高自动化**：从启堆到停堆的全过程高度自动化；
- **更小操纵员队伍**：单堆人员从百人降至数十人。

这些挑战要求 HSI 进行范式转变。

## 新核电站对 HSI 的要求

按 NUREG-0711、NUREG-0700 等监管文件，新核电站 HSI 应满足：

1. **任务分析驱动**：基于操作任务（如启堆、停堆、应对事故）反推信息需求；
2. **可用性**：信息可读、可达、可理解；
3. **情境感知**：操纵员随时了解电站状态；
4. **冗余与多样性**：硬接线、模拟、数字多种手段并存；
5. **错误容忍**：避免单一错误导致事故；
6. **网络安全**：抵御外部攻击；
7. **可维护性**：HMI 软件、报警阈值、画面布局易于修改；
8. **可培训**：模拟机配套，初始与持续培训。

针对 SMR，新增要求：

- **多机组协同**：跨模块信息整合、冲突检测；
- **远程支持**：与远程专家中心数据交互；
- **自动化管理**：操纵员监督自动化决策（"自动化团队"）；
- **超长免操纵时间**：事故后 7 天、30 天内无须操纵员干预（部分设计目标）。

## 当前核电站的 HSI 现状

现代大型核电站（如 AP1000、EPR、华龙一号）的 HSI 已全面数字化：

- **大屏幕概览显示**：电站总状态一览；
- **工作站 + 触屏**：操纵员主要操作界面；
- **报警管理系统**：智能报警过滤（如"报警雪崩"抑制）；
- **计算机化规程（CPS）**：电子化 SOP，与状态参数联动；
- **安全级硬接线盘**：用于事故后停堆、安全注入；
- **模拟机培训**：每年 200+ 小时强制模拟机培训。

但仍存在不足：

- 报警数量过多（数千到数万条），关键报警易被淹没；
- 信息分散在不同系统，操纵员需要"拼图"；
- 自动化水平有限，启停过程操纵员任务繁重。

## HSI 目标和人因挑战

### 目标

1. **降低操纵员认知负荷**；
2. **保持高水平情境感知**；
3. **减少人因错误概率（HEP）**；
4. **支持跨班次知识传递**；
5. **支持远程与无人值守场景**。

### 挑战

- **监督自动化陷阱**：操纵员过度信任自动化，丧失技能（"out-of-the-loop"）；
- **多机组认知过载**：1 个操纵员监督 12 个反应堆，注意力分配困难；
- **新型故障模式**：软件 bug、网络攻击、传感器漂移带来的"假报警"；
- **培训成本**：每种机型需独立模拟机；
- **认证**：人因可靠性分析（HRA）方法（如 SPAR-H、ATHENA）需要适应 SMR 场景。

## HSI 核工业应用

近年来，核工业 HSI 应用越来越广泛：

- **AP1000 / 华龙一号**：全面数字化主控室；
- **NuScale**：12 模块共享主控室，1–2 名操纵员；
- **GE Hitachi BWRX-300**：极简主控室；
- **海上浮动核电站**：远程监控 + 短期值守；
- **空间核电源 / 深海核电源**：极端无人值守场景。

这些应用推动了 HSI 从"显示和控制"向"决策支持"演进。

## HSI 选择

HSI 选择涉及**信息显示**、**控制输入**、**反馈机制**、**辅助工具**等多方面，需在以下维度权衡：

| 维度 | 选项 | 权衡 |
|---|---|---|
| 显示技术 | 大屏 / 工作站 / 移动设备 / AR/VR | 信息密度 vs. 注意力 |
| 输入方式 | 触屏 / 鼠标键盘 / 语音 / 手势 | 速度 vs. 防误操作 |
| 报警 | 听觉 / 视觉 / 触觉 | 注意力分配 |
| 规程 | 纸质 / 计算机 / AR | 灵活性 vs. 可靠性 |
| 自动化程度 | 手动 / 半自动 / 全自动 | 人因 vs. 系统鲁棒性 |

## HSI 操作域

按 IEC 60987、NUREG-0711，HSI 涉及：

- **主控室（MCR）**：正常运行与事故响应核心；
- **辅助控制点（Remote Shutdown Room）**：MCR 不可用时启用；
- **技术支持中心（TSC）**：事故后专家支持；
- **应急运行设施（EOF）**：场外协调；
- **远程监控中心**：跨电站专家协同。

SMR 引入**远程监控中心**概念，多家 SMR 电站共享一个专家中心，操纵员 + 专家协同处理异常。

## HSI 技术分类（一）：显示与可视化

- **概览显示**：电站总状态、关键参数、安全状态彩色编码；
- **系统画面**：P\&ID 风格，设备状态、流量、温度；
- **趋势曲线**：历史与实时数据，含预测；
- **报警清单**：按优先级、时间、系统分类；
- **3D 可视化**：堆芯功率分布、辐射场、设备位置；
- **AR/VR**：维修指导、培训、远程协助。

## HSI 技术分类（二）：决策支持与自动化

- **计算机化运行规程（CPS）**：电子 SOP，逻辑分支自动判断；
- **智能报警**：基于状态机与机器学习的报警抑制；
- **故障诊断助手**：基于知识图谱、案例推理；
- **预测性维护**：基于传感器数据 + ML；
- **决策支持系统**：可选方案 + 风险评估；
- **自动化代理人（Agent）**：在限定范围内自主执行任务。

> **重要原则**：自动化决策不得进入安全级（Class 1E）功能链。AI 仅作为决策支持，最终决策由操纵员或硬接线保护系统做出。

## HSI 设计和实施策略

参考 NUREG-0711 *Human Factors Engineering Program Review Model*，HSI 设计应遵循：

1. **规划**：定义 HFE 范围、角色、计划；
2. **运行经验审查**：吸取现有电站经验反馈；
3. **功能需求分析**：基于运行情景定义功能；
4. **任务分析**：分解每个任务到步骤、信息、控制需求；
5. **人员配置与资质**：确定操纵员数量、技能；
6. **人因可靠性分析（HRA）**：估算 HEP，反馈设计；
7. **HSI 设计**：基于上述输入；
8. **验证与确认（V\&V）**：通过模拟机、可用性测试；
9. **实施与培训**：开发模拟机培训课程；
10. **运行反馈**：投运后持续改进。

## HSI 未来发展趋势

1. **AI + 人协同（Human-AI Teaming）**：AI 提供建议，人决策；
2. **自适应 HSI**：根据操纵员状态（疲劳、压力）调整信息密度；
3. **数字孪生**：实时同步物理与虚拟，支持演练"what-if"；
4. **AR / VR / MR**：远程协助、维修指导、培训；
5. **无人值守 + 远程监控**：海上、空间、极地应用场景；
6. **多机组协同决策**：跨模块资源调度；
7. **网络安全原生设计**：HSI 与网络安全融合（Zero Trust）；
8. **跨电站标准化**：行业标准 API、数据格式，降低重复开发。

## 结论

SMR 的 HSI 是核工业"数字化转型"的关键战场。从"多人员 + 模拟仪表"到"少人员 + 数字 + AI 辅助"，HSI 的本质是**管理认知负荷 + 增强情境感知 + 保证安全决策**。第 8 章转入安全性，第 9 章转入防扩散，与 HSI 共同构成 SMR 的安全与保障（3S：Safety, Security, Safeguards）。
