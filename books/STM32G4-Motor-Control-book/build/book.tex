\chapter{STM32G4 概述}\label{stm32g4-ux6982ux8ff0}

\begin{epigraph}

\textbf{核心命题}　STM32G4 是 ST 面向数字电源与电机控制打造的混合信号
MCU 系列：一颗芯片内集成了电机控制所需的全套信号链------互补 PWM
高级定时器、双高速 ADC、可编程增益运放、硬件比较器刹车，以及 CORDIC/FMAC
两个数学加速器。理解这套''为电机控制而生''的资源布局，是理解后面所有章节的钥匙。

\end{epigraph}

\section{STM32G4
系列的特性}\label{stm32g4-ux7cfbux5217ux7684ux7279ux6027}

STM32G4 系列于 2019 年发布，基于 Arm Cortex-M4 内核（带 FPU 与 DSP
指令），主频 170 MHz（213 DMIPS），定位是取代 STM32F3 成为 ST
在数字电源、电机控制、太阳能微逆等''强模拟 + 强实时''场景的主力产品线。

两组定位，主要差异在存储容量与高精度定时器（HRTIM）的有无：

\subsection{内核与数学加速器}\label{ux5185ux6838ux4e0eux6570ux5b66ux52a0ux901fux5668}

Cortex-M4F 内核之外，G4 最有特色的是两个数学协处理器：

\begin{itemize}
\tightlist
\item
  \textbf{CORDIC}（坐标旋转数字计算机）：硬件计算 sin/cos/atan2
  等三角函数。一次调用可同时返回一对 sin 与
  cos，几十个周期完成，且计算期间 CPU
  可以并行做别的事。对电机控制来说，Park 变换、反 Park
  变换需要的正余弦对，以及无感观测器最后一步的 atan2，全部可以交给它。
\item
  \textbf{FMAC}（滤波数学加速器）：内置 256 字 RAM
  的硬件乘累加（MAC）单元，可脱离 CPU 执行 FIR/IIR 滤波，可挂 DMA
  持续供数。适合放速度估计滤波、母线电压前馈滤波这类''不着急但不能占
  CPU''的环节。
\end{itemize}

\subsection{定时器与数字外设}\label{ux5b9aux65f6ux5668ux4e0eux6570ux5b57ux5916ux8bbe}

\begin{itemize}
\tightlist
\item
  \textbf{高级定时器}：TIM1（G4 全系都有，互补 6 路 PWM
  输出、可编程死区、中央对齐计数、刹车输入、CCR
  预装载双缓冲）------这就是电机控制 PWM 的发生器。
\item
  \textbf{通用定时器}：多个 16/32
  位通用定时器，用于测频、编码器接口、时间基准。
\item
  \textbf{通信}：FDCAN、USB FS Device、SPI、I2C、多路 USART、LPUART。
\item
  \textbf{存储}：双 bank Flash（可在运行中擦写一个 bank
  同时从另一个执行）、SRAM 带奇偶校验、CCM
  SRAM（零等待，适合放实时中断代码）。
\end{itemize}

\textbf{一句话总结 G4 的电机控制价值}：相电流的放大（运放
PGA）、采样（双 ADC 同步）、保护（比较器\(\rightarrow\)刹车）、PWM
生成（TIM1
互补输出）、三角函数（CORDIC）、滤波（FMAC）全部片内闭环，几乎不需要外加模拟器件------这是第
7、8 章跑 FOC 时硬件设计的全部底座。

\section{STM32G4
的主要应用}\label{stm32g4-ux7684ux4e3bux8981ux5e94ux7528}

STM32G4 的目标市场集中在''把强实时控制算法与功率级直接对接''的领域：

\begin{itemize}
\tightlist
\item
  \textbf{数字电源}：服务器电源、充电桩模块、太阳能微逆变器、UPS------G474
  的 HRTIM 可实现数百 kHz 开关频率下的高精度数字控制。
\item
  \textbf{电机控制}：工业伺服、无人机电调（ST 官方 B-G431B-ESC1
  评估板即为此设计）、家电变频（空压机、风机、水泵）、电动工具、服务机器人关节。
\item
  \textbf{焊接设备}：逆变焊机的功率级控制。
\item
  \textbf{照明与充电}：大功率 LED 驱动、快充协议与功率级协同。
\end{itemize}

在这些应用里，电机控制是 G4 生态支持最完整的一块：ST
不仅提供芯片，还提供评估板（NUCLEO + X-NUCLEO 系列）、图形化配置工具（MC
Workbench）、电机参数自辨识工具（Motor Profiler）、完整的 FOC
固件库（X-CUBE-MCSDK）------本书要讲的正是这条完整的官方路径。

三相驱动板概述}\label{x-nucleo-ihm16m1-ux4e09ux76f8ux9a71ux52a8ux677fux6982ux8ff0}

X-NUCLEO-IHM16M1（用户手册 UM2383）是 ST
面向低压小功率三相电机开发的扩展板，核心特征（ST 官网产品页）：

\begin{itemize}
\tightlist
\item
  基于 \textbf{STSPIN830 单片三相驱动器}（栅极驱动 + 功率级集成）；
\item
  工作电压 \textbf{7 \textasciitilde{} 45 V}，最大输出电流 \textbf{1.5
  A（RMS）}；
\item
  支持 \textbf{单电阻（1-shunt）与三电阻（3-shunt）} 两种电流检测拓扑；
\item
  支持 \textbf{3-PWM / 6-PWM} 两种控制模式；
\item
  内建可调阈值 PWM 限流、过流/短路保护、互锁、过温关断、欠压锁定；
\item
  板上含
  \textbf{反电动势（BEMF）感知电路}------无感方波（六步）控制专用；
\item
  母线电压检测与板温（NTC）检测；
\item
  预留 \textbf{霍尔传感器/编码器输入连接器}------第 8 章有感控制用；
\item
  与 STM32 Nucleo 通过 Arduino 排针机械/电气对接，完全兼容
  X-CUBE-MCSDK。
\end{itemize}

\subsection{X-NUCLEO-IHM16M1
三相驱动板的硬件构成}\label{x-nucleo-ihm16m1-ux4e09ux76f8ux9a71ux52a8ux677fux7684ux786cux4ef6ux6784ux6210}

信号链按''功率流''与''信息流''两条线读图：

\textbf{功率流}：12 V 电源从输入连接器进入 \(\rightarrow\) STSPIN830
内部三个半桥（功率管导通电阻 HS+LS 合计约 1 Ω）\(\rightarrow\)
三个输出端 U/V/W \(\rightarrow\) 电机三相绕组。STSPIN830
是''驱动+功率级''一体的单片方案，板上没有外置功率 MOSFET------这决定了它

\textbf{信息流}（全部回流到 G431）：

\begin{itemize}
\tightlist
\item
  三个低侧采样电阻上的相电流压降 \(\rightarrow\) 板上运放调理
  \(\rightarrow\) G431 的 ADC（三电阻模式）；
\item
  三相端电压经分压 \(\rightarrow\) BEMF 感知电路 \(\rightarrow\) G431
  ADC（方波无感换相判断）；
\item
  母线电压分压 \(\rightarrow\) ADC（过压/欠压保护与 SVPWM 前馈）；
\item
  板温 NTC \(\rightarrow\) ADC；
\item
  反方向：G431 TIM1 输出的 6 路 PWM \(\rightarrow\) STSPIN830
  输入；故障信号 \(\rightarrow\) G431。
\end{itemize}

\section{DC 电源}\label{dc-ux7535ux6e90}

套件附带 12 V / 2 A 直流适配器，接 IHM16M1
的电源输入端。围绕它做三个预算估算：

\begin{itemize}
\tightlist
\item
  \textbf{电机侧}：GBM2804H 相电阻约 11 Ω，星接下线电压除以 2
  倍相电阻为相电流上限量级------12 V 满压堵转电流也在 0.5 A
  量级，加上运行时大部分电压由反电动势与电抗压降分担，实际工作电流典型在几十到几百毫安，2
  A 余量充足。
\item
  \textbf{板卡侧}：STSPIN830 导通电阻约 1 Ω（HS+LS），百毫安级电流下管耗
  \textless0.1 W，自然冷却无压力。
\item
  \textbf{控制侧}：IHM16M1 通过排针向 NUCLEO-G431RB 反向提供 5
  V（经板载稳压），无需额外给控制板供电------具体取决于 JP1/JP3
  跳线配置，按 UM2079/UM2383 的堆叠说明操作。
\end{itemize}

\textbf{上电操作纪律}（贯穿全书的实验守则）：

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  先接电机三相线，再上母线电源；断电顺序反之。带电插拔电机线会产生感应对系统的电压尖峰。
\item
  首次运行新固件时，手边放着电源开关；异常啸叫、异常发热立即断电。
\item
  电流检测相关参数（采样电阻值、运放增益）来自板卡手册，配置错了电流读数会整体错------这也是第
  7 章坚持用 MC Workbench 选官方板卡型号（而不是自定义板）的原因。
\end{enumerate}

  \(\lambda_f\) 解出来；
\item
  \textbf{测惯量/摩擦}：分析自由减速段的转速衰减率。
\end{itemize}

\section{定时器 PWM
应用实验}\label{ux5b9aux65f6ux5668-pwm-ux5e94ux7528ux5b9eux9a8c}

\textbf{目标}：在 TIM2 通道 1（PA0）输出 1 kHz、占空比可调的
PWM------这是理解电机驱动''占空比 = 电压指令''的起点。

\textbf{定时器三要素}：预分频 PSC、自动重装 ARR、比较
CCR。计数器在每个时钟沿加一，从 0 数到 ARR 后归零（边沿对齐模式）；CNT
与 CCR 比较决定输出电平：

\[f_{PWM} = \frac{f_{TIM}}{(PSC+1)(ARR+1)}, \qquad D = \frac{CCR}{ARR+1}\]

\textbf{CubeMX 配置}：Timers \(\rightarrow\) TIM2 \(\rightarrow\)
Slave/Channel1 选 \texttt{PWM\ Generation\ CH1}；Parameter Settings 里
Prescaler = 169（170 MHz / 170 = 1 MHz 计数）、Counter Period = 999（1
MHz / 1000 = 1 kHz）、Pulse（CCR 初值）= 500。

\textbf{用户代码}：

\begin{verbatim}
HAL_TIM_PWM_Start(&htim2, TIM_CHANNEL_1);
/* 主循环里呼吸灯式修改占空比 */
uint32_t ccr = 0;
while (1) {
    ccr = (ccr + 10) % 1000;
    __HAL_TIM_SET_COMPARE(&htim2, TIM_CHANNEL_1, ccr);
    HAL_Delay(10);
}
\end{verbatim}

\begin{figure}
\centering
\pandocbounded{\includegraphics[keepaspectratio,alt={定时器 PWM 原理：计数器 0 到 ARR 循环计数，CNT 小于 CCR 期间输出高电平；改 CCR 即改占空比（图中两个周期分别为 70\% 与 40\%）}]{images/fig_04_pwm_duty.png}}
\caption{定时器 PWM 原理：计数器 0 到 ARR 循环计数，CNT 小于 CCR
期间输出高电平；改 CCR 即改占空比（图中两个周期分别为 70\% 与 40\%）}
\end{figure}

\textbf{现象与验证}：示波器（或万用表平均电压档）可见 1 kHz 方波，占空比
0 \(\rightarrow\) 100\% 缓慢扫动；把 LED 串电阻接 PA0
可见呼吸效果。\textbf{记住这张图}：第 6 章的 SVPWM
最终产物就是三个这样的 PWM
波，只是频率高两个数量级、占空比由算法每周期刷新。

\section{外部中断实验}\label{ux5916ux90e8ux4e2dux65adux5b9eux9a8c}

\textbf{目标}：按下 B1（PC13）翻转 LED，中断方式实现（不用轮询）。

\textbf{CubeMX 配置}：点击 PC13 选 \texttt{GPIO\_EXTI13}；GPIO
配置里触发沿选 Falling（按下为低）；NVIC 里勾选
\texttt{EXTI\ line\ 15..10\ interrupt} 并给合理抢占优先级（如 5）。

\textbf{用户代码}：

\begin{verbatim}
/* main.c —— 回调函数（HAL 已在启动文件的中断向量里接管入口） */
void HAL_GPIO_EXTI_Callback(uint16_t GPIO_Pin)
{
    if (GPIO_Pin == GPIO_PIN_13) {
        HAL_GPIO_TogglePin(GPIOA, GPIO_PIN_5);
    }
}
\end{verbatim}

\textbf{现象与验证}：每按一次 B1，LD2 翻转一次。中断路径即图 4.1
右侧：引脚边沿 \(\rightarrow\) EXTI13 检测 \(\rightarrow\) NVIC 仲裁
\(\rightarrow\)
\texttt{EXTI15\_10\_IRQHandler}（启动文件中的向量入口）\(\rightarrow\)
HAL 分发到用户回调。

\textbf{为什么用中断}：电机控制的主循环时间预算以微秒计，``等按键''这种事必须让硬件代劳。第
7 章的旋钮控制实验（7.4
节）会把''按键改速度''与''电机控制''并存，靠的就是这套机制。

\section{互补 PWM
输出实验}\label{ux4e92ux8865-pwm-ux8f93ux51faux5b9eux9a8c}

\textbf{目标}：用 TIM1 同时输出互补的
CH1/CH1N（带死区、中央对齐）------这是三相逆变桥一个桥臂的完整驱动波形，是本章通往第
5 章的桥。

\textbf{为什么需要互补 + 死区}：半桥上下两管绝不允许同时导通（直通 =
短路母线）。理论上一路 PWM
取反就是下管波形，但实际开关管开通/关断有纳秒到微秒级的延迟差异，必须在上管关断与下管开通之间（以及反之）人为插入一段''两管皆关''的死区时间。

\tightlist

  PA8/PA7）；
\item

\item

\item
  20 kHz
  PWM：\(ARR = f_{TIM}/(2 f_{PWM}) - 1 = 170\,\mathrm{MHz}/(2 \times 20\,\mathrm{kHz}) - 1 \approx 4249\)。
\end{itemize}

\section{无刷直流电机的数学模型}\label{ux65e0ux5237ux76f4ux6d41ux7535ux673aux7684ux6570ux5b66ux6a21ux578b}

\subsection{定子电压方程}\label{ux5b9aux5b50ux7535ux538bux65b9ux7a0b}

每相绕组电气上是''电阻 + 电感 + 反电动势源''串联。三相电压方程：

\[\begin{cases} u_a = R_s i_a + L_s \dfrac{\mathrm{d}i_a}{\mathrm{d}t} + e_a \\[4pt] u_b = R_s i_b + L_s \dfrac{\mathrm{d}i_b}{\mathrm{d}t} + e_b \\[4pt] u_c = R_s i_c + L_s \dfrac{\mathrm{d}i_c}{\mathrm{d}t} + e_c \end{cases}\]

其中 \(R_s\) 为相电阻、\(L_s\) 为相电感、\(e_{a,b,c}\)
为反电动势。星接无中线时三相电流恒满足 \(i_a + i_b + i_c = 0\)。

读这个方程的方式：\textbf{电压是因，电流是果}。电感项决定电流不能突变（电流环带宽受
\(L_s\)
限制），反电动势项是与转速相关的''反向电压源''，转速越高吃掉的母线电压越多------这就是电机的最高转速限制。

\subsection{反电动势方程}\label{ux53cdux7535ux52a8ux52bfux65b9ux7a0b}

BLDC 的反电动势设计成\textbf{梯形波}：气隙磁场经绕组切割，每相反电动势呈
120° 平顶的梯形（图 5.3 下三行），理想幅值：

\[e_x = k_e \, \omega_m \, f_x(\theta_e)\]

\(k_e\) 为反电动势常数，\(\omega_m\) 为机械角速度，\(f_x(\theta_e)\)
是该相的梯形形状函数（归一化，平顶为 ±1）。三相梯形波互差 120° 电角。

\subsection{电磁转矩方程}\label{ux7535ux78c1ux8f6cux77e9ux65b9ux7a0b}

通电导体在磁场中受力（安培力），对电机整体求和，电磁转矩：

\[T_e = \frac{e_a i_a + e_b i_b + e_c i_c}{\omega_m}\]

功率守恒的必然结果：电磁功率（反电动势 ×
电流）全部转化为机械功率。方波驱动的精髓在于：\textbf{在每相反电动势平顶的
120° 区间给该相通 120° 方波电流}，于是 \(e \cdot i\)
乘积恒定，转矩平滑无纹波（理想条件下）。

\subsection{运动方程}\label{ux8fd0ux52a8ux65b9ux7a0b}

转子机械侧由牛顿第二定律：

\[J \frac{\mathrm{d}\omega_m}{\mathrm{d}t} = T_e - T_L - B\,\omega_m\]

\(J\) 为转动惯量（转子 + 负载折算），\(T_L\) 为负载转矩，\(B\)
为粘性摩擦系数。三个电机参数 \(J\)、\(B\) 与电气侧的
\(R_s\)、\(L_s\)、\(k_e\) 合起来，就是 Motor Profiler
要辨识的全部家当（3.6.3 节）。

\section{三相 PMSM 的结构}\label{ux4e09ux76f8-pmsm-ux7684ux7ed3ux6784}

永磁同步电机与 BLDC
在结构上是近亲：定子三相绕组、转子永磁体，区别在\textbf{绕组设计目标}------PMSM
追求\textbf{正弦反电动势}，BLDC 追求梯形反电动势。GBM2804H-100T
这类云台电机的反电动势正弦度相当好，当 BLDC 用（方波）或当 PMSM
用（正弦）都行，正好一鱼两吃。

按转子磁路分两类：

\begin{itemize}
\tightlist
\item
  \textbf{表贴式（SPM）}：磁铁贴在转子表面，交直轴电感近似相等（\(L_d = L_q\)），转矩严格正比于
  \(i_q\)------本书电机与大多数云台/无人机电机都是这类，控制最简单；
\item
  \textbf{内嵌式（IPM）}：磁铁埋入转子铁芯，\(L_q > L_d\)，除永磁转矩外还有磁阻转矩，高速弱磁性能好，控制要精细得多（利用
  \(L_d \ne L_q\) 的转矩公式），本书不展开。
\end{itemize}

\section{三相 PMSM
的数学模型}\label{ux4e09ux76f8-pmsm-ux7684ux6570ux5b66ux6a21ux578b}

\subsection{三相 PMSM
的坐标变换}\label{ux4e09ux76f8-pmsm-ux7684ux5750ux6807ux53d8ux6362}

\textbf{为什么变}：三相电流是三个时间上错开 120°
的正弦量，直接闭环控制它们，控制器必须在每个瞬间同时算三笔相位相关的账。坐标变换的洞见：三个正弦量其实是同一个旋转矢量在三个轴上的投影------\textbf{控制一个矢量，比控制三个正弦量干净}。

三个坐标系的几何关系是本章的''地图''（图 6.1）：

\begin{itemize}
\tightlist
\item
  \textbf{abc 系}：三相静止轴，互差 120°（电角），A 相轴与 α 轴重合；
\item
  \textbf{αβ 系}：两相静止轴，α 对齐 A 相轴，β 超前 90°------Clarke
  变换的目的地；
\item
  \textbf{dq 系}：两相旋转轴，d 轴对准转子磁场（永磁体磁链方向），q
  轴超前 90°------Park 变换的目的地，FOC 的作战地图。
\end{itemize}

\begin{figure}
\centering
\pandocbounded{\includegraphics[keepaspectratio,alt={坐标系与矢量图：同一个定子电流矢量，在 abc 三相轴、αβ 静止轴、dq 旋转轴上各有投影；θe 为转子电角，FOC 的目标是让电流矢量始终贴着 q 轴（γ = 90°）}]{images/fig_06_frames.pdf}}
\caption{坐标系与矢量图：同一个定子电流矢量，在 abc 三相轴、αβ

\end{figure}

\textbf{Clarke 变换}（abc \(\rightarrow\) αβ，等幅值形式）：

\[i_\alpha = \frac{2}{3}\Big(i_a - \frac{1}{2} i_b - \frac{1}{2} i_c\Big), \qquad i_\beta = \frac{2}{3}\Big(\frac{\sqrt{3}}{2} i_b - \frac{\sqrt{3}}{2} i_c\Big)\]

工程上常用''采两相''版本（\(i_c = -i_a - i_b\) 代入）：

\[i_\alpha = i_a, \qquad i_\beta = \frac{i_a + 2 i_b}{\sqrt{3}}\]

\textbf{Park 变换}（αβ \(\rightarrow\) dq）：

\[\begin{cases} i_d = \;\;\, i_\alpha \cos\theta_e + i_\beta \sin\theta_e \\ i_q = -\, i_\alpha \sin\theta_e + i_\beta \cos\theta_e \end{cases}\]

\textbf{反 Park 变换}（dq \(\rightarrow\) αβ）：

\[v_\alpha = v_d \cos\theta_e - v_q \sin\theta_e, \qquad v_\beta = v_d \sin\theta_e + v_q \cos\theta_e\]

整个 FOC 只需要一对 \(\sin\theta_e / \cos\theta_e\)------这正是第 1 章
CORDIC 协处理器登场的地方。

\subsection{同步旋转坐标系（d-q
坐标系）下的数学模型}\label{ux540cux6b65ux65cbux8f6cux5750ux6807ux7cfbd-q-ux5750ux6807ux7cfbux4e0bux7684ux6570ux5b66ux6a21ux578b}

站在随转子旋转的 dq
系里看，所有正弦量都静止了，电压方程变成两个\textbf{直流量}的方程（SPM，\(L_d = L_q = L_s\)）：

\[\begin{cases} v_d = R_s i_d + L_s \dfrac{\mathrm{d}i_d}{\mathrm{d}t} - \omega_e L_s i_q \\[6pt] v_q = R_s i_q + L_s \dfrac{\mathrm{d}i_q}{\mathrm{d}t} + \omega_e L_s i_d + \underbrace{\omega_e \lambda_f}_{\text{反电动势}} \end{cases}\]

\begin{itemize}
\tightlist
\item
  \(\omega_e\) 为电角速度（\(\omega_e = p \omega_m\)），\(\lambda_f\)
  为转子磁链；
\item
  \(\omega_e L_s i\) 项是\textbf{交叉耦合}：转速越高，d/q
  两轴通过电感互相串扰越强；
\item
  \(\omega_e \lambda_f\) 项就是反电动势在 q 轴上的化身。
\end{itemize}

\textbf{转矩方程}（SPM）：

\[T_e = \frac{3}{2} p \, \lambda_f \, i_q\]

只由 \(i_q\) 决定！这就是 FOC 的操作指南：\textbf{把 \(i_d\)
压到零（不励磁不浪费），用 \(i_q\) 当转矩旋钮}。速度环的输出就是 \(i_q\)
指令，力矩控制退化为直流量控制------FOC 把 PMSM
变成了一台''解耦的直流电机''。

\subsection{静止坐标系（α-β
坐标系）下的数学模型}\label{ux9759ux6b62ux5750ux6807ux7cfbux3b1-ux3b2-ux5750ux6807ux7cfbux4e0bux7684ux6570ux5b66ux6a21ux578b}

不做 Park
变换、直接在两相静止系建模（无感观测器喜欢在这里工作，因为不需要转子角度）：

\[\begin{cases} v_\alpha = R_s i_\alpha + L_s \dfrac{\mathrm{d}i_\alpha}{\mathrm{d}t} + e_\alpha \\[4pt] v_\beta = R_s i_\alpha + L_s \dfrac{\mathrm{d}i_\beta}{\mathrm{d}t} + e_\beta \end{cases}\]

反电动势两个分量
\(e_\alpha = -\omega_e \lambda_f \sin\theta_e\)、\(e_\beta = \omega_e \lambda_f \cos\theta_e\)------\textbf{藏着转子的角度信息}。STO
观测器（7.1 节）的原理就是：由已知的 \(v_{\alpha\beta}\)、测得的
\(i_{\alpha\beta}\) 和电机参数 \(R_s\)、\(L_s\) 反解出
\(e_{\alpha\beta}\)，再
\(\theta_e = \mathrm{atan2}(-e_\alpha, e_\beta)\) 拿到转子角。无感 FOC
的全部魔法就这一段。

\subsection{ST-MC-SDK Motor Profiler
测量电机参数的原理}\label{st-mc-sdk-motor-profiler-ux6d4bux91cfux7535ux673aux53c2ux6570ux7684ux539fux7406}

Motor Profiler（3.6.3 节的操作）每一步都严格对应 6.2 节模型的一项：

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  \textbf{测
  \(R_s\)}：注入小幅直流电压矢量（转子静止），稳态时电感项为零、反电动势为零，\(R_s = V / I\)；
\item
  \textbf{测
  \(L_s\)}：观察施加电压矢量初期电流的上升斜率，\(\mathrm{d}i/\mathrm{d}t = (V - R_s i)/L_s\)，拟合出
  \(L_s\)；
\item
  \textbf{测 \(\lambda_f\) 与
  \(p\)}：以已知电压矢量开环拖动电机旋转，稳态下从电压方程扣除 \(R_s i\)
  与 \(L_s\,\mathrm{d}i/\mathrm{d}t\)，剩下的就是反电动势项
  \(\omega_e \lambda_f\)；由指令频率与实测转速的关系同时校出 \(p\)；
\item
  \textbf{测
  \(J\)、\(B\)}：撤去驱动让电机自由减速，\(\mathrm{d}\omega/\mathrm{d}t = -(T_L + B\omega)/J\)，由减速曲线拟合。
\end{enumerate}

所以 Profiler 不是黑魔法，而是把 5.2
节的方程逐项反解的自动化脚本------输出的每个数都能用手动方法复核。

\subsection{SVPWM
算法的合成原理}\label{svpwm-ux7b97ux6cd5ux7684ux5408ux6210ux539fux7406}

\textbf{核心思想}：在一个 PWM 周期 \(T\)
内，用相邻两个有效矢量加零矢量按时间加权''平均出''目标矢量（设目标矢量落在扇区
I，相邻矢量为 \(\vec{V}_1\)、\(\vec{V}_2\)）：

\[\vec{U}_{ref} \, T = \vec{V}_1 T_1 + \vec{V}_2 T_2 + \vec{V}_{0/7} T_0, \qquad T_1 + T_2 + T_0 = T\]

由平行四边形法则解出（\(\theta\) 为矢量在本扇区内偏离 \(\vec{V}_1\)
的角度，\(|\vec{U}_{ref}| = U\)）：

\[T_1 = \frac{\sqrt{3} \, U \, T}{V_{dc}} \sin(60° - \theta), \qquad T_2 = \frac{\sqrt{3} \, U \, T}{V_{dc}} \sin\theta\]

\textbf{七段式排布}：把 \(T_1\)、\(T_2\)
对半拆开对称放置，零矢量分到两端与中央（000-100-110-111-110-100-000），使一个周期内开关次数最少、谐波最小：

\textbf{线性区与母线利用率}：六边形内切圆半径 \(V_{dc}/\sqrt{3}\)

\(2/\sqrt{3} \approx 1.155\) 倍------同样母线电压多出约 15\%
的电压利用率，这是 SVPWM
在电机驱动中一统江湖的直接原因。从调制波形看，SVPWM

\subsection{SVPWM
算法的实现}\label{svpwm-ux7b97ux6cd5ux7684ux5b9eux73b0}

教科书流程（判扇区 \(\rightarrow\) 套 \(T_1/T_2\) 公式 \(\rightarrow\)
七段排布）分支多；嵌入式实现的标准姿势是数学等价的\textbf{最小最大值注入法（min-max
injection）}------无分支、四次乘法完事：

\[\begin{cases} V_a = v_\alpha \\[2pt] V_b = \dfrac{-v_\alpha + \sqrt{3}\, v_\beta}{2} \\[4pt] V_c = \dfrac{-v_\alpha - \sqrt{3}\, v_\beta}{2} \end{cases} \qquad V_{off} = -\frac{\max(V_a, V_b, V_c) + \min(V_a, V_b, V_c)}{2}\]

\[\mathrm{duty}_x = \frac{1}{2} + \frac{V_x + V_{off}}{V_{dc}} \quad (x = a, b, c)\]

\texttt{duty\_x} 直接写入 TIM1 三个通道的 CCR
寄存器。三行代码的物理含义：三相调制波的共模平移（注入
\(V_{off}\)）不改变线电压，却把波形中心拉回 PWM
的线性范围中央------这正是七段式的代数化身。

\subsection{PMSM
矢量控制基本原理}\label{pmsm-ux77e2ux91cfux63a7ux5236ux57faux672cux539fux7406}

把 6.2 的模型与 6.3 的执行器组装起来，就是完整的 FOC 控制框图（图
6.5）------\textbf{这张图值得盯到能默画}：

按信号流走一遍：

\begin{enumerate}

\item
  速度指令 \(\omega^{*}\) 与反馈速度之差进\textbf{速度环 PI}，输出

\item
  \(i_q^{*}\) 与 \(i_d^{*} = 0\) 分别进两个\textbf{电流环 PI}，输出

  反 Park 变换转回 \(\alpha\beta\) 平面，SVPWM 生成三相占空比，写入

  每个 PWM 周期采样两相电流 \(\rightarrow\) Clarke \(\rightarrow\) Park
  得到 \(i_d\)、\(i_q\) 反馈；
\item
  \(\theta_e\) 来自编码器/霍尔（有感）或观测器（无感），同时喂给 Park
  与反 Park。
\end{enumerate}

\textbf{与六步方波对比}：方波每 60° 电角''跳一档''，电流矢量方向在 ±30°
间摆动；FOC 每一个 PWM 周期（几十微秒）都把电流矢量钉在 q
轴上------转矩恒定、电流利用率最高、低速平稳、无换相噪声。代价是计算量与对电流采样/角度质量的要求。

\subsection{PMSM 的电流环 PI
控制}\label{pmsm-ux7684ux7535ux6d41ux73af-pi-ux63a7ux5236}

\textbf{被控对象}：6.2.2 节 dq 方程忽略交叉耦合后，d、q 轴各是一个一阶
RL 惯性环节（传递函数 \(1/(L_s s + R_s)\)）------这是 PI
控制器的教科书对象。

\textbf{带宽整定法}（把闭环带宽直接设计为 \(f_{bw}\)，极点对消）：

\[K_P = 2\pi f_{bw} L_s, \qquad K_I = 2\pi f_{bw} R_s\]

\(f_{bw}\) 取 PWM 频率的 1/10 \textasciitilde{} 1/20（20 kHz PWM
\(\rightarrow\) 电流环带宽 1 \textasciitilde{} 2 kHz
量级）。\(R_s\)、\(L_s\) 就来自 6.2.4/6.2.5 的测量------\textbf{参数辨识
\(\rightarrow\) PI 整定 \(\rightarrow\) 性能}，链条在这里闭合。

\textbf{工程细节}（SDK 里都有对应参数项）：

\begin{itemize}
\tightlist
\item
  \textbf{输出限幅}：\(\sqrt{v_d^2 + v_q^2} \le V_{dc}/\sqrt{3}\)（SVPWM
  线性区圆）；
\item
  \textbf{抗积分饱和}：限幅的同时钳住积分器（反计算或钳位法），否则超调恢复极慢；
\item
  \textbf{交叉解耦前馈}（可选）：补偿 \(\pm\omega_e L_s i\)
  项，高速时改善动态；云台电机低速场景常省略，由 PI 积分顶住。
\end{itemize}

\subsection{PMSM 的速度环 PI
控制}\label{pmsm-ux7684ux901fux5ea6ux73af-pi-ux63a7ux5236}

速度环套在电流环外面，被控对象近似为''电流环（一阶惯性）+ 转矩常数 +
机械惯量''的积分环节：

\[J \frac{\mathrm{d}\omega_m}{\mathrm{d}t} = \frac{3}{2} p \lambda_f i_q - T_L \;\; \Rightarrow \;\; \omega_m(s) = \frac{K_t}{J s} i_q(s) + \ldots\]

\textbf{整定原则}：

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  \textbf{带宽分离}：速度环带宽取电流环的 1/5 \textasciitilde{}
  1/10，内外环才不打架（内环对外环近似'' instantaneous''）；
\item
  速度反馈在无感方案里来自观测器，噪声较大------加低通或用 FMAC
  硬件滤波（第 1 章），但注意滤波延迟也在吃相位裕度；
\item
  速度环输出 \(i_q^{*}\)
  要限幅（最大相电流），堵转时这层限幅就是电机的热保护。
\end{enumerate}

\textbf{级联结构的意义}：速度环不必关心电流怎么跟上，电流环不必关心电压怎么合成------每层只对一层负责。这个''分而治之''的框架从
0.5 Hz 的位置环到 20 kHz
的电流环通吃，是运动控制领域近百年沉淀下来的标准答案。

\section{本章小结}\label{ux672cux7ae0ux5c0fux7ed3-5}

\begin{itemize}
\tightlist
\item
  坐标变换把''三相交流''变成''两个直流''：Clarke（abc\(\rightarrow\)αβ）降维，Park（αβ\(\rightarrow\)dq）换到转子视角；FOC
  目标是 \(i_d = 0\)、\(i_q\) 出力；
\item
  dq 模型给出电压方程与转矩方程
  \(T_e = \frac{3}{2} p \lambda_f i_q\)；αβ 模型藏着无感观测器的钥匙；
\item
  SVPWM 用 8 个离散矢量时间加权合成任意矢量，七段式谐波最优，min-max
  注入法三行代码实现，比 SPWM 多 15\% 母线利用率；
\item
  电流环带宽法整定
  \(K_P = 2\pi f_{bw} L_s\)、\(K_I = 2\pi f_{bw} R_s\)，速度环带宽低于电流环
  5 \textasciitilde{} 10 倍；
\item
  第 7 章把这些公式全部''对号入座''到 MC SDK 的配置界面与 API 上。
\end{itemize}

\section{旋钮控制电机运行速度实例}\label{ux65cbux94aeux63a7ux5236ux7535ux673aux8fd0ux884cux901fux5ea6ux5b9eux4f8b}

\textbf{目标}：脱离
PC，用一个电位器旋钮本地控制电机转速------``嵌入式产品化''的第一个原型。

\textbf{硬件}：10 kΩ 电位器两端接 3.3 V 与 GND，中心抽头接 NUCLEO
的一个空闲 ADC 通道（在 CubeMX 里给工程补一路 ADC 常规采样即可，避开 MC
SDK 已占用的电流采样通道）。

\textbf{代码}（应用层，主循环 10 ms 周期执行）：

\begin{verbatim}
/* 读取旋钮电压 → 映射为速度指令 → 下发给速度环 */
#include "mc_api.h"

#define SPEED_MIN   300     /* rpm，低于此速无感观测不稳 */
#define SPEED_MAX   3000    /* rpm */

void UserPoti_Task(void)    /* 10 ms 周期调用 */
{
    uint16_t adc = ReadPoti_ADC();               /* 0..4095 */
    int16_t rpm = SPEED_MIN + (int32_t)(SPEED_MAX - SPEED_MIN) * adc / 4095;

    if (MotorIsStarted()) {
        MC_ProgramSpeedRampMotor1(rpm * SPEED_UNIT, 200); /* 200 ms 平滑 */
    }
}
\end{verbatim}

\textbf{要点}：速度指令经 \texttt{MC\_ProgramSpeedRampMotor1}
平滑下发（斜坡由 SDK 执行）；启动/停止仍可用板上 B1 按键触发（4.3 节的
EXTI 回调里调
\texttt{MC\_StartMotor1()}/\texttt{MC\_StopMotor1()}）。此实验把''传感
\(\rightarrow\) 指令 \(\rightarrow\) 速度环 \(\rightarrow\)
电机''的产品级数据流完整走了一遍。

\section{故障处理及恢复实例}\label{ux6545ux969cux5904ux7406ux53caux6062ux590dux5b9eux4f8b}

\textbf{目标}：理解 SDK
的故障管理机制，做一个''故障可查询、可恢复''的应用。

\textbf{故障检测}是 SDK
中间件内置的（过流、过压、欠压、速度反馈异常、启动失败等，枚举定义在固件
\texttt{mc\_type.h} 一带，以随 SDK
的头文件为准）。应用层要做的是\textbf{消费故障}：

\begin{verbatim}
if (MC_GetOccurredFaultsMotor1() != MC_NO_FAULTS) {
    uint16_t faults = MC_GetOccurredFaultsMotor1();
    LogFaultViaUART(faults);            /* 串口上报故障码（4.4 节通道） */
    HAL_Delay(3000);                    /* 等待现场排除（举例） */
    MC_AcknowledgeFaultsMotor1();       /* 确认清障 */
    MC_StartMotor1();                   /* 重新启动 */
}
\end{verbatim}

\textbf{人为制造故障做实验}（安全范围内）：运转中轻捏电机轴到堵转
\(\rightarrow\)
观察过流/启动失败故障码；串口日志看到码值后再松手让程序自动恢复。注意两点纪律：故障必须先
\texttt{MC\_AcknowledgeFaultsMotor1}
清除才能再启动；真实产品里''自动重启''要加次数与冷却限制，避免打火花式循环重启。

（具体码序与霍尔安装相位有关------若电机反转，交换任意两根电机线或两根霍尔线即可修正。MC
SDK 会根据配置的霍尔相序自动建表。）

\subsection{MC Workbench
配置与实验}\label{mc-workbench-ux914dux7f6eux4e0eux5b9eux9a8c}

\textbf{配置}：与 7.2 节工程相同，仅把 Feedback 从 Sensorless 改为
\textbf{Hall sensors}；填入极对数（7）；SDK 自动完成''霍尔沿
\(\rightarrow\) 换相 \(\rightarrow\) 速度计算''（相邻霍尔沿间隔 = 60°
电角，倒数即电角速度）。

\textbf{实验步骤}：

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  生成、烧录、上电，给速度指令------\textbf{注意与无感的最直观差异：电机从零速直接进入闭环}，没有开环强拖的三段式过程；
\item
  低速测试（100 rpm
  级）：无感方案在这个速度段观测器信噪比不足会失步或振荡，有感方案平稳旋转；
\item
  动态加载：捏轴加载/松开，霍尔实时反映真实位置，换相不受观测器收敛延迟影响，恢复干脆。
\end{enumerate}

\section{永磁同步电机的有感 FOC
控制案例}\label{ux6c38ux78c1ux540cux6b65ux7535ux673aux7684ux6709ux611f-foc-ux63a7ux5236ux6848ux4f8b}

\subsection{霍尔位置反馈在 FOC
中的角色}\label{ux970dux5c14ux4f4dux7f6eux53cdux9988ux5728-foc-ux4e2dux7684ux89d2ux8272}

FOC 需要\textbf{连续}的电角度 \(\theta_e\)（6.2.1 节 Park
变换的输入），而霍尔只给 60° 粒度的离散位置。SDK
的处理方式：\textbf{霍尔沿 +
平滑插值}------两个霍尔沿之间按平均角速度外推角度（高速时准确），同时用最近的霍尔沿做误差校正（累积误差每个
60° 清一次）。

\subsection{MC Workbench

\textbf{配置}：在 7.1 的无感 FOC 工程基础上，Feedback 改为 \textbf{Hall
sensors}，其余（FOC、3-shunt、速度模式）不变。

\subsection{从套件走向产品}\label{ux4eceux5957ux4ef6ux8d70ux5411ux4ea7ux54c1}

跑通本书全部实验后，自然的下一步：

\begin{itemize}
\tightlist
\item
  \textbf{换功率级}：套件的 STSPIN830 上限 1.5 A。更大电流需求可换用
  STSPIN32G4（G4 内核 + 栅驱一体的 SiP）、STDRIVE101 + 分立
  MOSFET，或直接参考 B-G431B-ESC1（G431 三电阻 FOC 参考设计，无人机 ESC
  形态）；
\item
  \textbf{换位置传感}：伺服级性能上编码器（SDK 支持）；
\item
  \textbf{上 RTOS / 总线}：FDCAN 多节点协调（第 1
  章的通信外设），把''单电机实验''组织成''多轴系统''；
\item
  \textbf{精读 SDK 源码}：5.x 固件库的 FOC 内核就是第 6
  章公式的工业级实现（定点化、抗饱和、观测器离散化细节），是极好的进阶读物。
\end{itemize}

\section{本章小结}\label{ux672cux7ae0ux5c0fux7ed3-7}

\begin{itemize}
\tightlist
\item
  霍尔三信号给出 60° 电角粒度的转子位置：方波控制直接查表换相，FOC
  用''沿 + 插值''合成连续角度；
\item
  有感方案的核心价值：启动可靠、低速可用、动态快------代价是传感器硬件与连线；
\item
  无感 vs
  有感的选型直觉：风机泵类负载（不要求零速、成本敏感）用无感；云台/关节/定位类负载用有感；
\item
  套件之上还有一整条 ST 电机控制产品线路（STSPIN32G4、ESC
  板、更高压驱动），路径是连续的。
\end{itemize}
