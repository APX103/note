# STM32G4 概述

> **核心命题**　STM32G4 是 ST 面向数字电源与电机控制打造的混合信号 MCU 系列：一颗芯片内集成了电机控制所需的全套信号链——互补 PWM 高级定时器、双高速 ADC、可编程增益运放、硬件比较器刹车，以及 CORDIC/FMAC 两个数学加速器。理解这套"为电机控制而生"的资源布局，是理解后面所有章节的钥匙。

---

## STM32G4 系列的特性

STM32G4 系列于 2019 年发布，基于 Arm Cortex-M4 内核（带 FPU 与 DSP 指令），主频 170 MHz（213 DMIPS），定位是取代 STM32F3 成为 ST 在数字电源、电机控制、太阳能微逆等"强模拟 + 强实时"场景的主力产品线。

### 子系列划分

ST 官网将 STM32G4 分为 Access 与 Performance 两组定位，主要差异在存储容量与高精度定时器（HRTIM）的有无：

| 子系列 | 典型型号 | Flash | 定位要点 |
| --- | --- | --- | --- |
| Access | STM32G431 / G441 | 最高 128 KB | 入门配置，无 HRTIM；G441 带 AES 加密 |
| Performance | STM32G471 / G473 / G474 / G484 | 最高 512 KB | 带 HRTIM 高精度定时器；G484 带 AES 加密 |

本书套件 NUCLEO-G431RB 使用的 STM32G431RBT6 属于 Access 线：128 KB Flash、32 KB SRAM（含 CCM SRAM）、LQFP64 封装。它没有 HRTIM——但这对本书毫无影响：普通电机控制（PWM 频率 10 \textasciitilde{} 20 kHz 级）用 TIM1 高级定时器完全够用，HRTIM 面向的是数字电源里几百 kHz 开关频率的场合。

### 内核与数学加速器

Cortex-M4F 内核之外，G4 最有特色的是两个数学协处理器：

- **CORDIC**（坐标旋转数字计算机）：硬件计算 sin/cos/atan2 等三角函数。一次调用可同时返回一对 sin 与 cos，几十个周期完成，且计算期间 CPU 可以并行做别的事。对电机控制来说，Park 变换、反 Park 变换需要的正余弦对，以及无感观测器最后一步的 atan2，全部可以交给它。
- **FMAC**（滤波数学加速器）：内置 256 字 RAM 的硬件乘累加（MAC）单元，可脱离 CPU 执行 FIR/IIR 滤波，可挂 DMA 持续供数。适合放速度估计滤波、母线电压前馈滤波这类"不着急但不能占 CPU"的环节。

### 模拟外设：单芯片电机控制信号链

G4 的模拟外设密度是同级别少见的。以 STM32G431（DS12550）为例：

| 外设 | 数量 | 关键能力 | 电机控制中的角色 |
| --- | --- | --- | --- |
| ADC | 2 × 12-bit | 4 MSPS，双 ADC 同步采样，硬件过采样到 16-bit | 相电流采样（同步采两相） |
| DAC | 4 通道 12-bit | 缓冲输出 | 给比较器提供过流阈值 |
| 运放 OPAMP | 3 个 | 可编程增益 PGA（2/4/8/16），内部直连 ADC | 采样电阻毫伏信号放大 |
| 比较器 COMP | 4 个 | 超快响应，输出可路由到定时器刹车 | 硬件过流保护（BRK） |
| VREFBUF | 1 个 | 2.048 V / 2.5 V / 2.9 V / VDDA | 采样基准 |

### 定时器与数字外设

- **高级定时器**：TIM1（G4 全系都有，互补 6 路 PWM 输出、可编程死区、中央对齐计数、刹车输入、CCR 预装载双缓冲）——这就是电机控制 PWM 的发生器。
- **通用定时器**：多个 16/32 位通用定时器，用于测频、编码器接口、时间基准。
- **通信**：FDCAN、USB FS Device、SPI、I2C、多路 USART、LPUART。
- **存储**：双 bank Flash（可在运行中擦写一个 bank 同时从另一个执行）、SRAM 带奇偶校验、CCM SRAM（零等待，适合放实时中断代码）。

**一句话总结 G4 的电机控制价值**：相电流的放大（运放 PGA）、采样（双 ADC 同步）、保护（比较器$\rightarrow$刹车）、PWM 生成（TIM1 互补输出）、三角函数（CORDIC）、滤波（FMAC）全部片内闭环，几乎不需要外加模拟器件——这是第 7、8 章跑 FOC 时硬件设计的全部底座。

## STM32G4 的主要应用

STM32G4 的目标市场集中在"把强实时控制算法与功率级直接对接"的领域：

- **数字电源**：服务器电源、充电桩模块、太阳能微逆变器、UPS——G474 的 HRTIM 可实现数百 kHz 开关频率下的高精度数字控制。
- **电机控制**：工业伺服、无人机电调（ST 官方 B-G431B-ESC1 评估板即为此设计）、家电变频（空压机、风机、水泵）、电动工具、服务机器人关节。
- **焊接设备**：逆变焊机的功率级控制。
- **照明与充电**：大功率 LED 驱动、快充协议与功率级协同。

在这些应用里，电机控制是 G4 生态支持最完整的一块：ST 不仅提供芯片，还提供评估板（NUCLEO + X-NUCLEO 系列）、图形化配置工具（MC Workbench）、电机参数自辨识工具（Motor Profiler）、完整的 FOC 固件库（X-CUBE-MCSDK）——本书要讲的正是这条完整的官方路径。

## STM32 生态资源

学习 STM32G4 离不开 ST 的文档与工具体系。按"从入门到排错"的使用频率排个序：

| 资源 | 编号/入口 | 用途 |
| --- | --- | --- |
| 数据手册（Datasheet） | DS12550（STM32G431x6/x8/xB） | 引脚定义、电气参数、外设清单 |
| 参考手册（Reference Manual） | RM0440（STM32G4 全系） | 外设寄存器级细节，2000+ 页的字典 |
| Nucleo 板手册 | UM2079（NUCLEO-G431RB，MB1367） | 板卡资源、跳线、LED/按键、Arduino 引脚映射 |
| 扩展板手册 | UM2383（X-NUCLEO-IHM16M1） | 驱动板电路、接口、电流检测配置 |
| STM32CubeMX / CubeIDE | st.com 免费下载 | 图形化配置 + 一体化 IDE |
| X-CUBE-MCSDK | st.com 免费下载 | MC Workbench + Motor Profiler + FOC 固件库 |
| ST 社区 | community.st.com | 大量电机控制实测问答 |

**工程建议**：读 STM32 文档先分清三个层次——Datasheet 讲"这颗芯片有什么、电气上能扛多少"，Reference Manual 讲"寄存器怎么操作"，User Manual 讲"这块板子怎么用"。本书面向应用层，主要在前两个层次之间取用必要细节；需要寄存器级深挖时，RM0440 是最终依据。

## 本章小结

- STM32G4 = Cortex-M4F @170 MHz + 完整电机控制模拟信号链 + CORDIC/FMAC 数学加速器；
- G431 属 Access 线（128 KB Flash、无 HRTIM），对 10 \textasciitilde{} 20 kHz 级电机控制绰绰有余；
- ST 为电机控制提供了从评估板到固件库的全套官方生态，本书的路线就是这条官方路径。
