# STM32 电机控制套件 P-NUCLEO-IHM03

> **核心命题**　P-NUCLEO-IHM03 是 ST 官方的 G4 入门级电机控制套件：NUCLEO-G431RB 控制板 + X-NUCLEO-IHM16M1 三相驱动扩展板 + GBM2804H-100T 云台电机 + 12 V/2 A 电源。三块板卡通过 Arduino 排针堆叠即成一套完整的"MCU + 功率级 + 电机"实验平台，全部资源对 X-CUBE-MCSDK 一等支持。

---

## 套件总览

按 ST 官方 Data Brief，P-NUCLEO-IHM03 的组成清单：

| 组件 | 型号 | 角色 |
| --- | --- | --- |
| 控制板 | NUCLEO-G431RB | MCU 主控 + ST-LINK 调试器 |
| 三相驱动扩展板 | X-NUCLEO-IHM16M1 | 功率级 + 电流检测 + 保护 |
| 电机 | GBM2804H-100T | 三相云台电机（BLDC/PMSM 两用） |
| 电源 | 12 V 直流适配器（2 A） | 给扩展板功率级供电 |

组装关系一句话：IHM16M1 通过 Arduino 排针堆在 NUCLEO-G431RB 上，电机三线接扩展板输出，12 V 电源接扩展板电源输入，PC 用一根 USB 线连 NUCLEO 的 ST-LINK 口完成烧录与监控。

## NUCLEO-G431RB 开发板

### NUCLEO-G431RB 开发板概述

NUCLEO-G431RB 是 ST Nucleo-64 家族成员（板卡标识 MB1367，用户手册 UM2079），外形与经典的 NUCLEO-F103RB 完全一致：

- **Arduino UNO R3 兼容排针**（CN4/CN5/CN8/CN9）+ **ST Morpho 双排针**（CN6/CN7，把 MCU 全部引脚引出）——X-NUCLEO 扩展板就是靠前者堆叠；
- **板载 ST-LINK/V2-1** 调试器：一根 USB 线完成编程、调试、虚拟串口（VCP）三件事；
- **供电灵活**：USB 5V、外部 E5V、或由扩展板反向供电（IHM16M1 堆叠后通过排针向 Nucleo 供电，相关跳线 JP1/JP3 的状态见 UM2079）；
- 板上默认不焊装外部主晶振，系统时钟由片内 HSI16 经 PLL 倍频到 170 MHz。

### NUCLEO-G431RB 开发板的硬件构成

板载 MCU 为 STM32G431RBT6（LQFP64），资源回顾见第 1 章表 1.2。板卡级资源（按 UM2079）：

| 资源 | 说明 |
| --- | --- |
| LD2（绿色用户 LED） | 接 PA5（焊桥 SB6 接通时）；写 1 点亮。第 4 章点灯实验用一个就是它 |
| LD1 / LD3 | ST-LINK 通信指示 / 板卡电源指示 |
| B1（蓝色用户按键） | 接 PC13，按下为低电平（内部上拉） |
| RESET 按键 | 复位 MCU |
| USART2 | PA2(TX)/PA3(RX)，经 ST-LINK 虚拟串口连 PC——所有 printf 调试都走它 |
| CN1 USB | 接 PC，Micro-AB 口 |
| JP1 / JP3 | 电源选择跳线（USB / E5V / 排针供电的切换，堆叠扩展板时按 UM2079 配置） |

![NUCLEO-G431RB 板面功能块布局（示意）：ST-LINK 区与 USB 在板一端，MCU 居中，用户 LED/按键引到 GPIO，四周为 Arduino UNO R3 兼容排针与 ST Morpho 扩展排针](images/fig_02_nucleo_board.pdf)

**与电机控制直接相关的引脚**：TIM1 的互补 PWM 输出、ADC 通道、比较器输入、运放输入在 64 脚封装上都有固定复用位置；使用 MC SDK 生成工程时这些引脚映射由工具自动完成，无需手工查表——这正是官方套件的价值：硬件设计与软件工具互相咬合，初学者不必在引脚冲突里打转。

## X-NUCLEO-IHM16M1 三相驱动板

### X-NUCLEO-IHM16M1 三相驱动板概述

X-NUCLEO-IHM16M1（用户手册 UM2383）是 ST 面向低压小功率三相电机开发的扩展板，核心特征（ST 官网产品页）：

- 基于 **STSPIN830 单片三相驱动器**（栅极驱动 + 功率级集成）；
- 工作电压 **7 \textasciitilde{} 45 V**，最大输出电流 **1.5 A（RMS）**；
- 支持 **单电阻（1-shunt）与三电阻（3-shunt）** 两种电流检测拓扑；
- 支持 **3-PWM / 6-PWM** 两种控制模式；
- 内建可调阈值 PWM 限流、过流/短路保护、互锁、过温关断、欠压锁定；
- 板上含 **反电动势（BEMF）感知电路**——无感方波（六步）控制专用；
- 母线电压检测与板温（NTC）检测；
- 预留 **霍尔传感器/编码器输入连接器**——第 8 章有感控制用；
- 与 STM32 Nucleo 通过 Arduino 排针机械/电气对接，完全兼容 X-CUBE-MCSDK。

### X-NUCLEO-IHM16M1 三相驱动板的硬件构成

信号链按"功率流"与"信息流"两条线读图：

**功率流**：12 V 电源从输入连接器进入 $\rightarrow$ STSPIN830 内部三个半桥（功率管导通电阻 HS+LS 合计约 1 Ω）$\rightarrow$ 三个输出端 U/V/W $\rightarrow$ 电机三相绕组。STSPIN830 是"驱动+功率级"一体的单片方案，板上没有外置功率 MOSFET——这决定了它 1.5 A 的电流上限，也决定了它配 12 V 小云台电机恰到好处。

**信息流**（全部回流到 G431）：

- 三个低侧采样电阻上的相电流压降 $\rightarrow$ 板上运放调理 $\rightarrow$ G431 的 ADC（三电阻模式）；
- 三相端电压经分压 $\rightarrow$ BEMF 感知电路 $\rightarrow$ G431 ADC（方波无感换相判断）；
- 母线电压分压 $\rightarrow$ ADC（过压/欠压保护与 SVPWM 前馈）；
- 板温 NTC $\rightarrow$ ADC；
- 反方向：G431 TIM1 输出的 6 路 PWM $\rightarrow$ STSPIN830 输入；故障信号 $\rightarrow$ G431。

![X-NUCLEO-IHM16M1 信号链框图：左为 G431 控制信号，中间 STSPIN830 功率级与保护，右侧电机；下方为四路模拟量检测回流链](images/fig_02_ihm16m1_chain.pdf)

**为什么这块板适合入门**：所有电机控制需要的模拟前端（电流采样、电压检测、温度检测、BEMF 感知）都已经设计并调试好，初学者把精力集中在控制算法与 SDK 使用上；1.5 A 的电流上限本身就是一层安全护栏——就算程序写错直通，也不至于酿成大事故（当然保护机制仍然会先动作）。

## 三相云台电机 GBM2804H-100T

套件配套的 GBM2804H-100T 是 iPower（iFlight 旗下）的云台电机，"2804" 表示定子外径 28 mm、高度 04（约 12 mm），"100T" 表示每相绕组 100 匝。汇总厂商公开规格：

| 参数 | 数值（公开资料） |
| --- | --- |
| 结构 | 12 槽 14 极（12N14P），即 7 对极 |
| 相电阻 | 标称约 10 Ω ±5\%（实测普遍在 11 \textasciitilde{} 12 Ω，随温度变化） |
| 相数 / 接法 | 三相，星接（三相线引出，无中性线） |
| 重量 | 约 41.5 g |
| 最高转速 | 约 2180 rpm |
| 建议电压 | 2S \textasciitilde{} 3S 锂电（本书用 12 V 适配器，处于安全区间） |

**为什么学电机控制首选云台电机**：

1. **多极对（7 对极）**：电角频率是机械角频率的 7 倍，低速就能产生足够的电信号，观测器工作条件好；反过来讲，它在很低转速下就有可测的反电动势，无感算法容易成功。
2. **绕组匝数多、电阻大**：电流小（安培级以下），安全性好；电气时间常数 L/R 适中，电流环容易整定。
3. **反电动势接近正弦**：云台电机为平稳定位设计，绕组分布追求正弦度，天然适合 FOC；用作六步方波驱动也能工作，一块电机两种算法都能学。
4. **可直接手掰**：低速力矩适中，实验中直接用手感受力矩变化是重要的调试手段。

需要注意：它没有装配编码器或霍尔，第 8 章的有感实验需要外接霍尔传感器板（IHM16M1 已预留连接器）。

## DC 电源

套件附带 12 V / 2 A 直流适配器，接 IHM16M1 的电源输入端。围绕它做三个预算估算：

- **电机侧**：GBM2804H 相电阻约 11 Ω，星接下线电压除以 2 倍相电阻为相电流上限量级——12 V 满压堵转电流也在 0.5 A 量级，加上运行时大部分电压由反电动势与电抗压降分担，实际工作电流典型在几十到几百毫安，2 A 余量充足。
- **板卡侧**：STSPIN830 导通电阻约 1 Ω（HS+LS），百毫安级电流下管耗 <0.1 W，自然冷却无压力。
- **控制侧**：IHM16M1 通过排针向 NUCLEO-G431RB 反向提供 5 V（经板载稳压），无需额外给控制板供电——具体取决于 JP1/JP3 跳线配置，按 UM2079/UM2383 的堆叠说明操作。

**上电操作纪律**（贯穿全书的实验守则）：

1. 先接电机三相线，再上母线电源；断电顺序反之。带电插拔电机线会产生感应对系统的电压尖峰。
2. 首次运行新固件时，手边放着电源开关；异常啸叫、异常发热立即断电。
3. 电流检测相关参数（采样电阻值、运放增益）来自板卡手册，配置错了电流读数会整体错——这也是第 7 章坚持用 MC Workbench 选官方板卡型号（而不是自定义板）的原因。

## 本章小结

- P-NUCLEO-IHM03 = NUCLEO-G431RB + X-NUCLEO-IHM16M1 + GBM2804H-100T + 12 V/2 A 电源；
- 驱动板核心是 STSPIN830 单片三相驱动器（7 \textasciitilde{} 45 V、1.5 A、1/3 电阻检测、BEMF 感知、霍尔接口）；
- 云台电机 7 对极、约 11 Ω 相电阻，是学习 FOC 与六步方波的理想被控对象；
- 套件的三块板卡与 X-CUBE-MCSDK 深度耦合：板级引脚映射、电流定标全部预置在 SDK 工程里。
