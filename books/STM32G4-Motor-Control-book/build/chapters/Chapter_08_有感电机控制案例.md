# 基于 P-NUCLEO-IHM03 套件的有感电机控制案例

> **核心命题**　霍尔传感器把"猜转子在哪"（无感）变成"看转子在哪"（有感）：启动无需开环强拖、低速与零速性能可靠、动态加载不丢步。本章给 GBM2804H-100T 外接霍尔板，跑通有感方波与有感 FOC，并与第 7 章的无感方案做系统对比——什么时候用无感、什么时候必须有感，是电机工程师的日常决策。

---

## 无刷直流电机的有感方波控制案例

### 霍尔传感器的安装与信号

GBM2804H-100T 本体不带霍尔，需外加霍尔传感器板（市售云台电机配套件，3 个开关型霍尔贴装于定子端面，空间互差 120° 机械角；对 7 对极电机，机械 120° 对应电角 $7 \times 120° = 840° = 2 \times 360° + 120°$，电角相位差仍为 120°——多极对下"机械角差 × p 取模 360°"即电角差）。

![霍尔传感器安装几何（左）与输出波形（右）：三个霍尔空间互差 120°，转子磁极扫过时输出三相方波，电角互差 120°，一个电周期产生 6 个 60° 状态](images/fig_08_hall_geom.pdf)

三个霍尔输出经 IHM16M1 预留的霍尔输入连接器进入 G431。转子每转过一个 60° 电角，霍尔状态码变化一次，一个电周期 6 个状态——正好驱动第 5.3.1 节的六步换相表：

| 霍尔状态 (Hc Hb Ha) | 导通管 | 电流路径 |
| --- | --- | --- |
| 101 | $Q_A^+$ $Q_B^-$ | A 进 B 出 |
| 100 | $Q_A^+$ $Q_C^-$ | A 进 C 出 |
| 110 | $Q_B^+$ $Q_C^-$ | B 进 C 出 |
| 010 | $Q_B^+$ $Q_A^-$ | B 进 A 出 |
| 011 | $Q_C^+$ $Q_A^-$ | C 进 A 出 |
| 001 | $Q_C^+$ $Q_B^-$ | C 进 B 出 |

（具体码序与霍尔安装相位有关——若电机反转，交换任意两根电机线或两根霍尔线即可修正。MC SDK 会根据配置的霍尔相序自动建表。）

### MC Workbench 配置与实验

**配置**：与 7.2 节工程相同，仅把 Feedback 从 Sensorless 改为 **Hall sensors**；填入极对数（7）；SDK 自动完成"霍尔沿 $\rightarrow$ 换相 $\rightarrow$ 速度计算"（相邻霍尔沿间隔 = 60° 电角，倒数即电角速度）。

**实验步骤**：

1. 生成、烧录、上电，给速度指令——**注意与无感的最直观差异：电机从零速直接进入闭环**，没有开环强拖的三段式过程；
2. 低速测试（100 rpm 级）：无感方案在这个速度段观测器信噪比不足会失步或振荡，有感方案平稳旋转；
3. 动态加载：捏轴加载/松开，霍尔实时反映真实位置，换相不受观测器收敛延迟影响，恢复干脆。

## 永磁同步电机的有感 FOC 控制案例

### 霍尔位置反馈在 FOC 中的角色

FOC 需要**连续**的电角度 $\theta_e$（6.2.1 节 Park 变换的输入），而霍尔只给 60° 粒度的离散位置。SDK 的处理方式：**霍尔沿 + 平滑插值**——两个霍尔沿之间按平均角速度外推角度（高速时准确），同时用最近的霍尔沿做误差校正（累积误差每个 60° 清一次）。

### MC Workbench 配置与实验

**配置**：在 7.1 的无感 FOC 工程基础上，Feedback 改为 **Hall sensors**，其余（FOC、3-shunt、速度模式）不变。

**实验与对比**：

| 对比项 | 无感 FOC（第 7 章） | 有感 FOC（本章） |
| --- | --- | --- |
| 启动 | 三段式（定位/强拖/切换），需调参 | 直接闭环，可靠 |
| 极低速 / 零速 | 观测器信噪比不足，不可用 | 可稳定运行（限霍尔 60° 粒度带来的小纹波） |
| 动态响应 | 观测器有收敛延迟 | 位置直接测量，响应快 |
| 硬件成本 | 仅电机 | 电机 + 霍尔板 + 连线 |
| 功率角精度 | 高速时好 | 60° 插值，高速精度足够 |

**低速力矩实验**：给零速指令，用手掰电机轴——电流环会立刻产生保持力矩把轴"顶"回原位（速度环积分对抗扰动）。这个"刚性"是无感方案给不出来的，也是云台、关节、POS 控制的立足点。

### 从套件走向产品

跑通本书全部实验后，自然的下一步：

- **换功率级**：套件的 STSPIN830 上限 1.5 A。更大电流需求可换用 STSPIN32G4（G4 内核 + 栅驱一体的 SiP）、STDRIVE101 + 分立 MOSFET，或直接参考 B-G431B-ESC1（G431 三电阻 FOC 参考设计，无人机 ESC 形态）；
- **换位置传感**：伺服级性能上编码器（SDK 支持）；
- **上 RTOS / 总线**：FDCAN 多节点协调（第 1 章的通信外设），把"单电机实验"组织成"多轴系统"；
- **精读 SDK 源码**：5.x 固件库的 FOC 内核就是第 6 章公式的工业级实现（定点化、抗饱和、观测器离散化细节），是极好的进阶读物。

## 本章小结

- 霍尔三信号给出 60° 电角粒度的转子位置：方波控制直接查表换相，FOC 用"沿 + 插值"合成连续角度；
- 有感方案的核心价值：启动可靠、低速可用、动态快——代价是传感器硬件与连线；
- 无感 vs 有感的选型直觉：风机泵类负载（不要求零速、成本敏感）用无感；云台/关节/定位类负载用有感；
- 套件之上还有一整条 ST 电机控制产品线路（STSPIN32G4、ESC 板、更高压驱动），路径是连续的。
