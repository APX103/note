1 · 问题：速率积分的三个先天缺陷

现有 AirMouse 的指针通路是速率式映射：矫正角速度（或原始角速度）积分成指针位置， 经影子模型钳制与空气墙、换算成 OS 光标偏移。这个结构有三个性质上的（而非调参能解决的）缺陷：

  1. 无界积分：cursor += S·ω·dt 在数学上是开环积分， 陀螺零偏、量化噪声、链路丢包都会线性累积。现有方案靠死区 + 静止再校零压制，属于"减慢漂移"， 不是"消灭漂移"。
  2. 无回中语义：手腕转回自然握姿时，光标不会回来——速率控制天生没有"原点"。 要回中必须显式重置，用户体验上就是"找不到家"。
  3. 轴耦合：体坐标系下积分，设备横滚后手腕的"水平转动"不再对准屏幕水平轴， 光标轨迹斜走。6 轴 Madgwick 输出的姿态若只用于显示而未回填到指针通路，此问题独立于漂移存在。

姿态锚定（attitude-anchored）映射从结构上换掉了积分环节：光标位置直接由姿态相对锚点的偏差给出。 姿态有界（加计锚 roll/pitch、磁锚 yaw），位置便按构造有界——漂移与回中问题同时消失， 轴耦合由水平系偏差角自然解决。代价是工作区受手腕工学限制，这由第 3 节的混合设计吸收。

2 · 核心思想与信号链

坐标与符号约定：滤波器输出体→水平导航系姿态四元数 q（ENU）， 由其取欧拉角 [φ, θ, ψ]（roll/pitch/yaw）。 锚点 qref 是某一时刻保存的参考姿态。光标驱动量取水平系欧拉差 而非 qerr 的欧拉分解——前者实现更直接，且绕开了大俯仰下的万向节奇异性 （俯角工作区 < ±25°，远离 ±90°）：

ψerr = wrap±π( ψ(q) − ψref ),    θerr = θ(q) − θref

矫正角速度在本方案里退居二线：不再驱动光标位移，但保留两个用途——边缘带的"推墙"手感增强 （第 3.3 节）与静止判据。水平系矫正角速度由 ω̂ = R(q)(ω − b̂) 给出， 轴耦合在此一并解决。

3 · 三种控制律与走廊式混合

3.1 纯速率式（现状）

cursor += S · ω̂ · Δt  ——工作区无限，但积分无界、无原点

3.2 纯姿态锚定式

cursorx = W2 · F( ψerr / Ψmax ),   cursory = H2 · F( θerr / Θmax )

其中 F 为奇函数：原点附近线性（斜率即灵敏度），向 ±1 渐进压缩（软墙）。 性质：漂移按构造为零（姿态有界 ⇔ 光标有界）、手腕回正即光标回中、 轴向永远对齐屏幕。代价：工作区 = 手腕工学角度 × 灵敏度，超出即"顶墙"，长距离巡航需要离合操作。

3.3 走廊式混合（推荐）

把工作角域分成三段，兼得两者优点：

区段条件行为等效语义
内区（走廊）|ψerr| < ΨlinF 线性段，增益 Gpos位置控制：回中、零漂、指哪打哪
软墙区Ψlin ≤ |ψerr| < ΨmaxF 压缩段，增益单调递减接近边缘越来越"钝"，提供边界预感
边缘带|ψerr| ≥ Ψmax光标钉死在屏边；锚点以速率 ρ 向 q 追赶（yaw/pitch 分别 slew）速率控制：推墙继续走、无限工作区

边缘带重锚的动力学：光标钉在屏幕边缘的同时，锚点角向当前姿态连续追赶—— ψref ← ψref + ρ·Δt·sign(ψerr)（ρ 即等效速率增益，典型 30~60°/s）。 效果：持续推墙时 ψerr 被锚点追赶压缩回 Ψmax 以内，用户感知是"继续推、光标继续走"； 手腕收回时 ψerr 反向减小、退出边缘带，重锚即刻停止，系统回到位置语义。 推墙期间光标速度 = ρ × Gpos × 屏宽比例，与手腕转多快无关——这正是速率控制的 本征手感，且只在边缘带出现。可选增强：ρ 乘以 (1 + κ·ω̂) 使推墙速度随手腕角速度轻微加速， 弥合位置控制缺失的"速率增益"直觉。

4 · 锚点管理（回中的灵魂）

锚点 qref（实现上只需 ψref, θref 两个标量）是整个方案的"家"。 它的每一次变更都必须满足一条铁律：锚点变更不得造成光标跳变——锚点动，偏差角动， F 的输出必须保持连续（或经过显示层的一阶平滑）。

三种锚点操作与瞬态处理：

操作触发锚点动作光标瞬态
手动回中回中键 / 按键双击ψref,θref ← 当前 ψ,θ设计上应回屏心：一阶趋近（τ≈150ms）而非瞬跳
边缘带重锚|ψerr|≥Ψmax 且同向外推锚点以 ρ 连续追赶（非阶跃）无跳变（光标本就钉在边缘）
离合按住期间松开时刻 ← 当前姿态按住期间光标输出冻结，天然无跳变
明确否决的两个"智能回中" 静止超时自动回中（停手 N 秒把光标拉回屏心）：违反直接操纵（direct manipulation） 直觉——用户的"停"不等于"想要回中"，实测会引发不可预测的光标滑动。 静止超时自动重锚（停手时悄悄把锚点挪到手腕当前角）：看似无害，实则窃取回中语义—— 停手后再转动，光标从新原点出发而非屏心。锚点变更只允许用户显式发起 （按键/离合/推墙），这是本方案交互安全性的底线。

5 · 姿态滤波器接口与选型

本方案对滤波器的需求只有三项：q（水平系姿态）、b̂（零偏估计）、静止标志。 现有 250Hz 融合率与 3–6ms 片内延迟预算完全容纳。选型对比：

Madgwick（现状）Mahony E+I7 态 EKF（WitMotion 式）
显式零偏状态无（β 硬扛，稳态误差角）Ki 积分项即零偏估计显式状态 + 静止分窗
磁航向融合可（梯度含磁）可（e 误差向量含磁）一维观测 + 卡方门控
计算量 @250Hz (FPU)低低中（7×7 矩阵，每 4 拍一次）
改造代价—与现有结构最接近，插拔式重写融合层
对本方案够显示，不够给光标（无 b̂）推荐首选性能上限最高，参数多

关键缺口在第一行：现有 Madgwick 不输出矫正角速度（无零偏态），这正是"感觉理论上能拿到 更准的角速度但实际拿不到"的原因。Mahony 的 Ki 项零偏估计是最低成本的补齐路径； 若追求上限（门控、分窗零偏、静止重对准），WitMotion 式 EKF 的调度结构可直接参考 （见姊妹研究 WitMotion 姿态 EKF 逆向—— 其 ZUPT 四档信任调度与磁门控的设计思想就是为"什么时候信谁"而生）。

静止判据：一条现成的教训 不要采用"窗口峰峰值 + 阈值突破时锚点重置"式静止检测——鼠标的典型动作恰好是慢速匀速转动， 该检测器会把匀速转动误判为静止（WitMotion 算法的实锤缺陷），后果是光标在匀速移动中冻结。 判据应使用瞬时量：‖‖acc‖ − g‖ < τ_a 且 ‖ω‖ < τ_g（典型 τ_a=0.08 m/s²、τ_g=2°/s， 连续 3~5 拍确认）。零偏更新只在静止确认后进行，速率限幅防污染。

6 · 磁锚定与降级阶梯

ICM-20948 内置磁力计，硬件零改动即可启用 9 轴。设计要点是磁是 yaw 的慢参考，不是硬约束：

  1. 标定前置：硬磁/软磁标定（椭球拟合）是使用磁航向的前提，一次性的上电引导流程即可；
  2. 门控融合：磁航向新息 ν = h(q) − Dec，卡方式门控 ν²/(γ²·S) ≤ 1 才融合， 否则本拍拒绝——桌面磁场被音箱/显示器/桌架扭曲时自动退化为 6 轴，而非输出鬼航向；
  3. 降级阶梯（可观测性决定）：
档位传感器行为残余漂移
9 轴（完整）acc+gyro+mag三轴全锚定，光标三轴有界≈0（构造性）
6 轴（磁被门控/未标定）acc+gyroroll/pitch 锚定；yaw 退化为"零偏矫正后的积分"yaw 慢漂（0.005°/s 级 ≈ 亚像素/分钟）
应急（加计异常）gyro only纯姿态积分 + 离合频繁回中三轴慢漂，可用的降级体验

降级是逐轴、平滑、自动的——磁质量决定的是"yaw 锚定的可用时长比例"，而不是"能不能用"。 这一点比追求永远 9 轴更重要：桌面尺度的磁场不均匀性是物理现实，方案必须假设磁会周期性不可信。

7 · 误差预算

误差源典型量级对光标的表现对策
姿态估计噪声 σatt0.1~0.3°（静止，取决于滤波器增益）抖动：σatt×Gpos×屏宽像素死区 0.3~0.5° + 显示一阶滤波（τ≤20ms，避免可感延迟）
零偏残余（静止爬行）0.005°/s（Ki 收敛后）6 轴档位下 yaw 慢漂 ≈ 0.3px/min @1080p 满偏映射静止判据下的零偏慢更新；9 轴下被磁锚定直接吸收
磁干扰（门控拦截上限）γ×σinnov（设计量，如 5σ ≈ 3~5°）被拒绝 → 不影响；漏网 → yaw 锚点偏移收紧 γ；锚点异常检测（静止时航向漂移 > 阈值 → 降级并提示重锚）
回中重复性= 姿态返回精度 ≈ 0.2~0.5°（手腕生理极限为主）回屏心的散布非算法问题；死区半径略大于该值即可"感知为零"
延迟（端到端）传感 LPF 2~4ms + 融合 ~0 + ESP-NOW 3~7ms + HID 1~8ms + OS合计目标 < 20ms（250Hz 融合已满足大半）融合层不做额外平滑；显示滤波 τ 与链路预算合并核算

预算的核心结论：位置噪声取代位置漂移成为主导误差——这是所有锚定式方案的共同命运， 且噪声远比漂移好治理（死区/轻滤波），而漂移只能压制。这笔交换是本方案的根本收益。

9 · 实验验证方案

9.1 离线（不动固件即可做）

  • 滤波器对比：录制桌面静置 + 典型操作数据，跑 Madgwick vs Mahony(E+I) vs 7 态 EKF 三条离线管线，对比：零偏收敛曲线、静止 10 分钟姿态游走（分轴）、匀速旋转段的行为（防冻结）；
  • 磁质量普查：ICM-20948 磁力计在真实桌面工作空间内缓慢平移采样， 绘磁场方向/幅值分布——直接决定 γ 门限与 9 轴可用比例预期；
  • 真值对照：JY901（9 轴模块）同机固定，以其固件输出为参考， 量化自建滤波器的 yaw 误差与漂移。

11 · 开放问题

  1. 大屏映射比冲突：4K 屏 + 手腕 30° 角域意味着灵敏度 ~64px/°，内区增益高放大姿态噪声—— 参数空间第 8 节的死区/滤波是否够用，需 9.2 实测回答；不够则内区增益改两段（细动低增益/快动高增益）；
  2. 磁锚点长期游移：桌面磁场缓变（季节性/桌面临时物件）导致锚点漂移的量化—— 决定回中键的实际使用频率，影响"自动 vs 手动"回中的最终取舍；
  3. 俯仰奇异性边界：Θmax=20° 距奇异尚远，但若未来支持"抬头看屏幕顶端"类大幅动作， 需切换到 qerr 四元数域映射（本设计预留：偏差角仅是 qerr 的一阶投影）；
  4. 双手/左右手切换：锚点与角域的非对称参数（Ψ vs Θ、左右旋优势）是否需要用户档案化；
  5. 与滚动/拖拽手势的正交性：边缘带推墙续航语义是否与"甩动滚动"手势冲突—— 需要手势状态机层面的互斥设计（本篇范围外，留待交互设计篇）。
