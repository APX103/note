双陀螺相减：刚性冗余里的零偏可观测性

概念深潜 · 2026-10-23 · 由 ATOM-IMU（BMI088+BMI270）引出 — 和差分解 · 地球自转锚点 · 失准/同步/恒温的工程账 · 与 9 轴修正、N 颗阵列的分界

§1 缘起：一句没被解释的"双 IMU"

起因是一场对比：Stack-chan Kawaii 机器人头部是一颗 9 轴（BMI270+BMM150），融合靠"外部基准修正"；而 RoboMaster 圈的 ATOM-IMU 模块用了 BMI088 + BMI270 两颗 6 轴，宣称零偏通常 <10°/h、校准环境好时 <3°/h。它的项目页和固件文档都只给结论不给原理——两颗陀螺为什么能压零漂？噪声平均只有 √2≈1.41 倍（3 dB），听着不像主要功臣。

答案藏在一个初看很朴素的操作里：把两颗刚性固连的陀螺输出相减。这个减法做的事情远比降噪深刻——它把"零偏"从"运动"里代数式地剥了出来，让一个原本只在静止时才可观测的量变成了运动中持续可观测。本文把这个概念单独讲透：数学上它是什么（§3–§4）、它的可观测性边界在哪（§4）、工程上每个前提条件值多少误差预算（§6）、完整算法长什么样（§8），以及它和 9 轴 AHRS、N 颗阵列在整个"陀螺补偏"家族里的位置（§9）。

一句话版本：两颗陀螺相减后真实运动完全消失，剩下的只有两颗零偏之差和噪声——于是零偏之差成为一个可以在任意动态下连续监视的量。但差值通道对"两颗一起漂"的共模分量天生失明，绝对零偏仍需静止窗口或外部基准锚定。双陀螺不是魔法，它只是把误差空间拆成了"看得见的差"和"看不见的和"两半。

§2 单陀螺的困境：零偏与运动不可分

先看没有第二颗陀螺时的问题。陀螺单轴输出建模为：

g(t) = ω(t) + b + n(t)
ω —— 真实角速度（待测）
b —— 零偏（bias / zero-rate offset，慢变）
n —— 白噪声（噪声密度 σ，典型几~十几 mdps/√Hz）

姿态角由积分得到：θ(t) = ∫ω dt。零偏积分起来是线性增长的误差——b = 0.003 dps（即 10.8°/h）一小时就积出 10.8°。白噪声积分是随机游走，按 √t 增长，量级由 ARW（角度随机游走，°/√h）刻画。对 RM 云台、惯导这类"航向靠陀螺裸积分"的应用，零偏是头号敌人。

零偏能不能测出来？静止时能：ω=0 ⟹ g = b + n，采几分钟平均，b 就标出来了。问题在"标完之后"：

  • 零偏不是常数。它随温度、应力、供电、老化慢变（Allan 方差里的 1/f 锅底，即偏置不稳定性）。开机标定的 b 只在标定那一刻是对的。
  • 一旦运动，b 与 ω 在输出里混成一项，g − b = ω 无法自证。控制理论的说法：单陀螺系统中零偏不可观（unobservable）——没有任何输入激励能把它从状态里分辨出来。
  • 9 轴方案的解法是引入外部基准（重力钉 roll/pitch、地磁钉 yaw），用观测方程反推零偏——但基准会被线加速度和磁干扰污染，且赛场电机环境下磁力计基本废掉（见 姿态融合工程指南）。

双陀螺走的是另一条路：不向环境要基准，向冗余要基准。

§3 相减：运动在代数上消失

把两颗陀螺刚性固连在同一块板上（同一角速度、轴对齐、采样同步——这三个前提的代价见 §6）：

g₁ = ω + b₁ + n₁
g₂ = ω + b₂ + n₂

差值通道：d = g₁ − g₂ = (b₁ − b₂) + (n₁ − n₂)   ← ω 消失
和值通道：s = g₁ + g₂ = 2ω + (b₁+b₂) + (n₁+n₂)   ← ω 保留

差值通道里，不管机器人转多猛、机动多复杂，真实运动 ω 在代数上被完全减掉。d 里只剩两颗零偏之差 Δb = b₁−b₂ 和合成噪声。这就是那个"两个证人"的比喻：两个刚性固连的陀螺必然感知同一个世界，它们证词的分歧不可能来自世界，只能来自证人本身——各自的说谎习惯（零偏）和口吃（噪声）。

有一个代价要说清楚：差值通道的噪声更大了——两路独立噪声相减，方差相加，σ_d = √(σ₁²+σ₂²)，比单路还大。但这不要紧：Δb 是慢变量（零偏不稳定性在分钟~小时尺度），用分钟级的低通去估它，噪声按 1/√T 压下去。按 BMI088+BMI270 的噪声水平（σ_d ≈ 15.7 mdps/√Hz），10 分钟平均后 Δb 估计噪声 ≈ 0.5 mdps ≈ 1.8°/h 当量——和 3°/h 的目标同一量级，够用但不白给，这正是 ATOM-IMU 校准流程要反复静置等待的原因。

§4 和差分解：双陀螺到底买到了什么

把两颗零偏看作二维平面上的一个点 P = (b₁, b₂)。所有可能的双陀螺算法——平均、加权、差分——本质上都在这个平面上做投影。而差值通道的几何意义是：它只照亮了 (1,−1) 这一个方向。

这就是"买到了什么"的完整清单——以及没买到什么：

  • 买到了：运动中连续的 Δb 观测。单陀螺零偏只在静止窗口可测，双陀螺的 Δb 在任意动态下都在监视中。温漂、应力漂移这些"两颗各漂各的"的分量，大多落在差方向，被跟住。
  • 买到了：故障检测与隔离。d 的统计量被连续监控，某颗陀螺饱和、通信毛刺、焊点开裂时 d 会瞬间跳出门限——χ² 残差检验即可定位坏颗（§7）。单陀螺系统坏了自己都不知道。
  • 顺手拿到：一点降噪。但注意账要算准——见下面的数字，对 BMI088+BMI270 这个组合，平均的收益小到几乎可以忽略。
  • 没买到：共模漂移的可见性。温度同升同降引起的共同漂移、板上同源供电纹波、基板共同形变——这些落在和方向的分量，d 完全无感。两颗一起说谎，证词依然一致。
  • 没买到：绝对零偏的连续性。Δb 只是差，绝对水平 Σb = b₁+b₂ 仍需静止窗口（或外部基准）锚定。锚点之间，Σb 的漂移是开环的。
算一笔让人清醒的降噪账：BMI088 陀螺噪声密度 0.014 dps/√Hz，BMI270 性能模式 <0.007 dps/√Hz——BMI088 噪声是 BMI270 的两倍。反方差加权平均后 σ = σ₁σ₂/√(σ₁²+σ₂²) ≈ 0.0063 dps/√Hz，折合 ARW ≈ 0.38°/√h，对比 BMI270 单颗的 0.42°/√h——只赚了约 1 dB（若傻乎乎等权平均，0.0078 dps/√Hz，甚至比单颗 BMI270 还差）。结论：这个组合里，"两颗平均降噪"是个几乎不存在的卖点；差值通道的可观测性才是全部意义所在。想靠堆颗数压白噪声是 N 颗阵列的事（见 IMU 阵列调研，32 颗才有 5.7 倍）。

§5 地球自转：那个容易被忘掉的免费锚点

ATOM-IMU 固件里有一条命令 ahrs set_location 55.87 -4.29（示例坐标是格拉斯哥）。为什么要输纬度？因为静止标定时，陀螺读到的不是零——是地球自转。

  • 地球自转角速率 15.041°/h ≈ 4.18×10⁻⁵ rad/s，方向沿地轴。在纬度 φ 处，它的竖直分量 = 15.04·sin(φ)°/h——北京（39.9°N）约 9.7°/h，比 ATOM-IMU 整机 10°/h 的零偏指标还大。
  • 也就是说：想校准到 3°/h 量级，静止读数里最大的"信号"根本不是零偏，是地球在转。不输入纬度、不按当前姿态把 Ω_earth 投影扣掉，标定就是拿地球自转当零偏存了起来。
  • ATOM-IMU 校准判据"绝对值 <0.00003"（结合其 3°/h 的宣称，单位应为 rad/s）换算正好是 6.2°/h，理想值 0.000015 rad/s = 3.1°/h——判据数字和宣传指标严丝合缝，说明设计者把这笔账算到了 rad/s 小数点后第五位。

换个角度看，地球自转也是一个免费的绝对基准：静止时每颗陀螺的读数 = 自身零偏 + 姿态相关的地球自转投影。已知纬度和姿态，零偏可以不依赖任何外部仪器地标定——这给"和方向"的锚定提供了物理依据。代价是要知道姿态（水平靠加计，方位角未知时需旋转对齐流程），所以实践中表现为"多面静置 + 等待"的长流程。

§6 四个前提，每个都值一份误差预算

§3 的推导建立在四个前提上：刚性、对齐、同步、同温。它们不是口号，每个都能折算成具体数字。

前提一：对齐（失准角）——差值通道的第一杀手

两颗芯片的坐标系若有失准角 θ，ω 会经叉乘泄漏进差值通道：d ≈ θ×ω。数字：失准 1°、载体 100 dps 时，泄漏 ≈ 1.75 dps——而想观测的 Δb 信号只有 ~0.003 dps（10°/h 当量），淹没 600 倍。所以差分方案必须先做相对安装矩阵标定：转动载体，用数据最小二乘解出 3×3 矩阵 R₁₂ 使 g₁ ≈ R₁₂·g₂，把失准压到毫弧度级，差值通道才可用。注意这与传统的"各自对齐到载体坐标系"不同——差分只关心两颗之间的相对关系，共模的安装误差被减法自动消掉，这是差分方案对标定的一项"优惠"。

前提二：同步（采样时刻）——角加速度的影子

两颗采样时刻错开 τ，d 里就混进 ω̇·τ（角加速度乘时间差）。数字：云台以 1000 dps² 加速、错位 10 µs，误差 0.01 dps = 36°/h 当量，又是信号量级的 3 倍。且这项误差在剧烈机动时最大——恰是你最需要零偏监视器的时刻。ATOM-IMU 用 FSYNC 硬同步（数据手册 FSYNC 延迟典型 8.5 µs、采样周期约 500 µs），把两颗的采样时刻锁到同一触发。软件轮询读两颗 SPI/I2C 设备的做法，毫秒级的错位在差值通道里是灾难。

前提三：刚性（基板应变）——"共点"假设的裂缝

刚体上所有点角速度相同，这是 ω 成为共模信号的物理前提。但 PCB 不是刚体：温漂形变、安装应力、振动模态都会让两颗芯片之间产生微小转动。1 µrad 的相对形变率在 100 Hz 振动下等效于 1 µrad × 2π×100 ≈ 6.3×10⁻⁴ dps 的差模污染——已在信号量级。对策是老老实实的机械设计：两颗靠近、对称摆放、远离螺钉孔和板边（应力集中区），螺钉三点安装定义平面（详见 阵列调研§7，32 颗的作者用整节讲这个）。

前提四：同温（恒温）——把"和方向"的漂移按住

零偏温度系数普遍在每开 0.01~0.1 dps 量级：取 0.015 dps/K，即 54°/h·K——温度每变 1 开，一小时积分漂 54°，比整机指标大五倍。图 2 已经说明恒温的定位：差值通道只管差方向，和方向的温漂必须靠"让它不发生"。ATOM-IMU 的做法是 STM32 PWM 驱动加热电阻，把两颗恒温在 45°C（选在环境温度上限之上，只需加热不需制冷，控制单向简单），两颗热耦合同步升温——README 里"两个 IMU 温度同步，修改一个即可"说的就是这个。恒温之后残余的独立温漂（每颗系数不同）落进差方向，被差值通道接管。至此图 2 的三个子空间各有其主，闭环。

§7 附赠品：χ² 故障检测——永远在岗的体检医生

差值通道还兼职"健康监控"。定义残差 r = d − Δb̂（差值减去已估计的零偏之差）：健康状态下 r 只有噪声，方差已知（σ₁²+σ₂²），rᵀr/σ_d² 服从 3 自由度 χ² 分布；设门限（如 99% 分位），超限即说明至少一颗陀螺的行为脱离了统计模型——饱和、卡死、SPI 毛刺、脱焊。再结合两颗各自与加计/上一拍预测的一致性即可隔离坏颗，系统降级为单陀螺继续工作并报警。惯导与航空领域管这叫 FDI（fault detection and isolation），双陀螺是它能落地的最小冗余配置——两颗是能投票的最少人数：无法多数表决找出坏的那颗，但配合其他传感（加计一致性、模型预测）可以做归因。这也是为什么安全相关系统（车载 ASIL-D、飞行器）天然要冗余 IMU：不是为了精度，为了能发现自己坏了。

§8 完整蓝图：双通道算法

# 两路陀螺已硬件同步（FSYNC），各自减去过出厂/静态标定的粗零偏
for (g1, g2) in imu_stream:                    # 3×1, rad/s
    g2 = R12 @ g2                              # 相对失准校正（数据标定解出，§6-一）
    d  = g1 - g2                               # 差值通道：理论 = Δb + Δn，ω 已消失
    r  = d - d_hat                             # 残差
    if r.T @ r / var_d > chi2_gate:            # χ² 门限（§7）
        isolate_faulty(); continue             # 定位坏颗 → 降级单陀螺 + 报警
    Kd = adapt(timeconstant='minutes')         # 机动大时收紧（同步残差污染，§6-二）
    d_hat += Kd * r                            # 慢低通更新 Δb
    if stationary(window='60s'):               # 静止窗口：和方向锚点（§5）
        omega_e = earth_rotation(R_body, lat)  # 15.041°/h 按姿态投影
        s_sum += Ks * ((g1 + g2) - 2*omega_e)  # 扣掉地球自转再锚 Σb
    b1_hat = 0.5*(s_sum + d_hat)               # b₁ = (Σ+Δ)/2
    b2_hat = 0.5*(s_sum - d_hat)               # b₂ = (Σ−Δ)/2
    w = var2 / (var1 + var2)                   # 反方差权：噪声小的多信
    omega = w*(g1 - b1_hat) + (1-w)*(g2 - b2_hat)   # 输出

两个实现细节值得强调：其一，Δb 的更新增益 Kd 应随机动强度自适应收紧——剧烈角加速度时同步残差（§6-二）污染差通道，宁可不更新也不能让脏数据进估计；其二，"静止"的判据要保守（多窗口、加计方差 + 陀螺能量联合判决），匀速旋转被误判静止会同时污染锚点和 Δb——这个坑 WitMotion 上位机就踩过（见 JY901 逆向笔记）。

§9 家族图谱：四种"陀螺补偏"路线的分工

方案信息来源对零偏做什么强项软肋
单陀螺 + 开机标定无静止窗口拍快照，之后开环零成本温漂后快照失效；坏了不知道
9 轴 AHRS（Mahony/EKF）外部基准：重力 + 地磁EKF 偏置态/积分项慢速估计姿态长期有锚，无需冗余硬件磁干扰、机动时基准被污染需门控；yaw 精度上限=磁环境
双陀螺差分（本文）冗余：差值通道Δb 运动中连续观测 + χ² 故障检测；Σb 仍需静止锚不依赖任何外部场；顺带完整性监控共模漂移盲区；√2~1dB 降噪聊胜于无；同步/失准门槛高
N 颗阵列（N≥4）统计：√N 平均 + 阵列信号处理白噪声 ÷√N；干扰/离群投影剔除ARW 指标级提升（32 颗 ≈5.7×）共模地板；成本、同步与算力复杂度陡增

四条路线不是互斥而是正交的拼图：ATOM-IMU = 双陀螺差分 + 恒温 + 地球自转锚（3°/h 级纯惯性航向，不需要磁力计——赛场电机环境下这是清醒的选择）；手机/机器人常见的 9 轴 = 给 yaw 找外部基准；地图级惯导 = 阵列 + 差分 + 温控全上。学术脉络上，这套冗余思想叫 virtual gyroscope / 虚拟陀螺：Bayard & Ploen 2002 年在 JPL 报告 Foundations of Virtual Gyroscope Synthesis（JPL D-21656）建立了从廉价 MEMS 阵列合成高性能虚拟陀螺的框架，Vaccaro & Zaki 2017 的开放获取论文是很好的现代入门（见页脚链接）。

§10 拍板：什么时候值得上双陀螺

值得：应用靠陀螺裸积分推航向、外部基准不可靠或间歇（RM 云台、GNSS 拒止备份、无磁环境）、或需要传感器自诊断完整性。此时差分通道提供的"运动中零偏观测 + 故障检测"是单颗加钱也买不到的能力。
不值得：已有可靠外部基准（VIO/GNSS/干净磁环境）且任务时间短、或只是嫌噪声大（那是阵列或滤波的事）、或两颗装在不同结构上通过柔性连接（刚体前提崩塌，差通道全是结构动力学）。
自己做的检查清单：① 两颗选不同型号（误差去相关 + 特性互补 + 供应安全——同批同型号共模风险高）；② 靠近、同向、对称布局，远离螺钉/板边，三点安装；③ FSYNC 硬同步或同源 CLKIN + 片内时间戳对齐；④ 相对安装矩阵数据标定（转几圈最小二乘解 R₁₂），验证残差进入 mdps 级；⑤ 加热电阻 + 恒温点设环境上限之上；⑥ 静止锚定流程内置地球自转补偿（输入纬度）；⑦ 验证三件套：单颗 Allan 方差 → 差值通道审计（d 的慢变轨迹就是 Δb 的真实演化）→ 整机 yaw 漂移实测。先把 ④⑥ 做对，再谈 3°/h。
