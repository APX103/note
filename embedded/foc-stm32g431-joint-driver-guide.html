FOC 算法落地 STM32G431：机器人关节驱动从原理到代码架构

技术报告 · 2026-09-23 · 讲清四件事：电磁学底座、FOC 在算什么、G431 拿什么算、代码怎么搭

§0 为什么是 FOC + G431

机器人关节的要害是力矩要平滑、响应要快、体积要小。六步换相（方波驱动）每 60° 电角换一次相，力矩纹波大、低速有顿挫、有换相噪声——用在关节上就是"齿轮感"和异响。FOC（Field-Oriented Control，磁场定向控制）把三相电流当成一个可以连续旋转、连续调幅的电流矢量来控制，力矩恒定无纹波、低速到零速都平稳、电流利用率最高，所以关节驱动清一色 FOC。

而 STM32G431 的选型逻辑一句话：FOC 电流环需要的整条信号链——放大（运放 PGA）、采样（双 ADC 同步）、保护（比较器→刹车）、运算（CORDIC/FMAC 数学加速器 + M4F 浮点）、输出（TIM1 互补 PWM）、通信（FDCAN）——全部在一颗芯片里，几乎不需要外加模拟器件。本文按"电磁学底座 → FOC 原理 → 算法 → G431 硬件映射 → 代码架构"五层展开，原理求简，实践求细。

§1 电磁学底座：四块基石

FOC 的全部公式只站在四块基石上，不需要麦克斯韦方程组。每一块都直接对应后文的一个环节——记住这四块，后面所有"为什么"都能落回来。

1.1 电流生磁：定子绕组就是三块可控电磁铁

导线通电，周围产生环形磁场，方向由右手定则给出（右手握导线，拇指指电流，四指弯曲的方向就是磁场方向）。绕成线圈后匝数把磁场放大 \(N\) 倍——这就是电磁铁。定子上嵌着三个绕组，轴线互差 120°，各自电流产生的磁场矢量叠加，得到一个大小和方向都由三相电流比例决定的合成磁场。这个"合成磁场矢量"就是后文所说的"电流矢量"的物理实体：控制三相电流的比例，就是控制这个矢量的方向和幅值。

1.2 磁场施力：力矩的来源

磁场中的载流导线受力（安培力，微观上是洛伦兹力），一根长度 \(L\)、电流 \(i\) 的导线在磁场 \(\mathbf{B}\) 中受力：

\[ \mathbf{F} = i\,\mathbf{L} \times \mathbf{B} \qquad \text{（方向由叉积决定，垂直于两者所在平面）} \]

把它宏观化：转子永磁体自带磁场 \(\mathbf{B}_r\)，定子电流造出磁场 \(\mathbf{B}_s\)，两个磁场像两块磁铁一样相互作用。作用在转子上的力矩正比于两者的叉积——夹角 90° 时最大，同向时为零。这就是 §2 整个 FOC 控制目标的出发点。

1.3 磁生电：反电动势，速度的天花板

转子磁铁转过定子绕组，绕组里感应出电动势（法拉第定律），它对抗外加电压，所以叫反电动势，记作 \(e\)，幅值正比于转速：\(e \propto \omega\)。这解释了两件事：其一，转速越高，反电动势吃掉越多母线电压，电机存在最高转速上限（弱磁可以突破它，见 §2.3 的 \(i_d\)）；其二，反电动势是转子位置的"广播信号"——无感 FOC 正是从电压电流里"听"出反电动势来估计转子角度的（§4.3 CORDIC 的 atan2 在这里登场）。

1.4 绕组的电路模型：电流环被控对象的真身

每个绕组电气上就是一个电阻串一个电感：电流 \(i\) 流过电感 \(L\) 建立磁链，端电压要同时供养电阻压降、电感压降和反电动势：

\[ v = R\,i + L\,\frac{\mathrm{d}i}{\mathrm{d}t} + e \qquad \Longleftrightarrow \qquad \frac{\mathrm{d}i}{\mathrm{d}t} = \frac{v - e - R\,i}{L} \]

读右边这个式子：电压是"油门"，电流是"车速"，电感是"惯性"。想让电流快速、精准地跟上指令，就得靠一个控制器不停地调电压——这正是电流环 PI 的工作，而 §3.5 的整定闭式解 \(K_P = 2\pi f_{bw} L\)、\(K_I = 2\pi f_{bw} R\) 就是从这个一阶方程直接导出的。电机参数 R、L 不是玄学，是这个模型的两个系数。

1.5 电机结构速览：极对数与"电角度"

转子上的永磁体有 \(p\) 对磁极（常见关节电机 7 对或 14 对）。转子机械转一圈，气隙磁场扫过 \(p\) 个完整周期，所以绕组里的电信号频率是机械频率的 \(p\) 倍，两者的换算就是电角度：

\[ \theta_e = p\,\theta_m + \theta_0 \qquad \text{（电角 = 极对数 × 机械角 + 标定零点）} \]

最后两个"为什么"：为什么是三相？三个互差 120° 的绕组通对称三相电流，合成磁场幅值恒定、匀速旋转（两相也行但每相要扛全功率，三相最省铜最经济）。BLDC 和 PMSM 有什么区别？按反电动势波形分：梯形波→配六步换相（方波电流），正弦波→配 FOC（正弦电流）；结构上经常是同一种电机，差别主要在绕组分布设计。关节电机一律是正弦反电动势的 PMSM + FOC。

§2 FOC 原理：最短路径讲透

2.1 电机里到底发生了什么

把 §1.2 的结论写完整：PMSM 的输出力矩是转子磁场与定子磁场叉积的结果——

\[ T \;\propto\; \bigl|\mathbf{B}_r \times \mathbf{B}_s\bigr| \;\propto\; \sin\theta_{gap} \qquad \text{（}\theta_{gap}\text{ 为两磁场夹角，90° 时力矩最大）} \]

所以 FOC 的全部目标就一句话：不管转子转到哪个角度，都让定子电流产生的磁场方向始终垂直于转子磁场。垂直 ⇒ 每安培出力矩最大且恒定；偏离 90° ⇒ 同样电流出力变小且波动。六步换相的问题是磁场夹角在 60°~120° 之间来回摆，纹波就来自这里；FOC 让夹角锁死在 90°，纹波消失。

2.2 三个坐标系：abc → αβ → dq

直接控制三相交流量（三个 120° 错开的正弦波）很别扭，FOC 的思路是换坐标系，把"交流"变"直流"：

  • abc：三相定子坐标系，三个随时间变化的正弦电流——物理真实存在，但难控制。
  • αβ：两相静止坐标系（Clarke 变换得到）。α 对齐 A 相绕组轴，β 领先 90°。两个量仍是交流，但少了一个变量，且与 PWM 合成（SVPWM）天然同平面。
  • dq：两相旋转坐标系（Park 变换得到），d 轴对准转子磁场方向、q 轴领先 90°（正是目标垂直方向）。站在这个跟着转子转的坐标系里看，定子电流是两个直流量：\(i_d\)（与转子磁场同向，励磁分量）和 \(i_q\)（垂直，力矩分量）。
图 1 · 坐标系与矢量：转子转到哪，θe 由编码器实时给出，电流矢量被控制指向 q 轴

2.3 直流电机类比（记住这个就懂了 FOC）

变换到 dq 系之后，PMSM 在数学上变成一台解耦的直流电机：\(i_q\) 就是"电枢电流"，直接比例于力矩；\(i_d\) 就是"励磁电流"，对表贴式转子（SPM）我们把它压到 0（不增力矩只会浪费电流和发热），高速弱磁时才给负值去"抵消"转子磁场、压低反电动势。于是整个控制问题退化为：用两个 PI 控制两个直流量，再变换回三相去执行。这就是 FOC 的全部。

2.4 完整控制环路

外环（位置/速度）输出 \(i_q\) 指令，电流环负责让实际 \(i_d\)、\(i_q\) 跟上指令。环路里每个框就是一个算法模块，§3 逐个讲怎么算，§4 讲 G431 拿什么算：

§3 FOC 是怎么算的：逐模块公式速讲

以下公式全部是"每拍执行一次"的离散运算，没有任何迭代或收敛问题——这是 FOC 看似神秘、实则工程友好的原因。

3.1 电流采样

三相电流之和恒为零，采两相即可推出第三相。主流方案两种：低侧采样（两个电阻串在下管源极到地，便宜，但必须在下管导通窗口内采样，见 §4.1）和相线 inline 采样（电阻+差分运放串在相线，任意时刻可采，成本高）。G431 的双 ADC 同步采样两相，正好匹配两电阻方案。

3.2 Clarke 变换（abc → αβ，降维）

\[ i_\alpha = i_a \qquad\qquad i_\beta = \frac{i_a + 2\,i_b}{\sqrt{3}} \;\approx\; (i_a + 2\,i_b)\times 0.5774 \qquad\qquad i_c = -i_a - i_b \]

等幅值形式（保持变换前后矢量幅值不变，电流的物理安培数直接可用）。计算量：2 次乘 1 次加（√3 提前折算成系数），浮点约 15 个周期。就这么多。

3.3 Park 变换（αβ → dq，旋转到转子视角）

\[ i_d = \;\;\, i_\alpha\cos\theta_e + i_\beta\sin\theta_e \qquad\qquad i_q = -\,i_\alpha\sin\theta_e + i_\beta\cos\theta_e \]

角度来自编码器（\(\theta_e = p\,\theta_m + \theta_0\)，§1.5）。这是整个 FOC 里唯一需要三角函数的地方之一（sinθ、cosθ 成对出现）。计算量：4 乘 2 加很便宜，贵的是那对 sin/cos——这正是 §4.3 CORDIC 登场的原因。物理含义：把电流矢量投影到"转子磁场方向（d）"和"垂直方向（q）"上，投影结果在稳态是直流量。

3.4 dq 系 PI 调节（把直流误差变成电压指令）

\[ v_d = K_{P,d}\,\bigl(i_d^{*} - i_d\bigr) + \int K_{I,d}\,\bigl(i_d^{*} - i_d\bigr)\,\mathrm{d}t \qquad (i_d^{*} = 0\ \text{，SPM 压 d 轴}) \]
\[ v_q = K_{P,q}\,\bigl(i_q^{*} - i_q\bigr) + \int K_{I,q}\,\bigl(i_q^{*} - i_q\bigr)\,\mathrm{d}t \qquad (i_q^{*}\ \text{来自速度环}) \]
\[ \text{输出限幅：}\quad \sqrt{v_d^2 + v_q^2} \;\le\; \frac{V_{dc}}{\sqrt{3}} \qquad \text{（电压限幅圆 + 积分钳位抗饱和）} \]

被控对象就是 §1.4 那个 R–L 一阶惯性，PI 参数有闭式解（带宽法，§5.5）。教科书上还有交叉解耦前馈项（\(v_d \mathrel{-}= \omega_e L_q i_q\) 等），关节电机转速不高、交叉项小，绝大多数关节实现直接忽略，靠 PI 的积分顶掉。

3.5 反 Park 变换（dq → αβ，转回定子平面）

\[ v_\alpha = v_d\cos\theta_e - v_q\sin\theta_e \qquad\qquad v_\beta = v_d\sin\theta_e + v_q\cos\theta_e \]

与 Park 用同一对 sin/cos（CORDIC 一次调用两个都给出），4 乘 2 加。至此，"转子视角的直流指令"已经变回"定子平面的旋转电压矢量 \((v_\alpha, v_\beta)\)"，剩下的问题是：三相逆变器只有 6 个开关，怎么输出一个任意方向、任意幅值的电压矢量？——SVPWM。

3.6 SVPWM（αβ 电压 → 三相占空比）

三相半桥共 8 种开关组合：6 个有效矢量（幅值 \(2V_{dc}/3\)，方向互差 60°）+ 2 个零矢量。SVPWM 的原理是用相邻两个有效矢量 + 零矢量按时间加权，在一个 PWM 周期里"平均出"目标矢量，七段式对称排布使谐波最小。其线性区可达 \(|v| \le V_{dc}/\sqrt{3}\)，比正弦 PWM（\(V_{dc}/2\)）多 15% 母线利用率——同样母线电压出更大力矩。

教科书做法要判扇区、解三角方程；工程实现用等价的 min–max 注入法，零分支判断，是嵌入式实现的标准姿势：

\[ V_a = v_\alpha; \qquad V_b = \frac{-v_\alpha + \sqrt{3}\,v_\beta}{2}; \qquad V_c = \frac{-v_\alpha - \sqrt{3}\,v_\beta}{2} \qquad \text{（投影回三相幅值）} \]
\[ V_{off} = -\,\frac{\max(V_a,V_b,V_c) + \min(V_a,V_b,V_c)}{2} \qquad \text{（共模注入，等效七段式）} \]
\[ \mathrm{duty}_x = \frac{1}{2} + \frac{V_x + V_{off}}{V_{dc}} \qquad (x = a,b,c\ \text{，写入 TIM1 的 CCR 寄存器}) \]

4.1 信号链总指挥：TIM1（一切都由它同步）

FOC 实时性的灵魂是"采样时刻与 PWM 相位精确锁定"。TIM1 配成中央对齐模式（计数器上数到峰值再下数到零，一个 PWM 周期 = 上数 + 下数），同时承担四个角色：发互补 PWM（带死区）、在计数器谷底硬件触发 ADC、接受比较器触发的刹车（BRK）、CCR 预装载双缓冲（本周期写入的占空比在下个更新事件才生效，杜绝毛刺）。20 kHz 时 ARR ≈ 4249（170 MHz ÷ 2 ÷ 20 kHz − 1）。

图 3 · 一个 PWM 周期内的时间轴：谷底采样 → ISR 计算 → 下个更新事件装载新占空比

为什么钉在谷底：低侧采样方案里，谷底对应三相下管全部导通、相电流全部流过采样电阻的时刻；且此刻离任何开关沿最远，开关噪声对 ADC 的串扰最小。这个"何时采样"的决策由 TIM1 触发 ADC 在硬件层面完成，与软件执行无关——软件晚一点进中断只影响控制延迟，不会破坏采样时刻的准确。这就是 G431 方案"力矩干净"的底层原因。

4.2 片内运放 PGA + 双 ADC：电流采样的前半程

采样电阻上的电压通常是毫伏级（例如 1 mΩ 电阻走 20 A 只有 20 mV），必须放大后才能喂给 ADC。G431 的做法：运放编成 PGA 模式（增益 2/4/8/16 由软件切换），同相端接采样电阻，输出在芯片内部直接路由到 ADC 输入通道——零外部运放、零模拟 PCB 走线，这在布板空间以毫米计的关节里是实打实的好处。两路相电流分别由 ADC1/ADC2 在同一触发沿同步采样（同时刻、同孔径，两相电流才可比），0.25 µs 完成转换。慢信号（母线电压、NTC 温度、基准分压）用硬件过采样升到 16-bit，CPU 拿到的已经是平均完的值。

4.3 CORDIC：三角函数从"贵"变"免费"（G431 最特别的东西）

CORDIC（坐标旋转数字计算机）的原理一句话：用一连串固定的微小旋转去逼近目标角，每步只需移位和加法——硬件实现极其便宜，却把三角函数/反三角函数变成了几个周期的外设调用。G431 把它做成了独立协处理器，对 FOC 的意义分三层：

  1. 一次调用出一对 sin/cos。Park 和反 Park 需要同一对 \(\sin\theta_e\)、\(\cos\theta_e\)，CORDIC 的调用约定是：往 WDATA 写入角度（注意格式：θ/π 的 Q1.31 定点，不是弧度原值），RDATA 顺序读出 cos、sin 两个 Q1.31 结果。整个电流环只需这一次三角函数调用。
  2. 省下的周期很可观。软件浮点 sinf()+cosf() 在 M4F 上是上百周期的库函数调用；CORDIC 满配置几十个周期出双结果，且精度随迭代次数可配。更重要的是它是独立外设：启动后 CPU 可以转身去算 Clarke/PI，回头再取结果——流水线并行，不占 FPU。
  3. atan2（phase 模式）是无感 FOC 的钥匙。观测器（反电动势/磁链）从 αβ 电压电流里估计转子角度，最后一步全是从 atan2 出角度（§1.3 说的"听反电动势"）；有感 FOC 也用它做电流矢量角监控、编码器标定校验。CORDIC 的 phase 模式同样几十周期。

诚实的工程账：Park 变换本身（4 乘 2 加）在 M4F 的 FPU 上只要十几个周期，用不用 CORDIC 都算得动；CORDIC 的真正价值是把 sin/cos/atan2 这类"贵函数"从电流环时间预算里拿掉，给观测器、保护、通信腾 CPU。20 kHz 电流环 G431 游刃有余，上到 40 kHz 依然从容。

4.4 FMAC：滤波白嫖一个 MAC 阵列

FMAC 是"滤波器专用小 DSP"：256 字内部 SRAM 划成输入/输出/系数三段，硬件执行 FIR/IIR 的乘累加，可挂 DMA 持续供数。FOC 里的正确用法：放慢环、别放电流环——电流反馈若经低通滤波会引入相位滞后，直接吃掉电流环相位裕度。典型用途是速度估计滤波（差分编码器计数噪声大）、母线电压前馈滤波（\(V_{dc}\) 波动实时折算进 SVPWM）、无感观测器的低通环节。这些滤波从 CPU 的周期预算里整体消失，且不占 FPU。

4.5 保护：比较器 → TIM1 刹车，独立于软件

4 个片内比较器的一路接电流信号（PGA 输出），阈值写 DAC 由软件设定（等效过流门限 = 阈值 ÷ 增益 ÷ 采样电阻）。比较器翻转直接路由到 TIM1 的 BRK 输入，同一个 PWM 周期内封锁六路输出——从过流发生到关断是纳秒级硬件路径，不依赖中断响应，CPU 死循环、栈溢出、看门狗打架时照样关得掉。软件侧再叠一层慢保护（堵转限时、过温、过压欠压）在主循环里巡检。关节会堵转、会摔，这条硬件底线是选 G431 的隐性理由。

4.6 20 kHz 一拍的周期预算（170 MHz）

电流环 ISR 内的动作周期量级由谁执行
中断进出 + FPU 惰性压栈~80内核
读 ADC 结果 + 偏置校正 + 定标~60CPU（DMA 已搬运）
\(\sin\theta_e/\cos\theta_e\)~40CORDIC（期间 CPU 并行算 Clarke）
Clarke~15FPU
Park + 反 Park~40FPU

这就是"单芯片 FOC"的含金量：电流环本身只花掉不到 5% 的算力，剩下 95% 留给速度/位置环、无感观测器（可选）、CAN 协议栈和上层逻辑。把 PWM 提到 40 kHz（预算 4250 拍）依然轻松。ISR 代码链到 10 KB CCM SRAM 上执行，零等待、无 cache 抖动，每一拍的耗时是常数——电流环的确定性就是力矩的干净度。

5.2 实时骨架：一个中断扛电流环，主循环扛一切慢的

整个系统的实时结构极其简单——没有 RTOS 的必要（用了也只是给慢任务分时）：

  • ADC 转换完成中断（最高抢占优先级）＝ 电流环：读两相电流 → 偏置校正 → Clarke → CORDIC 取 sin/cos → Park → PI(d,q) → 反 Park → SVPWM → 写 CCR → 退出。整个 ISR 执行时间常数化（§4.6），必须在一个 PWM 周期内收尾。
  • 主循环（或 RTOS 线程）：1 kHz 跑速度/位置环和 CAN 协议，算出新的 \(i_q^{*}\) 后原子交换交给电流环（单写者单读者，一个 volatile float 就够）；100 Hz 跑温度/母线巡检与故障状态机。
  • 中断优先级从高到低：ADC(电流环) → 编码器定时器 → SysTick → CAN → 其它通信。任何中断都不允许比电流环高，包括你的调试打印。

5.5 整定顺序与调参闭式解

  1. 不接电机：跑 PWM+ADC，示波器/上位机看死区、触发时刻、电流底噪。
  2. 开环 I/F：旋转电压矢量拖动电机空转，验证相序、SVPWM、电流采样链路（这一步电流环还没闭）。
  3. 电角度标定（§5.3 ALIGN）。
  4. 电流环：用带宽法一步到位——
\[ K_P = 2\pi f_{bw} L \qquad\qquad K_I = 2\pi f_{bw} R \]

\(f_{bw}\) 取 PWM 频率的 1/10~1/20（R、L 用万用表+LCR 表或 ST Motor Profiler 自动辨识）。\(i_q\) 阶跃看响应，超调 >20% 就降 \(f_{bw}\)。

  1. 速度环 → 位置环：带宽依次降 5–10 倍，从外向内不许反超内环。
  2. 带上关节负载复验：堵转力矩、温升、CAN 指令到力矩的延迟。

5.6 踩坑速查（每条都是真实事故风格）

① DMA 访问不了 CCM SRAM——把 ADC 的 DMA 缓冲放进 CCMRAM，采到的全是旧数据或 HardFault；CCM 只放代码和纯 CPU 数据。
② CORDIC 角度格式是 θ/π 的 Q1.31，不是弧度；直接喂浮点弧度转的定点会得到"看似有波形、实则角度随机"的灵异现场。
③ M4F 的 FPU 是单精度——代码里混进 double（比如 3.14 字面量传参）瞬间掉到软浮点，ISR 周期翻几倍；全链路强制 float + 3.14f。
④ 电角度 ≠ 机械角度：\(\theta_e = p\,\theta_m + \theta_0\) 忘乘极对数，现象是"电机嗡嗡抖动不转"；θ₀ 没标定，现象是"能转但力矩软、电流大"。多极对数下标定点还要防 360°/p 的机械周期混叠。
⑤ 低侧采样的窗口：占空比接近 100% 时下管导通窗口消失，谷底采到的是开关噪声——重载工况突然电流波形发毛，先查最小脉宽限制。
⑥ FPU 惰性压栈是隐形开销：任何用了 FPU 的中断都有 ~26 字压栈成本，频繁的低优先级浮点中断会偷电流环的时间；慢任务里少用浮点，或降频。
⑦ 电流环里别滤电流（§4.4）；同理别在 ISR 里 printf。

FOC 的原理一页纸：换个跟着转子转的坐标系（Clarke+Park），三相交流变两个直流量的 PI 问题，再变回去（反 Park）用 SVPWM 执行——目标是让电流矢量永远垂直于转子磁场。
G431 的答案一页纸：TIM1 中央对齐 PWM 在谷底硬件触发双 ADC 同步采样片内 PGA 放大过的相电流；比较器→BRK 硬件过流；Clarke/Park/PI/SVPWM 的乘加交给 170 MHz M4F，sin/cos/atan2 交给 CORDIC 协处理器，滤波交给 FMAC；一个 20 kHz 中断 ≈350 周期干完电流环，剩 95% 算力跑速度/位置环和 CAN——这颗芯片就是为这个数据流而生的。
代码骨架一句话：驱动/算法/应用三层 + 一个最高优先级中断扛电流环 + 主循环扛一切慢的 + 一个把顺序走对的上电状态机。
