3322 空鼠垂直切片实录

从星闪链路实锤 → 挂死结案 → IMU→EKF→鼠标流全链  ·  2026-10-13 · 前篇：Hi3322 ↔ EB21duino 星闪链路验证

TL;DR：2026-10-13 一天打穿四个里程碑——SLE 2.0↔1.0 空口互通实锤（"hello server" 双侧确认）→ 100Hz 挂死根因结案（uuid 时序 bug + 确认事件积压，反汇编定案并修复验证）→ ICM20948 接线驱动（whoami=0xEA、重力 0.99g 校准）→ EKF 姿态解算上板：转动开发板，姿态三轴实时跟踪，1294 个真姿态驱动的鼠标包零失败发到 dongle。本文给出全链复现配方（命令、代码改动点、判据、坑史）。

1 · 系统架构（Central-Server）

3322 谛听 V100 (SLE Central)                EB21duino/BS21 (SLE Server)
┌────────────────────────────┐   星闪 P2P   ┌──────────────────────────┐
│ ICM20948 ─I2C0→ EKF7 姿态解算│ ── write ──→ │ write 回调收 dx/dy 包      │
│ → 姿态增量→dx/dy 打包        │  (上行流控)  │  → [M4] USB HID report    │──→ 电脑
│ 100Hz · 窗口4确认流控        │              │ (当前: 聚合打印观察)       │
└────────────────────────────┘              └──────────────────────────┘

dongle=server 广播暴露连接点，3322=Central 扫描连接——连接发起权、重连策略在算力强的一端；上行 client→server write，下行 notify 二期。官方 air_mouse 样例的 mouse=server 是 BLE 惯例平移，弃用（用户拍板）。两端固件均 Mac 自产（3322 走 fbb 原生编译，dongle 走 Docker 容器）。

2 · 硬件与接线（官方文档核对版）

ICM20948（Waveshare 10DOF-D）接谛听开发板依据
VCC 3.3VJ1902 PIN 17/18（丝印 VDD3V3）开发板接口表（vendor/Sunniwell_HiDiTing_Dev_Board/.../sunniwell-hiditing-dev-board.md「1.8V/3.3V I2C 接口」「SPI/UART 接口」节）
GNDJ1901 PIN 9/10
SDAJ1901 PIN 12（丝印 C0_D = I2C0_SDA / MGPIO_5）
SCLJ1901 PIN 11（丝印 C0_C = I2C0_SCL / MGPIO_4）
AD0 悬空地址 0x68（AT 参数写十进制 104）—
  • 拨码 SW1901-5 默认 OFF = I2C0/1 电平 3.3V，与模块 VCC 匹配，无需动。
  • 勿用 J1901 PIN 7/8（I2C1）——板内已接屏 TP，文档明令勿复用。
  • 模组 IO 全 1.8V 域（模组管脚表），开发板排针经拨码做板级电平；模块内置 LSF0204 电平转换。UART2 恒 1.8V——串口适配器（CH347）必须供 1.8V。

3 · 3322 固件：sle_client.c 改动全集

基座 work/hs-fbb（gitcode master），改动全部集中在 samples/native_samples/sle/sle_client.c（搜 [AIM] 注释块定位），外加 quat-zupt-ekf/c/ 五文件拷入同目录并挂 CMakeLists SOURCES。

3.1 模块清单

模块要点
IMU 驱动uapi_i2c_master_writeread（i2c.h:219）组合事务读寄存器；初始化序列：PWR_MGMT_1 软复位→0x01 唤醒→PWR_MGMT_2=0 六轴全开。量程写不进（bank2 回读 0x00），按默认 ±2g/±250dps 刻度：16384 LSB/g、131.072 LSB/dps（重力实测 0.99g 校准过）
EKFekf7_pipeline_init(&ekf, 100.0, 1, 0) + 每拍 ekf7_pipeline_calculate(acc_mps2, gyro_rad_s, NULL, &out)（输入单位与 test_runner CSV 一致）；静置 ~2s 完成对准（align 状态机 0→4）
指针映射Δyaw/Δpitch × 15 px/deg + 0.03° 死区 + motionless 冻结 + ±127 限幅；yaw→x，−pitch→y
发送任务osal_kthread_create_ext（模板抄 dht22.c:435）100Hz；窗口式流控：在飞未确认 <4 才发（write_cfm 回调递减 pending）
回调注册FIND 回调捕获句柄处，用 service[s].service.uuid 的 static 拷贝 + 回调参数 dev_id/client_id 注册——不能用 g_client_app_uuid（step8 才赋值，注册时全零 → 0x8000600a）
睡眠保活任务启动时 uapi_pm_add_sleep_veto_with_symmetry(PM_ID_NATIVE_SAMPLE)（pm_veto.h；ID 枚举 pm_veto_porting.h:104）

3.2 关键架构红线

EKF 无条件每拍跑，绝不 gate 在 SLE 连接状态后面。曾因把 EKF 放在连接检查之后，链路一断姿态就"恒 0"，白查一轮。姿态解算独立于链路。

6 · 坑史（现象 → 根因 → 修法）

现象根因修法
100Hz 流跑 21~42s 后 3322 彻底静默（20Hz 观察窗内未见）两层叠加：① sample 的 g_client_app_uuid 在 FIND 回调 step8 才赋值（且按 SLE_MOBILE_MAX 索引），回调注册传全零 uuid 恒失败 0x8000600a；② 带确认写的完成事件无人消费 → ~2000-4000 包后资源耗尽 → 芯片异常+电气扰动（CH347 USB 掉线重枚举为伴生）。反汇编 bs_sle_ssapc_write(0x266c0aec) 见内部同步 memcpy_s（悬垂指针已排除）+ btos_new 池分配①用刚发现的服务 uuid 的 static 拷贝注册；②write_cfm 回调递减 pending + 4 包窗口流控。验证：sent=14575 fail=0 cfm=14571（差=在飞窗口），7.3 分钟零挂
3322 AT 时灵时不灵，序列中途断低功耗睡眠醒窗仅几秒；PM=0 会被栈 DISABLE/ENABLE 复位冲掉；跨进程命令间隔撞睡眠oneshot 单进程连发（轰 PM=0 到 OK 再走序列）+ 固件内 sleep veto
重复 PAIR 报 0x80006016dongle 挂半开连接（3322 侧重启没断链通知）或栈状态残留3322 先 DISABLE→ENABLE 复位栈；dongle 拔功耗跳帽复位
"挂死"误报（SerialException: device disconnected）macOS 两进程同开一个 cu 口（oneshot 与监听并行）串口独占：驱动与监听串行；流活性看 dongle 侧，最后才短探 3322
EKF 输出 rpy 恒 0EKF 被 gate 在连接检查后（连接失败陪葬）EKF 无条件每拍跑（§3.2）
编译错：packed member 取地址 / unused-Werror 严格集局部变量中转再赋值；(void) 参数
量程寄存器写不进（回读 0x00）未查（疑似 bank 切换时序）按默认量程刻度用（已重力校准），不影响
让用户"转板子"验证总扑空消息与监听同时发出，人反应 >40s先发消息再挂 ≥100s 监听
