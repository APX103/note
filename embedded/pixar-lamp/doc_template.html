机器人动力学建模 · 自研仿真 · CPU 策略训练 · 硬件选型 · RL 训练方案  |  2026-09-23

结论：真的可以。在自研平面多体动力学仿真（经过能量/动量守恒交叉验证）中，一台 1.29 kg 的 Luxo 构型台灯——底盘 + 双连杆 + 灯头，只用两个 317 g 级 QDD 关节电机（峰值 12.5 N·m）加一对 1.5 N·m/rad 平衡弹簧——经 CEM 策略搜索后可以实现：

  • 原地跳：腾空 {{HOP_APEX}} cm（离地速度 {{HOP_VTO}} m/s），落地基本直立 ✅
  • 定向跳：{{LEAP_SUMMARY}} ✅（平面结论，3D 由左右对称双臂 + 跳前转身保证）
  • 三维 MuJoCo 验证（几何 v2：圆片底盘 r=15cm + 圆台灯罩）：稳稳向前跳 ~10cm（前方=肘弯开口方向）、轻腾空 4-5cm、直立落地并起身站立 ✅；底盘偏航转 90° 后朝新方向（102°）跳出 ✅；初始化=半悬浮出生→关节位置PD力锁→落下弹性落定

瓶颈不在电机扭矩（余量充足，{{MARGIN_TORQUE}}），而在起跳时序与姿态协调——这正是强化学习能解、手调很难解的部分，也是本方案把 RL 放在核心位置的原因。

1. 项目解读与先例

目标：复刻 Pixar 片头那盏会跳的 Luxo Jr. 台灯——一盏真的能跳起来的台灯机器人。需求拆解：

能力定义本版覆盖
原地跳下蹲-爆发-腾空-落地自稳✅ 仿真闭环 + CEM 策略

1.1 先例调研：舵机路线已被证伪

  • dheera.net 的 3D 打印 Luxo（GitHub: dheera/robot-luxo）：Savox 舵机驱动，多个舵机协同只能让底座 "scoot along"（贴地滑移），做不出真跳跃；作者也提到为跳跃建模仿真困难。
  • Hackster.io 的 hopping Luxo：Raspberry Pi 3B+ 控制，明确结论是"电机不够快，跳不起来"。
  • Apple ELEGNT（2025.02）：Luxo 构型机器人研究平台，运动表达性极强（注视、鞠躬、示意），但不跳——执行器是低速高精度路线。

执行器拍板：准直驱（QDD）无刷关节电机 ×2 + 并联弹簧，不用舵机。跳跃的本质是 <150 ms 内把几焦耳能量灌进系统：需要峰值扭矩 + 高回转速度 + 低转子惯量三者同时满足，这恰好是 QDD（10:1 行星减速 + 无刷电机 + FOC 驱动一体）的定义。弹簧复刻真 Luxo 的平衡弹簧——蹲下储能、伸展释放，把电机峰值功率需求再降一个档次。

2. 机械结构设计 v1

结构完全沿用 Luxo 的解剖学：半球底盘（含肩电机/电池/主控）→ 下臂 → 上臂 → 灯头，肩、肘、颈三个转动关节。真实 Luxo 是双侧平行双臂 + 张簧；机器人版保留双臂外观、单侧驱动等效（左右臂同轴联动），平面模型取单侧。

图 1 · Luxo 构型侧视与质量预算 v1（站立全高约 470mm，站立质心高 164mm）

2.1 关键设计决策

  • 足底直径从 11cm 加宽到 17cm（真实 Luxo 约 23cm）：动力学仿真显示深蹲姿势质心前移 5.6cm，窄足底必翻；17cm 时静态裕度恢复。这是仿真给出的第一条硬约束。
  • 电池放底盘最低处：压低质心，落地稳定性和蹲姿平衡都受益。
  • 肘电机置于下臂远端：与真 Luxo 的关节盒位置一致，代价是下臂质心外移——仿真已按真实分布计入。
  • 平衡弹簧：肩、肘各一等效扭簧（1.5 N·m/rad，静止位=伸展位），蹲下时储能 6.1 J，起跳时无偿释放；真机上用沿臂拉伸弹簧实现。
  • 灯罩鼻端做接触点：摔倒时以灯罩前缘触地（真实 Luxo 摔倒也是这个姿态），仿真中已建模。

3. 机器人动力学：跳起来到底要多少"本钱"

跳跃的第一性原理是能量与冲量。设总质量 \(m=1.291\,\mathrm{kg}\)，跳高 \(h\) 需要离地速度 \(v=\sqrt{2gh}\)：

\[ v_{\text{离地}}=\sqrt{2gh},\qquad E_{\text{腾空}}=\tfrac{1}{2}mv^2=mgh,\qquad h\;=\;\frac{v^2}{2g} \]
目标跳高 h离地速度 v腾空动能 E滞空时间 t落地冲击（缓冲 8cm）
5 cm0.99 m/s0.63 J0.20 s~2.2× 体重
10 cm1.40 m/s1.27 J0.29 s~2.7× 体重
20 cm1.98 m/s2.53 J0.40 s~3.7× 体重

腾空动能小得惊人——难点从来不是能量总量，而是功率与协调：伸展行程只有约 15-20cm，要在 ~120ms 内完成加速（平均加速度 3-6 g），地面反力峰值 2-4× 体重，同时底盘不能被关节反扭矩顶翻。

3.1 扭矩需求（先验估算，后由仿真校准）

双腿式伸展时，地面反力 \(F\) 经腿雅可比映射到关节扭矩 \(\tau = J^\top F\)。深蹲附近力臂约 8-15cm，取 \(F=35\,\mathrm{N}\)（2.8× 体重）时单关节扭矩约 3-5 N·m，被 DM-J4310-2EC-V2（额定 3.5 N·m / 峰值 12.5 N·m / 317g）覆盖；电机转速上限 21 rad/s 在伸展末段会成为限制——弹簧在末段补扭（见 §5 余量分析）。落地缓冲是更苛刻的工况：1.7 m/s 触地、8-12cm 缓冲行程，关节峰值扭矩约 6-9 N·m，仍在峰值能力内但需要阻抗控制配合。

4. 自研平面多体动力学仿真

没有现成仿真器能直接回答"这盏灯能不能跳"，且先例作者也卡在"为跳跃建模仿真困难"。所以第一步是自研一个可审计的最小动力学内核（sim/lamp_sim.py，仅依赖 numpy，约 400 行）：

  • 模型：浮基座（x, y, φ）+ 肩 θ₁ + 肘 θ₂ + 颈 θ₃ 平面串联链，4 刚体、6 自由度；广义坐标 \(q=[x,y,\varphi,\theta_1,\theta_2,\theta_3]\)。
  • 动力学方程：\(M(q)\ddot q + b(q,\dot q) = \tau_{gen} + J_c^\top F_{contact}\)，质量矩阵由各刚体质心雅可比组装 \(M=\sum_i m_i J_i^\top J_i + I_i J_{\omega,i}^\top J_{\omega,i}\)；偏置项利用平面链的偏置加速度（\(\ddot q=0\) 时的纯向心项）精确计算，无有限差分。
  • 接触：足底两点 + 灯罩鼻端，法向 Kelvin-Voigt 罚接触（含 600N 材料极限）+ 正则化库仑摩擦（μ=0.65 橡胶）。
  • 执行器：峰值扭矩钳位 × 转速线性衰减 × 功率钳位（DM-J4310-V2 实测曲线）；关节库仑摩擦 0.15 N·m；平衡弹簧（保守项，储能不衰减）。
  • 数值：半隐式欧拉 + 关节阻尼/库仑摩擦线性化隐式积分 + 刚性瞬态自动子步。dt=0.4ms，单集 2.2s 仿真约 2s 实机时间。

4.1 验证（这一步不能省）

仿真内核的三次翻车与修复（复现时按此排查）：

  1. 浮基座小等效惯量 + 显式关节阻尼 = 数值爆炸：直立构形附近肩关节的"等效转动惯量"（含动量守恒反作用）可低至 2.6e-4 kg·m²，控制器的微分增益 kd=3 对应阻尼率 12000/s，显式欧拉每步放大 95 倍。修复：阻尼（及后来的库仑摩擦）全部转入隐式积分项 \((M+\Delta t\,D)\dot q' = M\dot q + \Delta t\,Q\)。
  2. 弹簧扭矩误过电机限幅：被动弹簧的扭矩被电机转速-功率曲线削顶，广义力不再等于势能梯度，能量凭空增减。修复：弹簧保守项独立作用，只钳位电机指令。
  3. 罚接触在高速触地时注入能量：阻尼项穿透回弹超弹性。修复：法向力 600N 材料极限 + 刚性瞬态自动子步 + CEM 奖励的物理合理性门限（v>6 m/s 判无效）。

5. 结果 I：原地跳（CEM 策略搜索，纯 CPU）

控制器是参数化的四阶段状态机：SETTLE（平衡下蹲）→ FIRE（时序点火伸展）→ FLIGHT（空中收腿备降）→ LAND（缓冲着陆）。16 个可优化参数（蹲姿、点火扭矩/延迟、姿态反馈增益、备降姿态、着陆刚度…），其中 FIRE 阶段的质心位置反馈 \(\tau_1 \mathrel{+}= k_x(0-x_{com}) - k_{dx}\dot x_{com}\) 是把"内旋转动量"导回竖直推程的关键——对应实机上"关节编码器+IMU 运动学算出质心"的标准做法。

优化器用 CEM（交叉熵方法，pop=40/精英 8/55 迭代，8 核并行，约 {{HOP_WALL}} 分钟 CPU），带域随机化（蹲姿目标扰动）。

7. 硬件方案（拍板版）

7.1 执行器

位置选型关键参数依据
肩、肘达妙 DM-J4310-2EC-V2 ×2峰值 12.5 N·m / 额定 3.5 / 317g / 24V / CAN / 双编码器/MIT 模式仿真余量分析（图 4）；24V 生态成熟、有现成 FOC 驱动经验（本库 FOC 报告）

7.2 电子架构

  • 主板（底盘）：ESP32-S3（TWAI→CAN 总线挂两个关节电机，1kHz 控制循环）+ BMI088 IMU₁ + 磁力计（BNO085 直接出四元数亦可）+ 6S 1000mAh 锂电 → DC-DC 5V/3.3V。
  • 头板（灯罩内）：ESP32-S3 + OV2640 摄像头 + IMU₂，WiFi 图传与姿态流（与主板 ESP-NOW/WiFi 对时）。线缆经中空臂走线，头部转角限制 ±45° 免滑环。
  • 传感汇总：关节位置/速度/扭矩（电机双编码器）×2、颈位置、IMU×2、电池电压电流、足底接触由关节电流 + IMU₁ z 轴联合判定。

7.3 状态估计与方向感知

"知道往哪跳"三层：① IMU₁ 互补滤波给出底盘俯仰/横滚与角速度；② 磁力计给出绝对航向（跳跃方向指令在世界系下表达）；③ 由关节编码器 + IMU₁ 姿态运动学实时算出全机质心位置（CEM 策略正是吃这个状态）；IMU₂ 在头部提供灯头指向（摄像头瞄准）与空中段第二视角姿态。双 IMU 冗余还可以在腾空段交叉校验积分漂移。

7.4 3D 定向跳的实现路径

  1. 平面内定向：本方案仿真已验证（§6）；
  2. 航向调整：连续小跳中用不对称落地 + 落地原地"蹭转"（足底差动摩擦）逐步转向；若不够，底盘加一颗 20g 空心杯做转台电机（备选）；
  3. 左右对称性：双侧平行臂 + 圆形足底，横滚方向与俯仰方向动力学同构（弧形足底等价）。

8. 强化学习训练方案

8.1 阶段 A（已完成）：CPU 上的直接策略搜索

用 CEM 在自研仿真上搜索 16/14 维结构化策略参数（本目录 sim/train_es.py），价值在于：验证可学性（回报单调上升、不依赖运气）、暴露真机必须处理的物理事实（蹲姿平衡、点火时序、落地缓冲），并直接产出第一版可烧录的策略参数。成本：{{HOP_WALL}} 分钟级，Mac CPU 即可。
