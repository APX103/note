STM32H743 摄像头完全教程 / 第 1 章

板卡档案与硬件全景

不知道板子上有什么，后面的一切都是猜。这一章建立完整的硬件心智模型。

1.1 这块板子是什么

WeAct OpenMV Plus v1.1：WeAct Studio 出品的 STM32H743 核心板，板型设计对齐 OpenMV 相机生态（可跑 OpenMV 固件的分支）。主控 STM32H743IIK6，封装 UFBGA176。

项规格备注
CPUCortex-M7 @ 480 MHz双发射超标量，算力对付图像预处理绰绰有余
Flash / SRAM2 MB / 1 MB（ITCM 64K + DTCM 128K + AXI 512K + SRAM1-4）内存域多，链接脚本要规划（第 4 章）
SDRAM32 MB @ FMC跑大分辨率帧缓冲用的，本教程 QQVGA 级用不上
其他外设USB FS、TF 卡（SDIO）、QSPI Flash
调试口SWD（SWDIO/SWCLK），配 ST-Link V2本教程全程只靠它

1.2 摄像头怎么接进来的（两级转接）

套件里那块小「接口板」是无源转接板，信号链是两跳：

OV 摄像头模组 ──FPC 24P 0.5mm──> 摄像头接口板 ──板对板 DF12-36──> 主板 MCU
                  （转接+照明LED）        （DCMI + SCCB 直连）
  • FPC 侧：兼容 OV7670 / OV2640 / OV7725 / OV5640-AF 四种模组（接口板丝印注明）；板上还有 3 颗白光照明 LED、IR LED、以及供 OV5640 自动对焦固件用的电平转换跳线（SB1/SB2，普通成像不用焊）。
  • 板对板侧：D0–D7、PCLK、VSYNC、HSYNC、XCLK、PWDN、RESET、I2C1（SCCB）、照明 LED 控制线，全部一根线一根线地进 MCU。
供电不用管：摄像头模组需要的 2.8V（AVDD/DOVDD）和 1.5V（DVDD）由主板上的两颗 LDO（XC6206P282 / XC6206P152）从 3.3V 自动生成，随板上电即有，无需任何固件干预。这是很多人「查供电查半天」的地方——这块板子上它天生就是好的。

1.3 LCD 模组

WeAct 配套的 0.96 寸 ST7735S TFT（原厂 Demo 编译宏 TFT96）：

  • 分辨率 160×80，横屏使用（LANDSCAPE_ROT180），HannStar 面板（有特定的行列偏移，厂商驱动里处理了）
  • SPI 单向 3 线制（无 MISO 回读）+ CS/DC/RST 控制线 + PWM 背光
  • 同系列还有 1.8 寸 128×160（TFT18 宏），本板实测用的是 TFT96

1.5 时钟与内存布局（沿用原厂 Demo 的配置）

HSI 64 MHz → PLL(M=4, N=60, P=2) → SYSCLK 480 MHz
  ├─ AHB 240 MHz
  ├─ APB1 120 MHz（I2C1 / SPI2 / TIM2）
  └─ APB2 120 MHz（TIM1 ×2 = 240 MHz 定时器时钟 ← XCLK 分频基准）

板上其实有 12 MHz HSE 晶振，但原厂 Demo 用 HSI 跑（免去晶振频率假设），本教程照抄——实测稳定。帧缓冲放在 AXI SRAM 的 0x24040000 起 64 KB，配 MPU 非缓存区（第 6 章讲为什么）。
