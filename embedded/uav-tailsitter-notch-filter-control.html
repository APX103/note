尾座机的 14Hz 共振：扫频辨识、陷波滤波与回路整形

无人机滤波控制三篇 · 之一 · arXiv:1903.06393（HKU MaRS Lab，ICRA 2019）· 2026-10-07

§0 这篇论文在讲什么

香港大学张富团队（MaRS Lab）造了一架碳纤维尾座式（tail-sitter）垂直起降无人机：没有舵面、没有舵机，四台电机差动就是全部操纵面。飞机很好，但地面调试时发现一个要命的问题——机身结构在 14Hz 附近有一个尖锐的柔性共振模态，姿态控制器增益一往上加，四个电机支架就开始发散振动，姿态环带宽被死死压在 4Hz 以下。

论文的解法是一套教科书级的频域流程：用指数扫频信号把飞机从 1Hz 到 60Hz 的频率响应实测出来 → 拟合出含共振峰的传递函数 → 在回路里串一个 14Hz 陷波滤波器（notch filter）把共振峰"挖掉" → 再用回路整形（loop shaping）法整定 PID。结果：俯仰角速度环带宽 6.8Hz（比不挖峰提升 70%），相位裕度 44°，实机悬停、过渡、平飞全部验证通过；平飞功耗只有悬停的约四分之一，兑现了尾座构型的效率承诺。

§1 前置知识

§1.1 尾座式 VTOL：旋翼的悬停 + 固定翼的效率

旋翼机（直升机、多旋翼）能悬停，但靠旋翼直接托起全重，功耗高、航时短；固定翼靠机翼产生升力，效率高得多，但需要跑道起降。尾座机取两头之长：起飞着陆时机身竖直坐在尾上，像四旋翼一样用推力对抗重力；平飞时低头转成水平，像固定翼一样靠机翼升力飞行。它是所有 VTOL 构型里最简洁的——不需要旋翼倾转机构，过渡飞行只是"俯仰角从 90° 慢慢压到 0°"的连续过程。

图 1 · 尾座机的两种生存姿态（示意）。悬停时像四旋翼，平飞时像固定翼——同一套电机，两种身份。论文实测平飞电流约为悬停的四分之一。

但这台飞机有个此前泡沫/软木原型没有的新麻烦：碳纤维结构刚而不柔中带"尖"——装配铰接不完美催生了尖锐的柔性模态。通俗说：机身不再是理想刚体，而像一个带弹簧的音叉，在某个频率上会被电机激励出共振。这个模态藏身在"电机指令 → 陀螺仪"通道里，第一性原理刚体模型完全抓不住它，必须实测。

§1.2 频域语言：传递函数与伯德图

控制工程师看系统有个惯用视角：给线性系统输入一个正弦，稳态输出也是同频正弦，只是幅值乘个倍数、相位移个角度。把每个频率 \(\omega\) 上的"复数增益"记成 \(P(j\omega)\)，就是频率响应；把它画成两张图（幅值 dB、相位 °，横轴对数频率）就是伯德图。幅值常用分贝：\(20\log_{10}|P|\) dB。

对反馈回路，真正决定命运的是开环传递函数 \(L(s) = P(s)C(s)\)（被控对象 × 控制器）。闭环为：

\[ T(s) = \frac{P(s)C(s)}{1+P(s)C(s)} = \frac{L(s)}{1+L(s)} \]

三条经验法则撑起了后面所有设计：

  • 低频要高增益：灵敏度函数 \(S = 1/(1+L)\) 把低频扰动（风、电机不对称）压小，要求 \(|L|\) 在低频远大于 1；积分器保证直流增益无穷大，常值误差归零。
  • 穿越频率附近斜率要平：\(L\) 穿越 0dB 的频率叫带宽（响应快慢的标尺）；此段斜率越接近 −20dB/dec（一阶特性），相位越充裕。相位裕度 PM = 180° + 穿越 frequency 处的相位，航空界经验值 35°~45° 以上；增益裕度 GM 是相位到 −180° 时增益还差几 dB。
  • 高频要滚降：高频 \(|L|\) 必须压到 0dB 以下足够低，否则传感器噪声和未建模高频动态会被放大，回路"唱歌"。

为什么会在特定频率"唱歌"？直觉版解释：负反馈自带 180° 相移，若回路在某个频率上总相移凑满 360°、且增益 ≥ 1（0dB），误差经回路转一圈回来不仅不衰减、反而变成同相加强——系统自持振荡甚至发散。记住这句话，14Hz 的故事就是它的一个实例。

§1.3 柔性模态：藏在回路里的音叉

任何真实结构都是分布的质量-弹簧系统，可以展开成一组"模态"：每个模态是一个二阶振荡环节，固有频率 \(\omega_0\)、阻尼比 \(\zeta\)。阻尼小（\(\zeta\) 小）时频率响应在 \(\omega_0\) 处冒出尖锐的峰，峰高约 \(1/(2\zeta)\)。

机翼/电机支架的柔性模态串在控制回路里意味着："电机差动力矩 → 陀螺仪角速度"这一通道的增益，在共振频率上被抬高了十几 dB。本来开环 \(L\) 在该频率已衰减到 0dB 以下，被峰一抬，重新穿回 0dB 之上——而相位在共振附近恰恰快速跌过 −180°。两个条件同时满足，于是任何一点噪声都能激励出等幅甚至放大的振荡。论文的实机表现：四个电机支架振动发散，姿态环带宽被限制在 4Hz 以下。

三条出路：加材料提高刚度（共振频率上移，但增重）；压低控制带宽绕开共振（牺牲性能）；陷波滤波器挖掉峰（几乎零成本，付一点相位代价）。论文选第三条。

§1.4 这篇文章里的"滤波"都在哪

用户视角的"滤波的东西"在这架飞机上其实有三层，分清楚它们对读论文很有帮助：

滤波器位置作用本文戏份
扩展卡尔曼滤波 EKF状态估计层融合 GPS/IMU/气压/空速，输出位置、速度、姿态、角速度一句话带过（PX4 自带）

§2 平台与建模

§2.1 一台没有舵面的尾座机

传统尾座/倾转机常保留舵面（副翼、升降舵）辅助巡航段操纵。这台机器彻底砍掉：桨差动出全部力矩。论文列出四个好处：① 舵机及连杆约占全重 5%，砍掉即增载荷；② 舵面在大迎角（超过失速角）后失效，而桨的操纵效能几乎不受迎角影响——尾座机过渡段恰好全程大迎角，这直接简化了控制器设计（不用为失速区单独设计一套）；③ 舵机齿轮箱带来额外动态与非线性，砍掉后控制带宽提升；④ 全飞行包线（悬停-过渡-平飞）可用同一套姿态/高度控制器，不再需要分段混控。

§2.2 坐标系与动力学

惯性系取 NED（北东地），机体系沿用固定翼惯例（x 前、y 右、z 下）。欧拉角旋转序取 Z-X-Y（偏航-滚转-俯仰）：这样俯仰角接近 ±90°（尾座机悬停姿态！）时方向余弦阵不奇异。姿态控制器内部同时用四元数做误差表示。刚体动力学三件套：

\[ \dot{R}_b^i = R_b^i \hat{\omega}_b \] \[ I\dot{\omega}_b = -\omega_b \times (I\omega_b) + \tau + M_a \] \[ \ddot{p}_z^i = mg + e_3^{\top}\!\left(f_a^i + f_p^i\right) \]

其中 \(\hat\omega_b\) 是角速度的反对称叉乘矩阵，\(\tau\) 是电机差动力矩，\(M_a\) 是气动力矩，\(e_3=[0,0,1]\) 取 z 分量。气动力与桨力分别按速度系/机系建模：\(f_a^i = R_v^i[-D,0,-L]^\top\)（阻力 D、升力 L），\(f_p^i = R_b^i[T,0,0]^\top\)（推力沿机身轴）——悬停时机身竖直，推力朝天上；平飞时推力朝前，升力顶上，公式自动兼容两种姿态。

§3 扫频辨识：把飞机的"频率性格"测出来

§3.1 为什么要扫频

§2.2 的刚体模型是"骨架"，抓不住柔性模态、滤波器群、延迟这些"血肉"。而回路整形恰恰需要精细的频域模型。做法：给系统灌已知频率成分的激励，量输出，算出每个频率点的增益/相位——即实验频率响应，再用参数化传递函数去拟合。团队之前用离散扫频（一次一个频点），精度好但实验次数多；本文换成指数 chirp 连续扫频，一次实验覆盖 1–60Hz 全部频段。

§3.2 激励与量测链路

图 2 · 姿态-角速度双环结构与扫频注入位置（依论文 Fig.3–5 重绘）。橙色注入点之后到陀螺仪输出之前的全部环节——电调、电机、结构柔性、PX4 低通——都被当作"被控对象"一起辨识。

扫频信号 \(u\) 直接加在角速度控制器输出 \(\tau\) 上；输出取机载 MEMS 陀螺仪角速度。陀螺原始 1kHz，经巴特沃斯低通降到 250Hz——这也是控制器更新率。激励用指数型 chirp：

\[ k=\left(\frac{f_1}{f_0}\right)^{1/T},\qquad \phi(t) = \frac{2\pi f_0}{\ln k}\left(k^t-1\right),\qquad u(t)=A\sin\phi(t) \]

频率范围 \([f_0,f_1]=[1,60]\,\mathrm{Hz}\)，\(T\) 为总时长，\(A\) 取到信噪比足够又不失稳。为什么用"指数"而不是线性扫频？指数 chirp 在对数频率轴上匀速前进，每个倍频程（octave）分配相等的能量和时间——正好匹配伯德图的对数横轴与"低频段每 Hz 都值钱"的辨识需求。

§3.3 从谱分析到五件套拟合模型

拿到时域输入输出后，用 SPAFDR（频率依赖分辨率的谱分析，Ljung 系统辨识工具箱）提取各频率点的增益与相位，得到一条非参数曲线；再用参数化模型拟合。拟合结果是五 个环节串联，每个都对应一段物理：

\[ P(s) = P_{lf}\,P_{Dy}\,P_{peak}\,P_{offpeak}\,P_{delay} \]
环节传递函数（论文数值）物理含义
\(P_{lf}\)\(\dfrac{1}{1+0.00321s+5.31\times10^{-6}s^2}\)PX4 自带的 69Hz 二阶巴特沃斯低通：隔离 75–90Hz 的桨叶通过频率振动。它是软件里的事实环节，所以并入被控对象
\(P_{Dy}\)\(\dfrac{260+3.764s+0.01362s^2}{1+0.0637s}\cdot\dfrac{1}{s}\)主动力学：\(1/s\) 积分器是刚体"力矩→角速度"的积分，两个零点与一个极点吸收气动与陀螺力矩修正
\(P_{peak}\)\(\dfrac{1+0.00239s+1.29\times10^{-4}s^2}{1+3.41\times10^{-4}s+1.29\times10^{-4}s^2}\)14Hz 结构共振：分子分母同频但阻尼悬殊的二阶对，制造尖峰
\(P_{offpeak}\)\(\dfrac{1+1.18\times10^{-4}s+3.48\times10^{-5}s^2}{1+1.3\times10^{-3}s+3.48\times10^{-5}s^2}\)27Hz 反共振（谷）：结构与结构之间的耦合 zero
\(P_{delay}\)\(e^{-0.021s}\)21ms 纯延迟：采样、滤波器群延迟、电调响应的总和

这个"五件套"最漂亮的地方在于每一件都能指认物理出处——辨识不是黑魔法，而是给每个物理嫌疑犯量相。按论文系数复算：14Hz 处幅值约 +14dB，比 12Hz 邻域（约 +1dB）高出约 13dB，即共振把该频率的回路增益抬了 4~5 倍；相位在 14Hz 附近已跌破 −180°——§1.2 说的"唱歌"两个条件，全部凑齐。

§4 陷波滤波器：一行数学救回 70% 带宽

§4.1 不挖峰会发生什么

论文做了对照实验（§7 复述）：悬停起飞后陷波器先关着——俯仰通道立刻振荡，振幅越来越大（发散）；中途打开陷波器，发散振荡迅速收敛。频域预言与实机表现完全对上。下面的复算图把这层关系画了出来：同一组 PID 增益下，无陷波的开环在 15Hz 附近（共振峰处）第二次穿越 0dB——共振条件成立；有陷波后该区域被压回 −20dB 以下，0dB 只穿越一次。

§4.2 陷波器数学

陷波器 = 一种极窄的带阻滤波器，论文用的二阶形式：

\[ N(s) = \frac{a s^2 + c s + 1}{a s^2 + b s + 1},\qquad a=\frac{1}{\omega_0^2},\quad b=\frac{k_1}{\omega_0},\quad c=\frac{k_2}{\omega_0} \]

分子分母是同一频率 \(\omega_0\) 的二阶多项式，唯一区别是中项系数（阻尼）。归一化写法更直观：

\[ N(s) = \frac{s^2 + k_2\,\omega_0 s + \omega_0^2}{s^2 + k_1\,\omega_0 s + \omega_0^2} \]

在中心频率 \(s=j\omega_0\) 处增益恰为 \(k_2/k_1\)——这就是深度；\(k_1\) 决定谷的宽度。设计只需三步：中心频率对准共振（\(\omega_0 = 2\pi\times14\) rad/s）；深度按"把 +14dB 峰削回 0dB 附近"反算（约 1/5，即 −14dB）；宽度取窄——谷越窄，谷外的相位扰动越小。

§4.3 复算：峰、谷与开环

§4.4 天下没有免费的午餐：相位代价

陷波器在谷底附近会造成相位下陷（分子先"失速"、分母后跟上），谷外也残留几度滞后。论文的账：按最终控制器带宽估计 7Hz，陷波器在该处吃掉约 5° 相位裕度——可以承受。所以 \(k_1,k_2\) 不能贪深贪宽：削平峰即可，多一 dB 都是浪费相位。这也是为什么陷波器要配合精确的频域模型使用——中心频率对不准，挖的坑就是白挖。

§5 回路整形 PID

峰被挖掉后，剩下的就是标准作业：把开环 \(L=CN P\) 整成 §1.2 的三条法则形状。控制器用 PID，微分项串二阶巴特沃斯低通（转折 18Hz）防止微分放大高频噪声：

\[ C(s) = \frac{K_i}{s} + K_p + K_d\,\frac{s}{\left(s/\omega_c\right)^2 + \sqrt2\,s/\omega_c + 1},\qquad \omega_c = 2\pi\times 18\ \mathrm{rad/s} \]

论文取值 \(K_i=0.1,\ K_p=0.09,\ K_d=0.01\)。整定结果（论文报告）：俯仰角速度环带宽 6.8Hz，比无陷波上限（<4Hz）提升 70%；相位裕度 44°；0.6–14Hz 段幅值斜率约 −19dB/dec——几乎完美的单积分穿越特性，鲁棒频段厚实。复算校验：同参数下穿越频率 7.3Hz、0.6–14Hz 段斜率约 −15dB/dec，与论文报告一致量级（论文未公开陷波 \(k_1,k_2\)，相位裕度数值略有出入属预期）。

回路整形的阅读方式，对着图 3 下图：低频段（<0.6Hz）积分器把增益抬到 +18dB 以上——常值扰动（四个电机个体差异、重心偏）被压掉 20 倍以上；中频段以接近 −20dB/dec 的斜率穿过 0dB——相位裕度的来源；高频段（>20Hz）被 69Hz 低通 + 21ms 延迟压到 −20dB 以下——桨频振动与量测噪声进不来。

§6 高度控制：前馈 + 反馈并联

尾座机的高度控制比四旋翼难：悬停时推力竖直，平飞时推力水平、升力竖直——同一个高度误差，该加油门还是该拉杆，取决于当前速度和姿态。论文的解法是把"模型知道的"放进前馈、"模型不知道的"交给反馈：

图 4 · 高度控制器：前馈-反馈并联结构（依论文 Fig.16 重绘）。前馈支路承担"物理上早知道"的推力需求，PI 反馈只兜模型误差的底，两者在电机指令处汇合。

前馈链路三步：① 目标垂直速度乘比例得目标加速度 \(a_{zd} = K_{ff}v_{zd}\)；② 把 §2.2 的竖直方向力平衡（重力 + 气动力 + 推力的 z 分量）反过来解出所需总推力 \(T\)——这里用到的升阻模型 \(L=\tfrac12\rho V^2SC_L(\alpha,V)\)、\(D=\tfrac12\rho V^2SC_D(\alpha,V)\) 来自团队前作同构型风洞试验数据；③ 推力换算油门 \(u^{ff}_T = kT\)，比例系数 \(k = T_h/(mg)\) 取悬停推力与悬停油门之比。协调飞行假设（无侧滑）保证升力只依赖空速与迎角，模型可用。

前馈算得再准也有模型失配（空速用地速近似、风洞数据是"邻居的"），所以并联一个 PI 反馈环修误差。这套结构的哲学与 §4 一脉相承：确定的部分开环给足，不确定的部分闭环兜底。

§7 飞行验证：三场考试

  • 悬停考（陷波器的生死测试）：起飞后陷波器关闭——俯仰通道立刻起振，振幅持续增大（发散）；中途使能陷波器，振荡迅速收敛。频域预言（图 3 下）与实机现象一一对应。随后快速手动指令跟踪测试：回路整形后的俯仰角速度响应无超调、跟得快。
  • 过渡考（鲁棒性）：爬升到目标高度悬停，随后给线性低头指令加速前飞——俯仰角一路跟到 85° 保持平飞段，全程几乎无超调；79s 后给反向阶跃回悬停，俯仰阶跃响应呈现干净的一阶系统形态。全程高度误差 < 2m，前馈-反馈高度控制器交卷。
  • 效率考（尾座机的存在意义）：500m×600m 开阔场地，悬停段电流 ~20A；13.67m/s 平飞段平均电流 ~5A，约悬停的四分之一——与多学科优化设计阶段 CFD 预测吻合（前作报告平飞功耗约为悬停 1/5）。

§8 总结：这套方法为什么值得学

可复用的方法论闭环：chirp 扫频（一次实验覆盖全频段）→ SPAFDR 谱辨识 → 物理可指认的分式拟合 → 陷波器对准结构模态 → 回路整形 PID。每一刀都有频域数据背书，没有一步靠盲调。这套流程不只属于尾座机——任何"控制器带宽被结构共振卡死"的场景（机械臂、云台、大型多旋翼）都适用。
局限与后续演进：① 陷波中心频率固定在 14Hz——共振会随载荷/温漂/结构老化移动，今天飞控的进化版是 RPM 跟踪陷波（中心频率实时跟随电机转速）；② 模型是悬停点附近的线性化，大迎角非线性依赖增益调度与鲁棒裕度兜底；③ 扫频要在地面/悬停状态下做，"换个机型就要重扫"——这正是系列之二要解决的问题：把辨识搬上天，让飞机在 450ms 的抛飞里自己认出自己。

三篇连读的建议顺序：本文（频域 + 经典控制）→ 之二：RLS 在线辨识 + INDI（时域 + 自适应）→ 之三：H∞ 鲁棒增益调度（把"辨识有误差"这件事显式建模）。恰好是飞行控制从经典到自适应再到鲁棒的完整谱系。
