01 / 硬件与引脚速览

这块板子是 XIAO nRF52840 Plus 核心板 + 1.47″ IPS 扩展屏的一体形态(26.4×51.4 mm):JD9853A 驱动的 172×320 彩屏(SPI)、AXS5106L 电容触摸(I²C 0x63)、LSM6DS3 六轴 IMU(I²C 0x6A)、PDM 数字麦克风、MicroSD(与 LCD 共享 SPI)、双用户按键、JST 2.0 锂电池接口(带充电与电压监测)。无线是 BLE 5.4(无 Wi-Fi、无经典蓝牙),定位便携 HMI / 可穿戴原型。

外设引脚备注
LCD SPICS=D2 DC=D3 SCK=D8 MOSI=D10RST=38、背光=37(可 PWM)
触摸 AXS5106LSDA=D4 SCL=D5 INT=D7与 IMU 共享 I²C 总线;RST 与 LCD 共线
IMU LSM6DS3I²C 0x6A,INT1→D14加速度+陀螺仪,支持硬件唤醒中断
MicroSDCS=D6,共享 SPI注意与 LCD 的总线仲裁
PDM 麦克风CLK=D0 DATA=D116 kHz 采集;I2S 输出 D11-D13
用户按键BTN_A=D19 BTN_B=D15低电平有效,内部上拉
电池P0.14 使能分压 → P0.31(AIN7)读数分压比 (1000k+499k)/499k ≈ 3.004
nRF52840 = Cortex-M4F @64 MHz / 256 KB RAM / 1 MB Flash(+2 MB 板载)。编译产物上限 811 KB 是扣掉 SoftDevice S140 7.3.0 后的应用区。

02 / 环境搭建与被墙的 GitHub

Windows 10 上没有装过 Arduino IDE,沿用 M5StickS3 笔记定型的 arduino-cli 路线。本机特有矛盾:Seeed 板卡索引里的三个依赖包有两个只发布在 GitHub Releases,而本机直连 github.com 443 超时。

2.1 常规部分(顺利)

# arduino-cli 单文件安装
curl -sL -o arduino-cli.zip https://downloads.arduino.cc/arduino-cli/arduino-cli_latest_Windows_64bit.zip

# Seeed 板卡源(Wiki 指定 Seeed nRF52 Boards 1.1.13)
arduino-cli config add board_manager.additional_urls https://files.seeedstudio.com/arduino/package_seeeduino_boards_index.json
arduino-cli core update-index
arduino-cli core install Seeeduino:nrf52@1.1.13   # 在工具链下载处失败,见下

2.2 工具链下载失败与镜像分段下载

core install 卡死在 arm-none-eabi-gcc@9-2019q4(153 MB,托管于 adafruit 的 GitHub Release)。实测本机单线程各镜像只有 12-40 KB/s(直连超时、ghfast 死链、本机 47890 端口非可用代理),最终方案:cors.isteed.cc 镜像 + HTTP Range 16 线程并行,约 5 分钟拉完,聚合速度 ≈500 KB/s。

SIZE=153520070; CHUNK=$((SIZE/16+1)); P=/tmp/gccp; mkdir -p $P
URL="https://cors.isteed.cc/https://github.com/adafruit/arduino-board-index/releases/download/build-tools/gcc-arm-none-eabi-9-2019-q4-major-win32.zip"
seq 0 15 | xargs -P 16 -I{} bash -c \
  'i={}; s=$((i*CHUNK)); e=$(((i+1)*CHUNK-1)); [ $e -ge $SIZE ] && e=$((SIZE-1));
   for t in 1 2 3 4 5; do
     curl -s --connect-timeout 8 -m 600 -r "$s-$e" -o "$P/p$(printf %02d $i)" "$URL"
     g=$(stat -c%s "$P/p$(printf %02d $i)" 2>/dev/null||echo 0)
     [ "$g" -eq "$((e-s+1))" ] && exit 0; sleep 1
   done; exit 1'
cat $P/p* > ~/AppData/Local/Arduino15/staging/packages/gcc-arm-none-eabi-9-2019-q4-major-win32.zip
md5sum .../gcc-arm-none-eabi-9-2019-q4-major-win32.zip
# 9d60cbb0e358ab6a9d3c9e5dc3624dd2  ← 与 Seeed 索引内 MD5 一致

要点:arduino-cli 会优先使用 staging 目录里校验和匹配的包,所以“手动下载到 Arduino15/staging/packages/ 再 core install”即可离线续装。三个依赖的处理:

包大小来源处理
arm-none-eabi-gcc 9-2019q4153 MBGitHub(adafruit)镜像 16 线程分段,MD5 校验后 staging
nrfjprog 9.4.00.8 MBGitHub(adafruit)gh-proxy.com 单线程,MD5 校验后 staging
CMSIS 5.7.0104 MBfiles.seeedstudio.com国内 CDN 直连,无需干预
平台包 1.1.1324 MBfiles.seeedstudio.com同上,顺手 staging 后 install 秒装

之后 arduino-cli core install Seeeduino:nrf52@1.1.13 全部命中本地缓存,安装完成。板卡识别:arduino-cli board list 直接给出 COM4 → Seeeduino:nrf52:xiaonRF52840Plus(FQBN 免查表)。

03 / Seeed_GFX2 库与关键 API

图形库 Seeed_GFX2 不在库管理器里,官方要求 ZIP 手动安装;被墙环境下直接从镜像克隆到用户库目录:

git clone --depth 1 https://gh-proxy.com/https://github.com/Seeed-Studio/Seeed_GFX2.git ~/Documents/Arduino/libraries/Seeed_GFX2

IMU 例程用 SparkFun 版库(API 与 Seeed 原版一致):arduino-cli lib install "SparkFun LSM6DS3 Breakout"(库索引走 downloads.arduino.cc,不受影响)。

3.1 初始化模板(与 TFT_eSPI 时代的最大差异)

新库用 Board/Config 模板参数替代了手写 User_Setup / MADCTL / invert,屏幕与触摸各一句:

#include <Seeed_GFX.h>
#include "board/boards/XIAO_LCD_Board.h"
#include "driver/tft/Driver_JD9853A.h"
#include "panel/Panel_TFT.h"
#include "touch/Touch_AXS5106L.h"
#include <Adafruit_TinyUSB.h>   // nRF52 核心必带(USB CDC)

Seeed_GFX display;
static constexpr int8_t LCD_RST_PIN = 38;   // nRF52840 Plus 专用,ESP32-S3 版是 13/12
static constexpr int8_t LCD_BL_PIN  = 37;

// 触摸 RST 与 LCD 共线,display.begin 已处理过复位 → 传 -1,否则会把屏拉黑
Touch_AXS5106L touch(-1, D7, Wire, 172, 320);

void setup() {
  display.begin<Board_XIAO_1inch47_Touch_Display<LCD_RST_PIN, LCD_BL_PIN>,
                 Config_Seeed_1inch47_Touch_JD9853A>();
  display.attachTouch(touch, display.panel().driver().bus());
}
// 绘图 API 兼容 TFT_eSPI 习惯:fillScreen/drawString/setTextDatum/fillCircle…
电量换算:扩展板分压电阻 1000k/499k,VBAT = analogRead(PIN_VBAT) × 3.6 / 1023 × 3.004;读前需 digitalWrite(VBAT_ENABLE=14, LOW) 使能分压。PIN_VBAT 在该 BSP 的 variant.h 里 = 35(即 P0.31/AIN7)。

04 / 编译:FQBN 与产物

FQBN=Seeeduino:nrf52:xiaonRF52840Plus        # Plus 版;Sense 版另有 ID
arduino-cli compile --fqbn $FQBN <sketch目录>

# 触控画板(自写):  91,204 B flash / 8,096 B RAM  (11% / 3%)
# 板载自检(自写):  同级
# 电子流沙(官方):  90,604 B flash / 13,872 B RAM (11% / 5%)

首次编译全量构建约 1-2 分钟;softdevice 默认 s140v6(菜单仅此一档),debug 级别默认 Release,无需显式传参。

05 / 烧录与串口验证(含两个坑)

5.1 烧录

arduino-cli upload -p COM4 --fqbn Seeeduino:nrf52:xiaonRF52840Plus <sketch>
# Device programmed.  New upload port: COM4 (serial)

上传走 nRF52 DFU(双 bank),过程中端口会短暂从 COM4 跳成 COM5 再回来,属正常现象,不要在中途拔线。若某次上传失败导致端口消失,快速双击复位键进入 bootloader(出现 XIAO_nRF52840 U 盘)后重试即可恢复。

5.2 坑一:arduino-cli monitor 收不到任何输出

arduino-cli monitor -p COM4 连接成功但永远 0 字节。原因是它打开 COM 口的方式没有让这块板的 TinyUSB CDC 开始上报。可靠替代:pyserial 显式拉 DTR:

import serial, time
s = serial.Serial('COM4', 115200, timeout=1)
s.dtr = True          # 关键:不拉 DTR 就没有输出
s.reset_input_buffer()
# 循环 s.read(s.in_waiting) 即可

5.3 坑二:开机日志只能看一次

打开 CDC 串口不会复位 nRF52840(不像 ESP32 的 DTR/RTS 复位),setup() 里的初始化日志在监视器挂上前就打完了。两个对策:演示固件里加周期性心跳日志;或需要抓开机日志时,烧一个“持续输出”的自检固件替代(本次即采用后者,见下节)。

自写自检固件(500 ms 周期打印 IMU 三轴 / 电池 / 触摸状态),烧录后串口实录:

[imu] +0.07 +0.13 -1.04 g | [vbat] 4.17V | [touch] -

  • IMU ✓:静置桌面 Z 轴 ≈-1 g,轻微挪动实时跟随;流沙 demo 直接可用。
  • 触摸 ✓:手指按下即报 PRESSED,画板固件的换色事件(brush -> color #N)同步在日志出现。
  • 电池 ✓(带已知毛刺):USB 插电时读数在 3.7x / 4.1x V 双峰跳动 — 充电时 BAT 节点电压被拉高,官方 Dashboard 例程注释里明确提示“VBAT ADC 会毛刺几个刷新周期,USB 供电下不要静态信任单次读数”。纯电池供电时应为稳定单值。

三块验证(触控画板 → 自检 → 电子流沙)全部通过后,最终留在板子上的是电子流沙:24×45 网格、180 颗粒子、8 ms 帧间隔读 LSM6DS3 重力流场,倾斜板子沙粒会向低处堆积。

08 / 踩坑速查与归档

  • GitHub 直连超时:Seeed 板包的工具链依赖托管在 GitHub Releases。解法 = 镜像(cors.isteed.cc 快于 gh-proxy.com)+ Range 分段并行 + 手放 staging + 校验和比对。
  • monitor 无输出:arduino-cli monitor 对该 TinyUSB CDC 无效,用 pyserial + dtr=True。
  • 开机日志丢失:开串口不复位 nRF52,要么加心跳日志,要么烧自检固件。
  • 触摸构造器 RST 传 -1:RST 与 LCD 共线,传真实引脚号会在 LCD 初始化后把屏复位拉黑。
  • 电池读数:×3.004 分压;USB 供电下双峰跳动为已知特性,勿以单次读数判断。
  • IMU 库选型:官方例程用 SparkFunLSM6DS3.h(与 Seeed 版 API 同构),不是 Adafruit_LSM6DS。
