硬件方案：三档配置，成本与最简 Demo 双优先

硬件策略一句话：Demo 用现成品（零焊接），内测用开发板（可定制按键），验证通过才做量产 BOM（目标 ≤ ¥60）。绝不在验证前开模、打板、画原理图。

1设计原则

能买不焊Demo 阶段一切硬件从淘宝/华强北买现成品。焊接、画板、3D 建模都是验证之后的事。
跟着生态走选小智（xiaozhi-esp32）生态成熟的硬件形态——现成固件直接支持，服务器零适配，社区踩过的坑我们不用再踩。
成本红线倒推目标零售 ¥199–249，渠道+毛利倒推 BOM ≤ ¥60。凡是把这根线顶爆的配置（屏幕、摄像头、大喇叭、金属外壳）一律砍。
为认证而设计量产件从第一天就按 3C/GB 6675 的要求选（模块带 SRRC、电池带认证、阻燃外壳），认证是时间问题，别让硬件变成死局。

2主控选型：为什么是 ESP32-S3

候选优势劣势结论
ESP32-S3
(WROOM-1 N16R8)		小智生态第一公民（固件/服务器全现成）；PSRAM 8MB 满足音频缓冲与 Opus 编码；向量指令可跑离线唤醒词；模组厂（乐鑫/安信可）已带 SRRC 认证；量大单价 ¥12–18非国产芯片；深度定制音频 DSP 不如专业方案选定
ESP32-C3 / 经典 ESP32更便宜（¥6–10）无 PSRAM/无向量指令，小智固件支持差，音频缓冲吃紧否决
博通集成 / 云知声等玩具 AI 方案芯片玩具厂标配、出货量大价低封闭生态，绑定方案商，无法自建 Agent 与数据资产——与"声音记忆是我们的"根本冲突否决
树莓派 / Linux 类算力自由BOM ¥80+、功耗高、续航差、系统运维重否决
关键决策说明：选 ESP32-S3 不是因为它"最强"，而是因为它把固件研发成本降到接近零——小智固件已实现 I2S 采集、Opus 编解码、WebSocket 协议、OTA、配网全家桶。我们省下的 2–3 个月固件从零开发时间，正是"两周出 Demo"的根基（见 03 篇）。

3三档硬件配置

档位 A · Demo 用（强烈推荐起步） ¥79–168 单台，含物流

做法：淘宝直接买"小智 AI"兼容整机（ESP32-S3 核心的桌面机器人/音箱形态），到手重新指向我们自建的服务器即可。零焊接、零外壳、零结构设计。

  • 采购关键词：小智AI 聊天机器人 ESP32-S3、xiaozhi AI 桌面机器人
  • 买前必问客服三件事：① 是否 ESP32-S3 带 PSRAM；② 能否自行刷固件/改服务器地址（有的锁死，见 06 篇避坑）；③ 有无独立按键（对话键/音量键）
  • 自带：麦克风、扬声器、充电电池、按键、外壳——Demo 需要的一切
  • 局限：按键布局固定，无法实现"多段录音+单独发送"，Demo 阶段用"按住说话松开发送"先验证核心价值
档位 B · 内测/种子家庭用 ≈ ¥90–120 单台 DIY

做法：ESP32-S3 开发板 + I2S 麦克风/功放 + 独立按键，面包板或洞洞板连接，3D 打印简易外壳或塞进毛绒公仔。可完整实现我们的 3 键交互。

  • ESP32-S3-DevKitC-1（N16R8）≈ ¥45–60 · 或用面包板伴侣型（如 S3 Zero + 扩展板）更小
  • INMP441 全向 I2S 麦克风模块 ≈ ¥6–10
  • MAX98357A I2S 功放模块 + 2W/4Ω 全频喇叭 ≈ ¥12–18
  • 轻触按键 ×3 + 自锁开关 + WS2812 RGB 灯（状态灯效）≈ ¥5
  • 18650 电池盒（带 Type-C 充电保护一体板）+ 2000mAh 电芯 ≈ ¥15–20
  • 外壳：¥10–20 的现成毛绒公仔（掏空塞入，网布透声）或 3D 打印 ≈ ¥5–15
档位 C · 量产 BOM（1k–10k 台） ≈ ¥45–60 含组装测试与包装，不含开模费

验证通过后再启动。核心动作：找方案商/代工厂定制 PCB（把开发板上的芯片直贴）、开注塑模具或毛绒模具、贴牌组装。明细见下节 BOM 表；供应链路径见第 8 节。开模（¥3–8 万）是本档位最大的一次性投入，必须在小批量验证数据支撑下再拍板。

5外壳：毛绒优先的三个理由

① 成本与安全毛绒+短绒面料单价低于注塑加喷涂；天然满足 GB 6675 对边缘/尖点的严格要求（没有硬棱角）；跌落不坏。
② 儿童亲和3–8 岁对"抱的"比"摆的"更有依恋——情感联结正是本产品黏性来源；毛绒=睡眠场景入场券（睡前故事）。
③ 透声天然友好网布/短绒区域即是免结构设计的"扬声器开孔+麦克风开孔"；省掉防水格栅等结构件。
实施路径：Demo 买现成公仔掏空塞开发板（麦克风/喇叭对准网布区）；小批量用东莞毛绒厂现成公仔改内胆；量产开毛绒模具（比注塑便宜）。电子部分用 ABS 内胆盒 + 螺丝固定（电池仓不可徒手打开，3C 硬要求），按键穿过内胆露在公仔手脚部位（大凸键，好按好找）。

  • 音量童锁：软件限制最大输出电平（出厂校准），家长端可再调低；无论孩子怎么按，不超 85dB（GB 6675 声级要求）。
  • AGC：孩子说话忽大忽小、距离忽远忽近，自动增益保证 ASR 识别率（对"断断续续说话"场景尤其重要）。
  • 回声处理：玩具自己说话时孩子抢话是常态。Demo 阶段用"半双工"（播放时按键录音排队）；量产版启用 ESP32-S3 AEC 库实现全双工打断。
  • 静默检测（VAD）：多段录音"自动封口"（静默 5s）由它驱动，无需孩子理解"结束"概念。

7电源

方案：单 18650 + Type-C

2000mAh ≈ 中度使用 8–10h（待机为主、交互间歇）。充电 2.5h，支持边充边用——睡前故事场景大概率是插电状态，续航压力比想象小，不必上大电池。

低电量红色快闪 + 童声提示；电量上报服务器（家长端可见）。

童安要点（3C 审查项）

  • 电池仓螺丝固定，儿童无法徒手取出电芯
  • 电芯必须带认证（GB 31241 / UN38.3），加 PCM 保护板
  • Type-C 口带 ESD 保护；充电中限制使用温度检测
  • 整体工作电流与发热：满负荷外壳表面温升 < 限值

与方案商合作的底线：固件必须能自己刷写升级、服务器地址必须指向自己域名、设备数据（录音）必须归我们。方案商只挣硬件的钱，数据资产一分不碰——这是"声音记忆"商业模式的生命线，签合同前逐条确认。

9认证前置设计（现在选型，未来少花冤枉钱）

认证/合规项阶段硬件选型对策
电玩具 3C（GB 6675 / GB 19865）量产前必须无棱角（毛绒天然满足）、电池仓螺丝、阻燃材料选择 VL-94 等级、声压 ≤ 85dB、拉力测试件（按键/绒毛）
SRRC（无线电型号核准）量产前必须只用已带 SRRC 的 ESP32 模组（乐鑫/安信可模组自带），不做板载天线设计——省 ¥2–5 万和 8 周周期
电池 UN38.3 / GB 31241物流+3C 前置只采购认证电芯成品，索要报告随货
质检报告（平台入驻）开店铺时抖音小店/淘宝玩具类目需 3C 或质检报告；DIY 智能硬件类目门槛不同（见 08 篇合规路径）
生成式 AI / 深度合成备案放量前面向未成年人提供 AIGC 服务的合规评估；用大厂 API（豆包/通义）可借用其内容安全能力，降低自建成本

Demo 与内测阶段（自用/种子家庭免费体验）不涉及销售，无需认证；从收费那一刻起进入合规区间——时间线在 09 篇路线图中与开模并行安排。
