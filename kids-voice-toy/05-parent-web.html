家长端：手机 H5 三屏起步，不做 App

家长端策略一句话：一个移动端优先的 H5 网页，只做三个屏——绑定、时间线、精选——两周内和 Demo 设备一起跑起来。App、小程序、成长报告全部等验证后再投入。

1定位与原则

H5 而不是 App家长的使用是"低频高情感"（每晚/每周看几分钟），不值得装 App；扫码即用、微信内直接打开、分享零阻力——H5 完胜。Demo 阶段连小程序都不做（审核周期会拖慢验证）。
设计语言：情感相册，不是后台系统视觉参考"亲宝宝/时光小屋"：大圆角、暖色、日期分组、原声播放器是主角。不做图表仪表盘——妈妈要的是"翻相册的心动"，不是"看数据"。
原声优先原则一切页面围绕"点开就能听到孩子声音"设计：列表页直接内嵌播放按钮，一点就响，绝不让用户翻两屏才找到声音。
隐私是前置功能不是设置页监护人同意流程内置于首次绑定；删除/导出/成员管理放在首页可达的一级入口——合规要求同时是信任卖点。

2三屏信息架构（Demo 版）

屏名称内容与操作
屏 0绑定与同意扫玩具底部二维码 → 手机号验证码登录 → 填孩子昵称/生日 → 监护人同意书（儿童个人信息收集告知，勾选才可继续）→ 完成
屏 1声音时间线（首页）按天分组倒序；每条卡片：播放按钮 + 转写文字 + 标签（开心/幼儿园/金句）+ 时长 + 收藏/删除；日期跳转；"今天她说了 14 句话"问候语
屏 2本周精选 / 时光机每周童言精选卡片（原声+文字，可生成分享图）；时光机日历视图："2026-03-18 她说过…"；家长点"在玩具上播放"远程触发回忆
屏 3（半个）我的 / 隐私设备管理（WiFi 状态/电量/音量上限/免打扰时段）、成员邀请、保留期设置、一键导出、注销删除

严格说 Demo 只需要屏 1 能用、屏 2 能看、屏 0 能走通；屏 3 用一个最简设置页占位。

设计要点：

  • 每条卡片 3 秒内能听到声音——圆形播放键是页面上最大的元素
  • 转写文字是辅助（快速扫读），原声才是主菜（情感）
  • 标签是 LLM 自动打的：既是筛选入口，也是"原来它真的在理解我孩子"的感知点
  • 精选卡片可生成分享图（孩子头像剪影+金句+二维码）——自传播入口，直接喂抖音/朋友圈
  • 首页顶部问候语每日变化，制造"今天她又说了什么"的开启动机

4技术实现（最简栈）

Demo 版（与后端同仓，2–3 天工作量）

  • · 纯静态单页：一个 HTML + 原生 JS（或 Vue CDN），移动端优先
  • · 音频播放：<audio> + 后端签名 URL
  • · 列表接口直接查 recordings 表（04 篇 API）
  • · 登录：手机号+验证码（或 Demo 期用家庭邀请码代替短信）
  • · 部署：与 Agent 服务同一台云主机 nginx 托管

量产版（小程序，验证后启动）

  • · 微信小程序（Taro/uni-app 一套代码）+ 微信 OAuth 免密登录
  • · 订阅消息推送每周精选（H5 无法推送，这是转小程序的第一动因）
  • · 分享卡片生成、亲友邀请收听、成长报告
  • · 小程序需主体资质 + 类目（母婴/工具），与抖音店铺资质并行办理

5推送与留存抓手（家长侧增长的发动机）

触点时机内容
每日一句（Demo 可选）每晚 21:00"今天朵朵说了一句特别可爱的话，点开听听"——只推一条最强的，不轰炸
每周童言精选每周日 20:00Top 3–5 金句卡片 + 分享图生成（P1 核心功能）
时光胶囊提醒去年今天 / 指定纪念日"一年前的今天，她说…"+ 原声——最强情感触点，抖音素材固定来源
里程碑累计 100 条/500 条录音"您已经为孩子珍藏了 100 条童言，可以导出留念了"
异常通知安全事件触发时内容安全严重信号（04 篇第 5 节），即时推送，措辞克制专业

推送频控：非异常类每日 ≤ 1 条，可在设置关闭全部——体验克制本身就是差异化（对比教培类 APP 的轰炸）。

6隐私功能设计（合规动作产品化）

首次绑定 = 监护人同意流程

《儿童个人信息网络保护规定》要求收集儿童个人信息需监护人单独同意。绑定流程第三步呈现儿童化白话版告知（收集什么/用来什么/存多久/谁能听/怎么删），监护人勾选确认——把合规动作做成"我们很认真保护你孩子"的信任时刻。

四项家长数据权利（一级入口）
  • · 听：成员权限分级（爸爸可听/奶奶仅收藏/亲友仅精选）
  • · 删：单条删除 / 全部清空（30 天物理清除含备份）
  • · 取：一键导出 zip（音频+转写+时间线）——离线永远可留
  • · 改：保留期（1/3/5 年）、昵称生日、免打扰时段
数据承诺三条（写进隐私政策首页）：① 录音仅用于回听与记忆功能，绝不用于模型训练或任何二次利用；② 员工不可收听（权限隔离+审计日志）；③ 公司主体变更需重新征得同意。儿童数据业务里，信任崩塌只需一次事件。
