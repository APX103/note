0. 整体流程总览

整个项目只有六步，每一步都可以独立验证，不要跳步：

  1. 确认目标：你的空调是什么品牌/协议（决定选方案 A 还是 B）。
  2. 了解硬件：板载红外的引脚、器件特性、使用限制（发射距离、载波）。
  3. 搭环境：安装 Arduino CLI、M5Stack 板包、红外库。
  4. 写最小程序：先发一帧已知信号，把"发射→接收"链路打通（这是最关键的一步）。
  5. 实现功能：按选定的方案（生成帧 / 学习回放）写出完整控制器。
  6. 实测固化：近距离对准空调验证，然后固化使用姿势（距离、按键习惯）。
最重要的原则：先打通链路，再堆功能。第一步不要写任何业务逻辑，只验证"设备能不能发出一段空调认识的信号"。

1. 认识硬件：StickS3 的红外能力

1.1 引脚与器件

功能引脚板载器件特性
IR 发射 TXGPIO46Everlight IR928-6C（940nm 红外管）单管 + 22Ω 限流，功率较小，高电平点亮
IR 接收 RXGPIO42Vishay VSOP38338（38kHz 解调接收头）内置 AGC + 带通滤波，active-low 输出，10K 上拉

1.2 必须先知道的四条使用特性

① 发射距离短，必须近距离正对

板载红外管功率小，有效发射距离 ≤ 30-50cm，且要正对设备的红外接收窗（空调面板右下角的暗红色小窗）。这是设备固有特性，不是软件能解决的。

② 接收目标距离 30-100cm

接收头带 AGC，信号太近（<20cm）会饱和导致波形失真，太远信号弱。学习时把遥控器/手机放在 30-100cm 处最稳。

③ 载波 38kHz

接收头对 38kHz 载波最灵敏（带宽约 ±2-3kHz）。你的信号源（遥控器/手机 App）应使用 38kHz 载波。

④ 供电与干扰

代码里必须先 M5.Power.setExtOutput(true, m5::ext_none); 给板载红外供电，并调用 M5.Speaker.end(); 关闭扬声器功放（功放会干扰 IR 接收）。

2. 环境搭建（Arduino CLI + 板包 + 库）

2.1 安装 arduino-cli

brew install arduino-cli

2.2 添加 M5Stack 板包并安装核心

arduino-cli config init --overwrite

arduino-cli core update-index
arduino-cli core install m5stack:esp32

2.3 安装红外库

推荐 ESP32IRPulseKit：支持 RMT 底层收发，内置十余种空调协议（Panasonic / Gree / Haier / Midea / Toshiba…）的编解码，可生成标准帧。

arduino-cli lib install M5Unified M5GFX ESP32IRPulseKit

2.4 确认板子与端口

# 列出已连接的板子（记住你的 USB 端口名）
arduino-cli board list
库的推荐配置（烧录前设置好，避免长帧丢失）： ESP32-S3 每个 RMT 通道内存很小（48 符号），空调帧往往 75-125+ 符号。建议把库的 RX 通道内存调到 128 符号并开启 DMA（src/hal/RmtHal.cpp 里 cfg.mem_block_symbols = 128; cfg.flags.with_dma = true;）。改完放在项目内、并记录改动，避免库更新后被覆盖。

3. 方案选型：生成帧 vs 学习回放

做 AC 控制器有两条完全不同的路，先选路再动手：

方案 A：库生成标准帧直发方案 B：学习 + 回放
原理库内置该品牌协议，用代码生成一帧标准波形发送捕获遥控器的原始波形，原样重放
前提你的空调品牌在库的协议表里（Panasonic/Gree/Haier/Midea…）任意品牌、任意按键，只要捕获质量好
稳定性最稳 波形教科书级，空调一定认识依赖学习时捕获质量（容易受距离/AGC 影响）
灵活性可程序化生成任意温度/模式/风速组合只能重放录过的按键
推荐首选协议不在库里的备选
判定方法：先把库支持列表看一遍（ESP32IRPulseKit 的 ac/ 目录），找到你空调品牌就用方案 A；找不到再用方案 B。绝大多数主流空调都能在 A 里找到。

4. 方案 A：库生成标准帧直发（推荐）

以 Haier 空调为例，完整可编译的 sketch（K1 短按 = 开关，K2 长按 = 关机）：

#include <M5Unified.h>
#include <ESP32IRPulseKit.h>

constexpr uint16_t IR_TX_PIN = 46;
constexpr uint16_t IR_RX_PIN = 42;

esp32irpk::IRSender tx(IR_TX_PIN);
esp32irpk::IRReceiver rx(IR_RX_PIN, false);

void setup() {
  M5.begin();
  Serial.begin(115200);
  delay(200);

  M5.Power.setExtOutput(true, m5::ext_none);  // 给板载红外供电
  delay(100);
  M5.Speaker.end();                           // 关功放，避免干扰 IR

  // 发送端：长帧建议关闭相位对齐载波、加大 RMT 内存
  tx.setTxMemBlocks(2);
  tx.setPhaseAlignedCarrier(false);
  tx.begin();

  Serial.println("K1: 开关   K2长按: 关机");
}

void loop() {
  M5.update();

  if (M5.BtnB.pressedFor(1000)) {
    Serial.println("power off");
    M5.Power.powerOff();
  }

  if (M5.BtnA.wasPressed()) {
    sendToggle();
  }
  delay(10);
}

static bool powerOn = false;  // 交替开/关
void sendToggle() {
  powerOn = !powerOn;

  // 库生成一帧教科书级 Haier 帧（完整头部 + 正确校验和）
  esp32irpk::ac::Haier::Frame f;   // 默认 制冷24°C / 风速自动
  f.setPower(powerOn);

  uint16_t ticks[esp32irpk::ac::Haier::Frame::kMaxTicks];
  esp32irpk::IRRawTickBuffer buf{ticks, esp32irpk::ac::Haier::Frame::kMaxTicks, 0};
  if (!f.toRaw(buf)) {
    Serial.println("encode failed");
    return;
  }
  esp32irpk::IRRawTickView view{buf.ticks, buf.len};

  // 连发 3 次（模拟真实遥控器重复行为），提高空调命中率
  for (int i = 0; i < 3; i++) {
    tx.send(view);
    delay(80);
  }
  Serial.printf("sent Haier %s\n", powerOn ? "ON" : "OFF");
}

4.2 修改成你的空调设置

库每个品牌都提供 setter，直接改默认帧即可生成你想要的模式/温度：

esp32irpk::ac::Haier::Frame f;
f.setPower(true);
f.setMode(esp32irpk::ac::Haier::Mode::COOL);   // COOL / HEAT / DRY / FAN / AUTO
f.setTemperatureC(26);                          // 16-30°C
f.setFan(esp32irpk::ac::Haier::Fan::AUTO);      // AUTO / LOW / MED / HIGH
f.setSwingV(esp32irpk::ac::Haier::SwingV::OFF); // OFF / UP / DOWN / CYCLE

不同品牌命名略有差异（如 Gree 用 ac::Gree::Mode::COOL），但结构完全一致。

5. 首次实测：打通收发链路

这一步是整件事的成败关键。上传后立刻做链路验证：

  1. 把设备举到空调正前方 30-50cm，对准空调接收窗（面板右下角暗红色小窗）。
  2. 按 K1，观察空调有没有反应。
  3. 若没反应，按顺序检查：距离/角度 → 载波 38kHz → 板子供电（setExtOutput）→ 端口是否烧对。
不要一开始就隔 1 米测试。 板载红外管功率小，先近距离确认链路通，再考虑距离。90% 的"发不出去"都是距离/角度问题，而不是代码问题。
链路验证通过后再加功能（学习、多按键、屏幕显示）。先小步跑通，再扩展，永远比一次写完再查快。

6. 方案 B：学习 + 回放（任意遥控器）

当你的空调品牌不在库的协议表里时，用学习回放：捕获遥控器原始波形 → 保存 → 原样重发。

6.1 捕获（学习）

// 初始化接收
rx.setMaxRxSymbols(512);      // 空调帧长，务必调大
rx.setIdleThresholdUs(15000); // 15ms 空闲阈值，把连发帧切成独立捕获
rx.begin();

// 循环里读一帧
esp32irpk::IRReceiveResult<4> result;
if (rx.read(result)) {
  // result.raw.ticks[] = mark/space 时长数组（1 tick = 10us）
  // 在这里保存 result.raw
}

6.2 保存到 LittleFS（文件格式约定）

// 格式：2 字节 uint16_t 长度 + len 个 uint16_t tick（小端）
File f = LittleFS.open("/power.bin", FILE_WRITE);
uint16_t len = (uint16_t)raw.len;              // 注意！长度必须是 2 字节
f.write((const uint8_t *)&len, sizeof(len));
for (size_t i = 0; i < raw.len; i++) {
  uint16_t t = raw.ticks[i];
  f.write((const uint8_t *)&t, sizeof(t));
}
f.close();
文件格式是学习回放最容易翻车的地方：长度字段必须固定写 2 字节（uint16_t）。如果用 sizeof(raw.len)（size_t 在 ESP32 上是 4 字节），读写就会错位，回放出来的波形整体损坏。

6.3 回放

// 读文件 → 还原 ticks → 发送
uint16_t len = 0;
f.read((uint8_t *)&len, sizeof(len));
for (size_t i = 0; i < len; i++) f.read((uint8_t *)&tickBuffer[i], sizeof(uint16_t));

esp32irpk::IRRawTickView view{tickBuffer, len};
tx.send(view);

6.4 学习时的捕获质量判断

  • 一帧空调波形通常 100-250 个 tick（Haier 约 150）。
  • 波形的数据位应包含 1-bit 空间（约 1000-2600µs）；如果完全没有，说明捕获的是噪声，重学。
  • 理想的帧从 同步头开始（如 Haier 是 3000/3000/3000/4300µs）；缺头的半帧空调不认。
  • 手机万能遥控 App 通常只能"点按"发一帧，且信号偏强——放在 30-100cm、连按 3-5 次，取最干净的一帧。

7. 使用最佳实践与避坑清单

7.1 发射（控制空调）

做法原因
≤30-50cm、正对空调接收窗板载 IR 功率小，远了信号到不了
连发 2-3 次（间隔 50-100ms）模拟遥控器重复行为，提高命中率
确保 38kHz 载波接收头只对 38kHz 灵敏

7.2 接收（学习）

做法原因
信号源放 30-100cm太近 AGC 饱和失真，太远信号弱
连按 3-5 次，取最佳帧单次捕获可能撞上 AGC 恢复期/半帧
关闭扬声器功放（M5.Speaker.end()）功放噪声会干扰 IR 接收
接收通道用 128 符号 + DMA空调长帧（75-125+ 符号）不被截断

7.3 通用避坑清单

1 先确认"谁在发信号"

手机 App 能控空调 ≠ 它的码能被轻松学习。先用库的生成帧做链路验证（方案 A），确认设备自身收发正常，再谈学习。

2 一个按键一个动作，别让 repeat 帧捣乱

长按遥控器会连发多帧，学习时捕获到的可能是合并帧。点按 + 多次捕获取最佳。

3 协议"单帧"就别连发

有些品牌一帧就是完整指令（如 Haier、Toshiba、Samsung），连发两帧会被当成两次按键（开关互相抵消）。查库文档确认你的品牌是否单帧，连发只用于提高命中率时也要控制次数与间隔。

4 上传报 "port busy"

先退出串口监视器再上传；若仍占用，用 lsof /dev/cu.usbmodemXXXX 找到残留的 serial-monitor 进程并结束。

5 端口名会变

设备重插/重枚举后端口名可能从 usbmodem1101 变成 usbmodem101。上传前用 arduino-cli board list 确认。

6 改第三方库要留记录

把库放在项目内（如 .arduino_sketchbook/libraries），改动记进 README，防止库更新被覆盖。

8.1 一个按键循环多种功能

// K1 短按：开关；K1 长按：温度+1；K2 短按：温度-1；K2 长按：关机
// 用 M5.BtnA.wasPressed() / pressedFor() 区分手势即可

8.2 保存你的"常用设置"

把温度/模式/风速固化在代码里，开机即用，不需要每次设置：

esp32irpk::ac::Haier::Frame f;
f.setPower(true);
f.setMode(esp32irpk::ac::Haier::Mode::HEAT);  // 冬天模式
f.setTemperatureC(26);
f.setFan(esp32irpk::ac::Haier::Fan::HIGH);
// 生成帧发送即可

8.3 接上电池做便携遥控

  • 电池满电约 250mAh，待机功耗低，可当床头遥控器常开。
  • K2 长按 M5.Power.powerOff() 可关机省电。
  • 用支架把设备固定在床头柜，正对空调方向。
完成标志：设备在你伸手可及的位置，按一下 K1 空调就响应——恭喜，你的 StickS3 已经是合格的 AC Controller 了。
