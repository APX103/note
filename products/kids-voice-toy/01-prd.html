产品需求文档（PRD）

产品名（候选）：小回声 / 回声宝 / 留声鹅 / 时光蛋 · 项目代号 Echo。本文回答"做什么、为谁做、做到什么程度"，是后续所有技术方案的需求源头。

1背景与洞察

市场现象：AI 玩具大量"吃灰"。一位从事 AI 测评的宝妈为女儿买过市面多数 AI 玩具，绝大多数玩几天就失去兴趣。AI 对话的新鲜感衰减极快——"聊什么都能聊"很快变成"没什么可聊"。

例外：一个会留存状态的小相机（华强北购入）。女儿持续玩了很久，原因是它拍下的内容一直存在：很久之后还能回看过去拍的东西，并且带有"对过去的思考"。这说明儿童玩具的长留存不来自更强的对话能力，而来自状态的积累与重温——玩具随着使用时间变得越来越"有内容"。

机会：把这个机制移植到声音。做一个声音版"时光机"：孩子可以随时对它说话、听故事；孩子说过的每一句都被留存，很久之后可以重新回听，并带着 AI 的回忆视角；家长也可以在手机上回听孩子的童言，长大后导出留念。

反面教材（必须规避）：同类付费产品讲故事讲到一半播报"Token 不足了，快叫妈妈充值吧"。体验崩塌 + 亲子尴尬 + 家长反感。任何情况下，故事与对话不允许停在半路。

核心结论：AI 陪聊只是入口功能，"留住童年的声音"才是产品本体。聊天会腻，回忆不会——录音数据随时间增值，用户随时间黏住。

2产品定位

"孩子的玩伴，父母的声音日记。"

一个无屏幕、按键操作的 AI 声音玩具：孩子按住它说话，它用可爱的童声回应、讲故事；孩子说过的每一句话都被珍藏，随时可以回听——是孩子成长的"声音时光机"。

孩子侧：好玩的伙伴

  • 按住就能说，松开/发送就有回应——低门槛、即时反馈
  • 童声回复，语气像同龄小伙伴，不说教
  • 会讲爱听的故事，还能接着孩子的想法编
  • "还记得我上次说的话"——玩具记得我，情感联结

家长侧：情感价值（真正的购买动机）

  • 童言无忌全量留存，手机随时回听、永久导出
  • 每周"童言精选"自动推送——育儿生活里的高光时刻
  • 一年后回放"她 4 岁时说的话"——时光胶囊式情感杀
  • 隐私可控：谁能听、可删除、可导出，数据归家长

注：访谈显示妈妈对"留声"价值一秒 get，爸爸常 get 不到。营销素材与详情页要面向感性记录型家长，而非参数党。

3用户画像

使用用户：孩子（3–8 岁）

User · 玩的人

  • 语言表达期，话多、爱重复、爱问"为什么"
  • 注意力短，需要即时反馈与具象交互（按键/灯效/声音）
  • 不识字：零文字 UI，全靠声音与按键
  • 黏性来源：被记住、被回应、仪式感（睡前故事）

购买用户：妈妈（25–38 岁为主）

Customer · 买单的人

  • 记录型家长：手机相册几万张，爱发朋友圈/相册书
  • 情感驱动消费，对"留住童年""成长纪念"高度共鸣
  • 决策顾虑：安全（内容+隐私+听力）、辐射、电池、耐摔
  • 价格带敏感度：¥200–400 玩具可接受，¥39–59/月服务需强理由

影响用户：爸爸 / 祖辈

Influencer · 影响决策

  • 爸爸：关注参数与隐私安全，是"质检员"不是"粉丝"——详情页要有安全与合规背书
  • 祖辈：高频陪玩人，需要"插电即用"级简单，几乎零学习成本
  • 远程祖辈/亲友：潜在"收听用户"，后期分享功能的付费点

4核心用户故事

孩子侧
  • S1
    按住说话：我想跟它说话时，按住大按钮开说；我说话断断续续，可以停下来想一下再继续说；说完按另一个按钮，它就回我。回复要快、声音可爱、像小伙伴。
  • S2
    听我刚才说的：我可以说"听听我刚才说的"，或者按回放键，它会放我刚才说的话。（童年的"复读机"快乐）
  • S3
    讲故事：我说"讲个小猪佩奇的故事"（或按下故事键），它就开讲；我能插话改变故事走向。断网了它也能讲本地存的故事。
  • S4
    它记得我：我问"我上次说长大想当什么呀"，它能放我以前的原声录音，还会像朋友一样评论"那时候你说想当宇航员诶"。
家长侧
  • S5
    回听：扫码绑定后，我在手机上按日期回听孩子对玩具说的每一句话，带文字转写；可以收藏、下载、转发给爸爸/奶奶。
  • S6
    每周精选：每周日晚上收到一条推送："本周最可爱的 3 句话"——自动从录音中挑出金句，附原声。
  • S7
    时光胶囊：一年后的今天，收到"去年今天她说过……"的提醒，附原声；18 岁时可以导出一本"声音成长书"。
  • S8
    安全与隐私：我能设置哪些内容不可回放、一键删除任意录音、随时导出全部数据；孩子问出敏感问题（死亡/暴力等）时，玩具会用儿童友好的方式回应，并给我一条提示。

6按键交互规格

推荐 · 方案 A（3 键 + 开关）

适配"断断续续说话"的多段录音

  • ① 录音键（大圆键）：按住录音，松开暂停（3s 内可续录拼接）；静默 5s 自动封口；封口后"滴"提示音
  • ② 发送键：把刚录的（一段或多段拼接）发出去，AI 回复扬声器播放
  • ③ 回放键：本地立即重播刚才的录音（不经云端，孩子最爱）
  • ④ 电源开关：拨动开关，物理断电（家长安心）
  • 长按发送键 2s = 讲故事（进入故事模式，可语音点播）；长按回放键 2s = 时光机（随机回放历史录音+AI 点评）
参考 · 方案 B（子豪 4 键）

录音键按住说话、松开即发送

  • ① 讲话键：按住说话，松开直接发送
  • ② 回放键：完整播放刚才的录音
  • ③ 确认键：确定要不要让 AI 发送
  • ④ 开关：电源
  • 差异点评：B 的"松开即发"更干脆，但不支持断续说话的孩子（说一半停住思考就误发送）；A 更贴合 3–5 岁语言节奏。Demo 阶段两种交互都可以让种子家庭试用后定稿。

状态灯效（唯一可视化反馈，替代屏幕）

状态灯效声音反馈
待机白光呼吸（缓慢）无
录音中黄色常亮，随音量微闪开始"叮"一声
上传/AI 思考蓝色呼吸（快）无（≤2.5s 内必须出声）
AI 播报蓝色常亮童声回复
讲故事暖橙色呼吸故事音频
网络异常红色慢闪"我连不上网啦，先听本地故事吧"→ 自动降级
电量低红色快闪 3 次/分钟低电量提示音
儿童产品设计约束：音量上限 ≤ 85dB（GB 6675 听力保护），软件限幅 + 出厂锁定；错误提示一律童声拟人化（不说"错误代码 404"，说"我打个盹儿了，再按一次嘛"）；所有按键支持盲操作（凸起/纹理区分）。

7非功能需求

维度要求
性能按发送到首次出声 ≤ 2.5s（P95）；讲故事点播 ≤ 3s；本地回放 < 0.5s
续航2000mAh 锂电：中度使用（日均 40min 交互）≥ 8h；支持边充边用（睡前故事场景常插电）
可靠性断网：本地故事可讲 + 本地录音暂存（≥ 500 段），联网后自动补传；7×24 服务可用性 ≥ 99.5%
内容安全双向过滤（输入 ASR 文本、输出 LLM 文本）经内容安全 API；拦截率目标 ≥ 99%；敏感问题走儿童友好兜底话术库
隐私合规儿童语音=敏感个人信息：监护人单独同意（绑定流程内置）、最小化收集、传输与存储加密、家长可删除/导出、明确保留期限；《儿童个人信息网络保护规定》+《个人信息保护法》
硬件安全电玩具 3C（GB 6675 / GB 19865）；电池 GB 31241 + UN38.3；无线模块用已认证 ESP32 模块（SRRC）；电池仓螺丝固定不可徒手拆
成本红线量产 BOM ≤ ¥60；单台月云边际成本 ≤ ¥8（重度用户），商业模式覆盖（详见 07 篇）
可维护设备 OTA；服务端配置热更（人设/话术/故事包）；设备端日志回捞（家长授权后）

8产品红线与 No-go

五条红线（违反=失败）

  • 1. 体验永不因计费中断：绝不出现"Token 不足，快叫妈妈充值"。额度用尽 → 无缝切换本地故事库 + 温和提示家长端续费（只发给家长，不播给孩子）。
  • 2. 不对孩子做商业话术：不引导孩子要求家长购买任何东西。
  • 3. 不说教、不评判：孩子说"我不想上幼儿园"，回应是共情而非教育；家长要的教育功能走家长端（P2）。
  • 4. 隐私默认最强：录音默认仅绑定的家庭可见；任何分享需家长显式操作；不做录音数据二次利用。
  • 5. 安全兜底优先于有趣：过滤有误杀没关系，漏放一次就是灾难。

明确不做（v1 No-go）

  • 摄像头/图像/视频：成本、隐私风险、场景（家长明确说不需要）三重否决
  • 屏幕：加成本、抢注意力、护眼争议；声音玩具就该"看不见"
  • 教育课程属性：不做"学英语/识字"卖点——防内卷焦虑定位，这是玩具不是教具
  • 开放唤醒词全时监听（v1）：按键交互 = 明确的录音边界，隐私上更站得住，功耗也更低；语音唤醒留待 v2 做可选开关
  • App 重客户端：家长端 H5 → 小程序，不做独立 App
  • 自研大模型/自建 ASR：全部用成熟 API，差异化在记忆层与体验层

10成功指标（Demo → 量产）

孩子侧（产品力）

  • 7 日后仍主动使用（反"吃灰"核心指标）
  • 日均主动交互 ≥ 3 次
  • 单次会话中位数 ≥ 3 轮对话
  • 故事功能周使用 ≥ 2 次（睡前场景渗透）

家长侧（价值验证）

  • 家长周回听 ≥ 3 次（时光机价值成立）
  • 每周精选打开率 ≥ 40%
  • 愿意推荐给朋友的比例（NPS）≥ 40
  • 绑定时隐私同意流程完成率 ≥ 95%

商业侧（放量判据）

  • 退货率 ≤ 5%（联网配置是最大风险源，见 08 篇）
  • 抖音视频 GPM ≥ 1000 再放量投流
  • 首年会员转化率 ≥ 20%
  • 单台首年云成本 ≤ 硬件毛利 30%
