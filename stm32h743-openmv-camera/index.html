一分钟快速开始

cd CAMERA_LCD_TEST && make -j8
openocd -s /opt/homebrew/share/openocd/scripts -f interface/stlink.cfg -f target/stm32h7x.cfg -c "adapter speed 4000" -c "program build/camera_lcd.elf verify reset exit"
板上现象：绿灯闪 3 次后熄灭 → LCD 居中显示 108×80 全视场实时画面 + 底部绿色状态条（传感器名/fps/错误数）；按 KEY 点亮摄像头照明灯（15 秒自动关）。
